# 视频字幕常用字体调研报告（Top 10 + 延伸备选）

> 调研目的：为 AIcut 视频编辑器的「字幕字体选择器」提供选型依据。
> 每条字体统一分析 4 个维度：①视觉特征 ②用户为什么喜欢 ③适合什么视频字幕类型 ④使用建议（描边/阴影/配色）。
> 调研时间：2026-07。数据来源：抖音/剪映官方字体实践、B站 UP 主字体使用统计（影视飓风调研 54 位 UP 主）、优设/站酷字库热度、100font / 猫啃网免费商用字体榜单、微课字幕参数实测。

---

## 一、字幕字体选型的三大硬原则（先讲规矩）

1. **可读性第一**：字幕是「信息载体」不是「装饰」。小屏（手机竖屏）+ 动态背景 + 频繁切镜，纤细/笔画粘连的字体叠描边会糊成一团。优选「中宫开阔、笔画粗实、字重齐全」的无衬线体。
2. **版权安全**：只要视频带货、接广告、门店引流、付费课程 = 商用。微软雅黑、方正、汉仪、华康等**仅个人免费，商用需授权**，是维权高发区。优先选 **SIL OFL 开源** 或 **厂商永久免费商用声明** 的字体（思源系列、阿里巴巴普惠体、鸿蒙均在此列）。
3. **风格匹配赛道**：知识口播用花哨手写体显不专业；少儿母婴用厚重黑体缺亲和力；国风美食用现代黑体缺氛围。字体即调性。

**字幕样式黄金公式（跨字体通用）**：
- 描边：`浅色字 + 深色描边` 或 `深色字 + 浅色描边`，粗细 **1–3px**（勾勒轮廓，不喧宾夺主）。
- 阴影：低强度投影（距离 2–4、模糊 4–8、透明度 30%–50%），增强与背景分离。
- 位置：画面底部 1/4 处，单行 ≤16 字，留安全边距（左右 5% 画幅）。

## 二、Top 10 常用字幕字体

### 1. 思源黑体（Source Han Sans / Noto Sans SC）
- **视觉特征**：Adobe + Google 联合开发，开源 OFL，7 个字重（ExtraLight→Heavy），覆盖简繁日韩，字形中性现代、中宫开阔。
- **用户喜欢的原因**：跨平台一致性极强（Win/Mac/Android/iOS 都有），多语言混排不违和；开源免费商用，无版权风险；小字号屏幕可读性天花板级。
- **适合**：**全能通用型**——知识科普、口播、Vlog、纪录片旁白、B站/YouTube 主字幕。抖音默认字幕字体之一，B站 54 位头部 UP 主中 14 位在用。
- **使用建议**：正文 Regular/Medium；重点句加粗到 Bold；白字 + 黑描边 2px。

### 2. 微软雅黑
- **视觉特征**：Windows 系统默认无衬线，笔画均匀、屏幕渲染成熟。
- **用户喜欢的原因**：几乎每台 Windows 都自带，零成本、零安装；长期视觉习惯，用户"看着舒服"。
- **适合**：知识科普、课件、Windows 生态录屏字幕。剪映知识类视频官方推荐字体之一。
- **⚠️ 重大版权提示**：**个人使用免费，商用（带货/广告/课程）需购买授权**，是字体维权高发对象。编辑器内置时建议标注"仅个人非商用"或引导用户自备授权。
- **使用建议**：白字 + 深灰描边 2px；避免极小字号（雅黑小字略虚）。

### 3. 苹方（PingFang SC）
- **视觉特征**：Apple 为 iOS 9 设计的中文字体，6 字重，现代干净、字间距舒适。
- **用户喜欢的原因**：iOS 原生观感，iPhone 用户"天然顺眼"；抖音系统默认字体之一。
- **适合**：面向苹果用户的 Vlog、生活方式、美妆种草；与 SF / Inter 西文搭配做"苹果风"界面字幕。
- **⚠️ 版权提示**：非苹果系统商用受协议限制（macOS 上 UI 用途可免费，其他场景法理上受限）。Windows 用户可用 Inter + 思源黑体近似替代。
- **使用建议**：浅色字 + 细描边即可，苹方自带留白已足够清晰。

### 4. 阿里巴巴普惠体（Alibaba PuHuiTi）
- **视觉特征**：阿里集团发布，永久免费商用，多字重，结构稳重、笔画清晰。
- **用户喜欢的原因**：电商/企业场景"国民级"免费商用黑体；比思源黑体更偏商务稳重，品牌感强；微课"通用标准款"首选之一（与思源黑体并列）。
- **适合**：**电商带货、企业宣传、数据可视化、付费课程**——凡涉及明确商用的字幕，它是比雅黑更安全的选择。
- **使用建议**：白字 + 黑描边；标题可用 Bold 压场。

### 5. 思源宋体（Source Han Serif）
- **视觉特征**：思源黑体同系宋体，开源 OFL，兼具传统宋体典雅与现代排印清晰度。
- **用户喜欢的原因**：在"需要文化感/厚度"的题材里，比黑体更有叙事质感，又不像老宋体那样屏幕发虚。
- **适合**：纪录片、访谈、文化类、书籍推荐、人文旅行 Vlog 的字幕/标题。
- **使用建议**：浅米色字 + 深棕描边；字号略大（宋体小字易糊），背景干净时甚至可关描边。

### 6. 楷体（KaiTi）
- **视觉特征**：书法楷书骨架，横轻竖重、带笔锋。
- **用户喜欢的原因**：天然"古风/情感/手写"联想，成本低（系统自带）；能瞬间把观众拉进故事情绪。
- **适合**：古风国风、情感独白、诗词、故事叙述类字幕；内心独白可用淡紫背景 + 楷体营造细腻氛围。
- **使用建议**：浅色字 + 深描边 2.5px（笔锋细处需描边保形）；避免快节奏卡点视频。

### 7. 黑体（SimHei）
- **视觉特征**：系统默认方头无衬线，笔画等粗、对比强、字重单一但极厚重。
- **用户喜欢的原因**：超高识别度，远距离/小屏一眼可读；演讲/短剧字幕"行业默认"。
- **适合**：**大字幕、标题压场、短剧对白、演讲字幕**——需要"字字砸实"的场景。
- **使用建议**：白字 + 黑描边 2–3px；正文长句慎用（单一字重略呆板），更适合短句标题。

### 8. 站酷快乐体 / 站酷酷黑
- **视觉特征**：站酷系免费商用字体。快乐体圆润活泼；酷黑厚重有力、设计感强。
- **用户喜欢的原因**：免费商用 + 强风格化，短视频"一眼年轻"；酷黑在游戏/二次元标题里力量感足。
- **适合**：活泼短视频、卡点视频、游戏/动漫二次元类标题字幕（站酷酷黑、庞门正道标题体被明确推荐）。
- **使用建议**：彩色字 + 白/黑描边；宜做标题不做长正文；快乐体配圆角背景更萌。

### 9. Impact / Bebas Neue（英文大标题）
- **视觉特征**：Impact 超粗紧凑无衬线；Bebas Neue 高瘦全大写，电影感强。
- **用户喜欢的原因**：英文标题"压迫感/速度感"标杆，运动、快剪、预告片标配；开源免费。
- **适合**：**英文大标题、运动集锦、快剪转场、影视预告片**字幕（常配合中文黑体做中英混排标题）。
- **使用建议**：纯英文用；与思源黑体中文搭配；白字 + 黑描边或纯色填充。

### 10. 仿宋（FangSong）
- **视觉特征**：政府公文标准字体，笔画清秀、有书卷气。
- **用户喜欢的原因**：权威/正式的心理暗示，观众一看即知"这是新闻/公文/通告"。
- **适合**：新闻字幕、公文播报、严肃纪实、政策解读类字幕。
- **使用建议**：深色字（黑/藏青）配浅色底；字号适中；不适合娱乐向。

## 三、延伸备选（确实常用、但不硬塞进 Top 10）

> 这 3 个在当下中文视频里使用量极大，因 Top 10 已覆盖"四类结构"而未强替；作为编辑器「更多字体」分区单列更合理。

- **鸿蒙字体（HarmonyOS Sans）**：华为发布、免费商用，科技感强、数字界面优。极客湾等数码 UP 主在华为/小米相关视频中高频切换（HarmonyOS Sans / MiSans / OPPO Sans）。适合数码评测、科技科普字幕。
- **抖音美好体**：抖音 × 方正联合定制品牌字体，平台原生，年轻现代。抖音系短视频直接套用相关性最高。适合抖音原生内容标题/字幕。
- **得意黑 / 站酷小薇体等艺术标题体**：极客湾等用于章节标题的"艺术风格字体"，冲击力强但可读性低，仅适合短标题/章节标，不适合长字幕。

## 四、给 AIcut 编辑器的落地建议

字幕在 AIcut 里是 DOM 叠加层（`activeTextOverlays`，CSS `fontFamily` 驱动），落地成本极低：

1. **字体选择器**：右侧属性面板字幕样式处加下拉，列出 Top 10 + 延伸备选（按"通用 / 文艺 / 标题 / 严肃 / 更多"分组）。
2. **安全标注**：微软雅黑、苹方项后标注「⚠ 商用需授权」，引导用户用思源/阿里普惠/鸿蒙做商用安全替代。
3. **字幕样式预设**（可选下一步）：把"字体 + 描边 + 阴影 + 配色"打包成几套开箱即用——如「通用清晰款（思源黑+白字黑描边）」「电商带货款（阿里普惠+黄字黑描边）」「古风情感款（楷体+米字深描边）」「数码科技款（鸿蒙+浅字细描边）」。
4. **字体可用性**：开源字体（思源/阿里普惠/鸿蒙）建议随安装包内置；系统字体（雅黑/苹方/黑体/楷体/仿宋）走 `fontFamily` fallback，缺失时优雅降级到思源黑体。
