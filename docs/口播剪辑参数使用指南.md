# 口播剪辑使用指南 —— 参数详解与实践建议

> 适用版本：Phase 4.5 口播剪辑模块（FunASR 识别 + DeepFilterNet3/FRCRN 降噪 + PANNs 副语言检测）
> 本文所有默认值、范围均以当前代码实际实现为准（SpeechPanel.tsx / core.py / speech.rs）。
> 目标：让不熟悉音频处理的用户也能快速上手，并理解每个旋钮「往哪边拧会发生什么」。

---

## 一、这个功能是做什么的

口播剪辑用于**自动清洗人声录音**：识别语音内容后，自动标记并删除口癖（嗯/啊/那个）、结巴卡顿、笑声叹息、过长停顿、首尾静音，可选 AI 降噪、响度归一等音质处理，最终生成一条紧凑、干净的口播成片。

支持两类素材：
- **纯音频**（m4a/wav/mp3 录音）——产出口播音频
- **视频**（mp4 等含人声的视频）——**画面随声音同步剪切**（口型对齐，无需二次对轨）

---

## 二、五步工作流（先看这个）

```
① 时间轴选中一段视频/音频片段
② 选一个预设（推荐先「标准」）→ 点【分析】
③ 在结果里看红色删除标记是否合理（可微调/撤销/改为保留）
④ 点【试听清洗结果】确认听感
⑤ 点【生成清洗片段】→ 自动落轨（原片段保留，可随时对比重做）
```

要点：
- **分析不会改动原素材**，只是生成一份「保留/删除」标记。
- **生成的文件写在源文件旁边**，命名如 `xxx_speechcut.mp4`；试听临时文件为 `xxx_preview.mp4`。
- 多段素材可点【批量处理时间轴】一次性串行处理全部音视频素材（结果自动落轨，无逐段人工审核环节）。

## 三、三个预设怎么选

| | 轻量 | **标准（默认）** | 激进 |
|---|---|---|---|
| 适用 | 内容珍贵、怕误删 | 大多数口播/vlog | 追求极致紧凑、可接受偶尔误删 |
| 识别模型 | base | base | small |
| VAD 灵敏度 | 0.30 | 0.25 | 0.20 |
| 最小停顿(s) | 0.10 | 0.18 | 0.05 |
| 词边界(s) | 0.02 | 0.04 | 0.06 |
| 降噪 | 标准 | 标准 | **高质量(FRCRN)** |
| 保留背景音乐/环境音 | 关 | **开** | 关 |
| 保留呼吸气口 | 关 | 开 | 开 |
| 副语言阈值 | 0.40 | 0.50 | 0.60 |
| 结巴阈值 | 0.40 | 0.50 | 0.60 |
| 接缝平滑(ms) | 20 | 20 | 30 |
| 去齿音 / 响度归一 | 关 / 关 | 关 / 关 | **开 / 开** |

经验法则：
- **拿不准就点「标准」**；分析完看统计里的「压缩 %」，觉得删得不够再换「激进」重新分析。
- 「激进」的副语言/结巴阈值反而**更高**（0.6）——因为它删的东西更全面，需要更高的置信度兜底防止乱删。

## 四、参数详解

### A 组 · 识别与时间轴（决定「哪里算说话」）

#### 1. 识别模型（下拉框）
- **作用**：本地语音识别引擎的规模，影响转写精度和速度。
- **选项**：tiny（最快）→ base → small → medium → large（最准）。
- **默认**：base。
- **怎么选**：
  - 普通话清晰 → base 够用；
  - 方言口音重、语速快、专有名词多 → 调到 small/medium（更慢但错字少，词级时间戳更准=剪切更准）；
  - tiny 仅建议试跑或超长素材粗剪。

#### 2. VAD 灵敏度（滑块 0.05 ~ 0.60，步进 0.05）
- **作用**：Silero VAD 判定「这段是不是人声」的概率门槛。
- **默认**：0.25。
- **向右调大**：判得**更严**——只有很确定的语音才保留，*轻微的说话声、拖长的尾音更容易被当作静音删掉*。适合录音干净、想剪得更紧的场景；**怕误删字的用户不要调太高**。
- **向左调小**：判得**更松**——轻声、气声开头都算语音被保留。适合小声细语、句尾习惯性收音很轻的人。

#### 3. 最小停顿(s)（滑块 0.05 ~ 0.60，步进 0.01）
- **作用**：**短于**这个时长的静音间隙一律保留，不视为可删停顿。它控制「剪刀的颗粒度」。
- **默认**：0.18s。
- **向右调大**（如 0.3~0.5）：保留更多自然的句间呼吸和停顿，**听感最自然**、不容易出现「赶话」，但压缩率下降。适合课程讲解、情感朗读。
- **向左调小**（如 0.05~0.1）：几乎见缝就剪，节奏最快，适合短视频快节奏口播；代价是可能显得喘不过气。

#### 4. 词边界(s)（滑块 0 ~ 0.20，步进 0.01）
- **作用**：每个删除区间从识别出的词边界**向外扩**的安全余量，防止剪切正好切在字的头/尾上产生「半截字」。
- **默认**：0.04s。
- **向右调大**（如 0.06~0.1）：切得更「留有余地」，不容易崩字；但会把目标词旁边多一点内容一起带走，偶发吃掉下一个字的开头。
- **向左调小**：切得极贴边、最紧凑；若发现成品有「字被劈一半」的爆音，优先把它往右调 0.02 试试。

### B 组 · 删掉什么（内容类删除）

#### 5. 删语气词（复选框，默认开）
- **作用**：删除「嗯 / 啊 / 那个 / 就是」等填充词区间（按识别文本匹配，带词边界余量）。
- **场景**：几乎所有人声口播都建议开。若是刻意保留口头禅风格（比如脱口秀节奏），关闭即可。

#### 6. 结巴/卡顿检测
- **作用**：检测重复音节、卡顿、拖腔（"我我我…"、"那、那个"）。
- **当前策略（重要）**：为保证语音自然流畅（硬性要求），口吃/卡顿**不做自动剪切**，
  而是在时间轴上以**建议标记**呈现——每处都附原音频试听定位，由你逐个确认是否删除。
- **原因**：在连续语流中间剪断必然产生韵律跳变（音高/共振峰不衔接），剪贴式技术
  目前无法保证接缝自然。宁可保留口吃，也不牺牲流畅度。
- **升级路线**：待引入生成式接缝修复（重合成替代剪贴）后，将重新开启自动剪切。
#### 7. 副语言事件检测（复选框默认开 + 副语言阈值滑块 0.10~0.90，步进 0.05）
- **作用**：用 PANNs 神经网络帧级识别**非语音发声**——咳嗽、清嗓、笑声、叹息、拍桌、键盘声等——命中即标记删除。
- **默认**：阈值 0.50。
- **阈值向右调高**（0.6~0.8）：只删非常确定的事件，稳妥。担心把特殊音效/情感笑声明明想留却被删时，调这里。
- **阈值向左调低**（0.3~0.4）：连轻微的杂音也抓出来删，环境音多时很好用；误删风险升高。
- 注意：此类事件**不受「最小停顿」限制**——再短的咳嗽也会被删（这是设计使然）。

#### 8. 呼吸专项检测（复选框，标准默认开）
- **作用**：温和去除吸气声/喘气声（Respiro 风格声学检测，专门识别呼吸特征，不碰语音）。
- **场景**：近距离大振膜麦克风录制的气息声明显时开；喜欢保留真实换气感的纪录片/朗诵风格可关。

### C 组 · 音质处理

#### 9. AI 降噪（复选框默认开）+ 降噪质量（下拉：标准/高）
- **作用**：降噪后的人声**直接作为成片音轨**（开启降噪并生成时自动替换，原声场景关闭降噪即可回退，天然支持 A/B 对比）。降噪波形同时持久化为源旁 `*_denoised.wav`，可单独取用。降噪波形也先行用于转写/VAD/检测，保证嘈杂环境下的剪切点精度。
- **标准 = DeepFilterNet3**（ONNX，GPU 加速，快）；**高 = FRCRN**（体量更大、降噪更彻底，CPU 推理较慢）。
- **场景**：录音有底噪/风扇声/电流声时**务必开启**；棚录干声可关掉以 100% 保留原汁。
- 规格说明：**标准档（DFN3）= 全带宽 48kHz 立体声输出**——DFN3 权重本身是 48k 模型，成片直接保留齿音、气声与背景泛音；高质量档（FRCRN）受限于模型仅 16kHz 单声道（人声频宽与播客相当）。带 BGM 或对音质挑剔的素材建议用标准档，噪声极重的素材用高质量档。

#### 10. DFN3 高 SNR 软化（复选框默认开）+ 软化阈值（滑块 0.30~0.90，步进 0.05，默认 0.50）
- **作用**：只在开启 AI 降噪且质量为「标准」（DFN3）时生效——现在**同时作用于检测音频和成片音轨**（全带宽增强用的就是同一份软化掩码）。降噪网络输出的增益掩码中，已较干净的频段不做满幅处理，按比例混回原始信号：既让识别/检测更接近真实语音分布，也抑制降噪在干净区的"金属味/染色"。
- **向右调大**（0.7~0.9）：越接近完全硬降噪，降噪力度最大，适合噪声极重的素材。
- **向左调小**（0.3~0.4）：混回原声越多，音色最保真、高频最自然，适合本身不太脏的棚录音。
- 默认 0.5 平衡值。若成片人声有处理痕迹 → 往左；残留噪声偏多 → 往右。

#### 11. 声源分离降噪（复选框，默认关）
- **作用**：用 Demucs 把人声和伴奏分离后再清洗，**只有当你的口播带背景音乐/BGM 且不想 BGM 被剪乱时才需要开**。
- **警告**：纯干声口播**别开**——历史实测存在分离误分配导致局部静音的风险；开了之后生成时会走"人声轨清洗 + BGM 按音乐区间拼接"的特殊管线。

#### 12. 去齿音（复选框，默认关）
- **作用**：生成阶段对 8 kHz 以上频段整体衰减 6 dB（高通搁架滤波），抑制 "s/x/c" 的刺耳嘶声。
- **场景**：性感话筒近讲、齿音炸耳时开。注意它是全曲统一衰减，**会让整体高频略微变暗**，能不开就不开（AI 降噪通常已顺带缓解部分齿音）。

#### 13. 响度归一（复选框，默认关，「激进」预设开）
- **作用**：生成阶段执行 EBU R128 响度标准化（目标 -16 LUFS、真峰 -1.5 dBTP），让成片响度和主流平台一致。
- **场景**：准备直接发抖音/B站/公众号，希望不用再二压调音量 → 开。想自己后期混音压限 → 关。

### D 组 · 输出接缝（生成阶段生效）

#### 14. 接缝平滑(ms)（滑块 0 ~ 100，步进 5）
- **作用**：相邻保留段拼接处的交叉淡入淡出时长，消除"咔"式跳变。
- **默认**：20 ms。
- **向右调大**（30~50）：接缝更柔和，适合BGM上或有混响的房间录音（避免背景突变）；太大（>80）会出现轻微"吞字/含糊"。
- **向左调小**（0~10）：切换干脆利落，适合干声快剪；若接缝处听到"嗒"声，说明太小或者配合下面的去咔哒声。

#### 15. 去咔哒声(爆音)（复选框，默认开）
- **作用**：FFmpeg `adeclick` 滤镜修复剪切点和录音本身的爆音/咔哒。
- 保持默认开即可；疑似引入相位感（极少数素材）才关。

### E 组 · 取舍开关

#### 16. 保留背景音乐/环境音（复选框，标准默认开）
- **作用**：不把"没在说话的段落"一刀切成删除——街景、 room tone、前奏这些环境内容会被保留评估而不是全部清除。
- 配合：「标准」预设 + 不开声源分离 = 简单地把 BGM 所在段落保下来（压缩率会低一些）。纯口播想剪最紧 → 关。

#### 17. 修剪首尾静音（复选框，默认开）
- 开头结尾的大段空白整段裁掉。一般不动。

## 五、分析结果怎么读 & 怎么精修

分析完成后：

1. **顶部统计**：`原时长 / 已删除 X 秒 / 压缩 N%` —— 直观看到剪掉了多少。
2. **彩色时间轴条**：绿块=保留，红底=删除；下方的白色曲线是**能量包络**（响度起伏），帮助判断删除段里到底有没有漏掉的语音。
3. **片段审核列表**（按时间排序）：
   - **删除段**可做四件事：输入框微调起止（精确到毫秒/帧）、**捕获**按钮取预览播放头当前位置一键填入、**改为保留**（AI 误删时的救命按钮）、配合底部「新增删除片段」手动补删任何 AI 漏掉的废话（手加的和 AI 删的权限完全一样）。
   - 所有修改支持右上角**撤销**。
4. **试听清洗结果**：先听后出片，不满意回去继续调。
5. **生成清洗片段**：产出落轨，原素材仍在工程里可以对比。

> 提示：手动精修过删除段之后，输出时间线将按你精修后的保留段直接拼接（AI 原始的"暂停压缩"映射失效），这正是所见即所得的行为，不用担心。

## 六、常见素材的推荐配置

| 场景 | 预设 | 关键调整 |
|---|---|---|
| 安静书房录课/知识区口播 | 标准 | 全默认；想更紧凑把最小停顿降到 0.12 |
| 嘈杂室外/手机录音 | 激进 | 打开降噪质量「高」；副语言阈值降到 0.4 |
| 带 BGM 的 vlog | 标准 | 开「声源分离降噪」；接缝平滑调大到 30~40 |
| 情感朗读/纪录片旁白 | 轻量 | 关呼吸检测（保留换气感）；最小停顿拉到 0.35+ |
| 短视频快节奏带货文案 | 激进 | 词边界 0.03；接缝 15；开响度归一直发平台 |

## 七、FAQ / 注意事项

1. **首次点分析很慢？** 识别模型首次加载权重需要时间，属正常现象；后续同会话内会快很多。
2. **视频处理后口型对得上吗？** 对得上。视频素材默认启用同步剪切（画面按声音相同的时间轴切割拼接），不需要手工对轨。
3. **生成的文件在哪？** 与源文件同目录，`原名_speechcut.mp4`。项目里通过「生成清洗片段」自动加入资产库。
4. **会不会覆盖我的原素材？** 不会。产物永远是新文件，时间轴上也保留原始片段供对比。
5. **删除段似乎太碎/太密？** 三件事依次试：换预设；调「最小停顿」向右（减少碎剪）；调对应检测阈值向右（提高置信度门槛）。
6. **某句话被误删了？** 在片段审核列表找到那段红条 → 点「改为保留」。
7. **AI 漏删了一段废话？** 底部「新增删除片段」输入起止（可用「捕获」沿预览播放头逐帧定位）→ 添加删除段。
8. **成片还有残余噪声？** 先确认降噪已开启（关着则成片为原声）。已开启仍有残留：换高质量档(FRCRN)重新分析+生成；仍不满意可在成片后再叠一次外部降噪。若发现的是"剪错了/漏剪了"，那属于检测精度问题，同样优先换高质量档试试。
9. **批量处理能撤吗？** 批量为全自动流水线（分析+生成一步到位），**没有中间审核环节**；重要素材建议先单个走一遍确认参数合适，再批量刷剩余素材。
10. **所有设置会记住吗？** 会。面板上任何改动都写入偏好记忆，下次打开软件仍是上次的状态；点预设按钮则整体切回预设并同样记忆。
