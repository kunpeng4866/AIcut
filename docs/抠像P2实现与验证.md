## 1. 目标

P2 在 P1 智能抠像（自动 matte）基础上，增加**用户引导式**手动抠像：

- 用户在前端用画笔在视频某帧上涂抹**前景（白）/ 背景（黑）/ 橡皮（擦除）**，
  生成一张引导图（guide）；
- 引擎把 guide 解码为前景/背景 mask，做高斯羽化，得到一个灰度 matte 视频；
- 可选**基于已有的智能 matte 首帧做修正**（"refine"），让手动涂抹只纠正智能结果的局部错误；
- 手动生成的 matte 与 P1 智能 matte **共用同一条 `matteAssetId` 预览 / 导出链路**（与模式无关），
  因此导出逻辑零新增、只新增"如何得到 matte 视频"这一前端 + Python 分支。

设计原则：不引入任何新模型权重、不新增导出 filter 分支；只在"matte 来源"上扩展 `mode='manual'`。

## 2. 架构（复用 P1 桥接，仅加 manual 分发）

```
前端 KeyingTab.tsx  [手动] 模式
  └─ ManualPaintCanvas：透明 <canvas> 叠加 <video> 底图，画笔涂 fg/bg/橡皮
  └─ runManualKeying()：
        guide = paintCanvas.toDataURL('image/png')   // data:image/png;base64
        smartMattePath = 已有 matteAsset?.path (可选，用于 refine)
        aicut.keying.generate(assetPath, JSON.stringify({
            mode:'manual', guide, smartMattePath,
            threshold, softness, fps, output
        }))
       → 返回 {mattePath,duration,width,height,fps,frames,model:'manual',mode:'manual'}
       → 注册素材 + 回写 keying:{mode:'manual', model, threshold, edgeSoftness, matteAssetId}
            └─ preload.ts → main.ts ipcMain 'keying:generate'
                 └─ callEngine('keying', --mode manual, ...)
                      └─ Rust main.rs keying 子命令（"matte"|"manual" 均放行）
                           └─ src/keying.rs → spawn python/keying/bridge.py <input> <optsJSON>
                                └─ core.generate_manual_matte()
                                     └─ stdout 单行 JSON
```

桥接契约与 P1 完全一致：仅 stdout 输出**一行** JSON，其余日志走 stderr。
前端 `KeyingTab` **直接消费 `res.data`**（mattePath 等），绝不对返回值再 `JSON.parse`（详见 P1 文档 IPC 契约铁律）。

## 3. 数据契约

### matte 灰度视频约定（与 P1 同）
- `luma = 抠像值`：**0 = 背景，255 = 前景**（与 `applyMatte` 前端合成 / `geq` 导出曲线统一）。
- 尺寸 / 帧率 / 时长与源素材一致；逐帧写 N 帧灰度 mp4。

### guide 引导图约定（P2 新增，前端 → 引擎）
- 传输格式：`data:image/png;base64`（前端 `canvas.toDataURL('image/png')`）。
- 颜色语义：**RGBA 四通道**；以 **Alpha > 32** 判定"该像素被涂过"：
  - `A>32 && R>127` → **前景** mask；
  - `A>32 && R<=127` → **背景** mask；
  - `A<=32` → 未涂（透明，忽略）。
- 因此画笔涂"前景"用**不透明白**、"背景"用**不透明黑**、"橡皮"用 `globalCompositeOperation='destination-out'` 把该处 Alpha 擦回 0。

### KeyingConfig（P2 复用 P1 字段，模式值新增 `'manual'`）
```ts
mode?: 'chroma' | 'smart' | 'manual'
model?: 'modnet' | 'rmbg2' | 'manual'   // manual 模式固定 'manual'
threshold?: number                       // 前景判定阈值（共享 MatteAdjust 滑块）
matteAssetId?: string                    // 手动生成的 matte 视频对应素材 id
edgeSoftness?: number                    // 复用为边缘柔化带宽（同时作为羽化半径系数）
```

## 4. 实现要点

### 4.1 python/keying/core.py —— `generate_manual_matte(input_path, opts)`
- 顶部新增 `import base64 / import io / import numpy as np / from PIL import Image, ImageFilter`
  （统一放在文件末段，**不改动 `generate_matte` 以上任何代码**）。
- guide 解码：
  ```python
  ga = np.array(Image.open(io.BytesIO(base64.b64decode(b64))).convert("RGBA"))
  fg_mask = (ga[:,:,3] > 32) & (ga[:,:,0] > 127)
  bg_mask = (ga[:,:,3] > 32) & (ga[:,:,0] <= 127)
  ```
- base alpha（refine 模式）：若 `opts['smartMattePath']` 有效，用 ffmpeg 抽其首帧 gray、
  缩放至 guide 尺寸作为 base；否则 base 全 0。
- 合成：
  - `radius = max(0.5, softness * min(gw, gh) * 0.05)`（羽化半径，随柔化带宽与图尺寸缩放）；
  - `fg_f = _feather(fg_mask, radius)`、`bg_f = _feather(bg_mask, radius)`（高斯模糊做软边）；
  - `alpha = base * (1 - fg_f - bg_f) + fg_f`，`np.clip(0, 1)`；
  - 逐帧写回**源素材尺寸**的灰度 mp4（每帧同一张 matte，等价于"静态蒙版"随时间重复）。
- 返回 `{"mattePath","duration","width","height","fps","frames","model":"manual","mode":"manual"}`。

### 4.2 python/keying/bridge.py
- `from core import generate_matte, generate_manual_matte`；
- dispatch 加 `elif opts.get("mode") == "manual": result = generate_manual_matte(input_path, opts)`；
- 缺失 / 未知 mode → stderr 报错，返回非零（不污染 stdout JSON）。

### 4.3 Rust 放行点（四处一致）
1. `src/main.rs` keying 子命令：`"matte" | "manual"` 均进入 `keying_generate`；未知模式提示
   `(可用: matte, manual)`。
2. `src/lib.rs can_keying_via_graph`：`"smart" | "manual"` 分支，要求 `matte_asset_id` 命中；
   否则返回 false（回落完整路径）。
3. `src/graph.rs build_video_chain`：matte 输入索引条件
   `if k.enabled && (k.mode == "smart" || k.mode == "manual")`。
4. `src/graph.rs build_render_command`：收集 matte 额外 `-i` 条件同 (3)。
   > ⚠️ **铁律**：graph.rs 这两处必须**同步**改为 `smart || manual`。P2 开发早期只改了其中一处，
   > 导致导出图漏挂第二 `-i`、无 `alphamerge`、输出全 42.3（背景未抠）。修复后两端到端对齐。

### 4.4 前端
- `KeyingTab.tsx` 新增 `ManualPaintCanvas` 组件：
  - 绝对定位 `<video>` 作底图（当前帧 / 首帧）+ 透明 `<canvas>` 涂鸦层；
  - 前景 / 背景 / 橡皮三按钮（橡皮用 `destination-out`）；
  - 笔刷大小滑块；**撤销**（undoStack ≤ 12，存 ImageData 快照）+ **清空**；
  - `toDataURL('image/png')` 导出 guide。
- 抽出共享 `MatteAdjust` 组件（阈值 / 边缘柔化滑块），smart 与 manual 复用，走 `updateClipLive`。
- `runManualKeying()`：取画布 guide + 已有 `matteAsset.path`（作 `smartMattePath`）→ IPC →
  注册 asset + 回写 `keying:{...keying, mode:'manual', model, threshold, edgeSoftness:softness, matteAssetId:assetId}`。
- `WebGPUPreview.tsx` 智能合成分支条件改为 `mode === 'smart' || mode === 'manual'`。
- `PreviewCanvas.tsx`：`isSmart` 改名 `isMatte = !!(keying.matteAssetId && matteAsset && (mode==='smart'||mode==='manual'))`；
  两处依赖数组 / isKeying 条件同步放行 manual。

## 5. 验证

### 5.1 单元 / 构建
- `cargo build`：成功（仅 11 个既有 warning，无新增 error）。
- `tsc --noEmit` + `vite build`：干净（`dist/assets/index-*.js` 已更新）。
- `py_compile python/keying/core.py bridge.py`：通过。

### 5.2 手动 matte 生成（桥接实跑）
- 合成「绿底 + 肤色人形 blob」测试视频，用一张**前景全涂白、四角未涂**的 guide 跑
  `aicut-engine keying --mode manual --input ... --opts` → 返回合法 JSON，matte 视频生成。
- matte 单帧实测：**中心（前景）luma = 255.0（全不透明），四角（未涂）luma = 0.0（全透明）**。
  ✅ 证明 guide 解码 + fg mask 羽化 + 灰度写出正确。
- **基于智能蒙版修正（refine）**：同一 guide + 已有智能 matte 作 base，输出数值与 from-scratch 一致
  （中心 255 / 四角 0）。✅ 证明 refine 分支未破坏基础合成。

### 5.3 导出端到端（ffmpeg alphamerge）
- `aicut-engine export manual_subject_audio.json out_manual.mp4`（**带音轨源**，绕过已知无音轨 -22 缺口）→
  ✅ `rc = 0`。
- 输出单帧实测：**背景四角 avg RGB = 0.0（透明），前景中心 avg RGB = 42.7（保留）**。
  对照源绿屏帧 mean RGB = 42.3，证明 matte 正确全不透明、**背景完全抠除**、前景保留。
- render 图诊断：含第二 `-i`（matte）+ `[src][mt]alphamerge[va]`，与 P1 智能路径完全一致。✅

### 5.4 校准结论
| 项 | 源绿屏帧 | manual matte | 导出帧 |
|---|---|---|---|
| 背景（四角） | mean RGB ≈ 42.3 | luma = 0.0 | avg RGB = 0.0 ✅ 透明 |
| 前景（中心） | — | luma = 255.0 | avg RGB = 42.7 ✅ 保留 |

数据闭环证明：P2 手动抠像"画笔 → guide → matte 视频 → 预览/导出"全链路正确。

## 6. 已知限制 / 后续
1. **无音轨源导出崩溃（pre-existing，非 P2 专属）**：`graph.rs` 对 video 轨音频无条件引用 `[0:a]`，
   源无音轨则 ffmpeg 报 `-22`。验证时用带音轨源绕过；建议后续按 `ffprobe` 探测有音轨再挂音频链。
2. **桌面端 In-App 触发未自动点完**：Cua Driver 无法选中时间轴 clip、新构建下 `Ctrl+O` 未触发打开对话框，
   未能在 App 内一键跑完"手动涂鸦 → 生成蒙版"。桥接 / 导出 / 算法均独立实跑验证；
   建议用户在 App 内手动选「手动」模式涂鸦 → 点「生成蒙版」做最终复核（**改动涉及渲染层 + Rust 引擎，
   须彻底重启 AIcut 桌面端生效**）。
3. **guide 为静态单帧引导**：当前 guide 取自画布当前帧，matte 逐帧重复同一张（等价于静态蒙版）。
   后续可扩展"多帧关键帧 guide"做时序演化。
4. **refine 仅用智能 matte 首帧**：当前 base 抽首帧，未做逐帧 refine；后续可改为逐帧 base。
