## 五、启动前还需补的一项数据工程

当前 `SRVideoDataset` 是“从全部视频里均匀随机选”，这样 150 段的 6 个核心类会主导，`food/animal/art/urban` 虽然存在但占比偏低。

正式训练前建议实现：

1. **按类别均衡采样**
   - 每类先按类别等概率选择，再在类内随机选视频；
   - 避免 10 类中部分类只占极小采样比例。
2. **按类别 8:1:1 划分训练/验证/测试**
   - 每类保留 10% 做验证、10% 做测试；
   - 验证指标按类别输出 PSNR/SSIM/LPIPS。
3. **每类保留人工评测小样本**
   - 人像、文字/UI、屏幕录制、动物、艺术各留 5~10 段截图/短视频，供最终目检。

## 六、启动与验证步骤

1. 完成类别均衡采样与按类别切分。
2. 先跑 1000 轮验证：
   ```bash
   python python/sr/train.py --config python/sr/train_config_v1_x2.json ^
     --num_iterations 1000 --output_dir python/sr/checkpoints/v1_smoke
   ```
3. 确认 1000 轮无 NaN、无连续非有限 loss。
4. 启动正式 100K：
   ```bash
   E:\AIcut\scripts\run_sr_train.bat --config E:\AIcut\python\sr\train_config_v1_x2.json
   ```
5. 每 100 轮记录损失，每 5000 轮保存 checkpoint。
6. 全程用状态命令查看：
   ```bash
   E:\AIcut\scripts\sr_train_status.bat
   ```
7. 训练完成后导出 ONNX：
   ```bash
   python python/sr/export_onnx.py ^
     --model_path python/sr/checkpoints/v1_x2/model_g_100000.pth ^
     --output_path python/models/sr_v1_x2.onnx ^
     --scale 2
   ```
8. 用 SRTab 生成一段真实视频的超分结果，做端到端验证。
