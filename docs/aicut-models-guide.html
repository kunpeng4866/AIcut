AIcut 模型与 AI 功能使用说明（用户版）

写给「只想把视频剪好、不想关心底层技术」的你。本文用大白话解释：AIcut 里的每一个 AI 功能背后用了什么模型、要不要下载、去哪下载、需要什么条件，以及如果某个功能不好用，还有什么靠谱的替代产品。

先给结论（一眼看懂）：AIcut 的 AI 功能分两大类——
① 云端服务 需要联网 + 你自己的 API 密钥（如 DeepSeek、阿里云百炼、火山引擎），不用下载模型，软件帮你调用；
② 本地模型 需要把模型权重下载到本机（Python 环境 + ONNX 模型），下载后可离线用，但吃电脑配置。
下面逐项拆解。

二、逐个功能详解

① AI 剪辑建议 / 脚本生成 / 翻译底座

做什么用：这是 AIcut 的「大脑」。它帮你写口播稿、给剪辑建议、把字幕翻译成外语。翻译功能没有独立模型，就是借用这个大模型来翻。

用的是什么：默认 DeepSeek（模型 deepseek-chat），你也可以在设置里换成 OpenAI、通义千问、或任何兼容 OpenAI 接口的本地模型。

云端服务 需要 API Key

去哪获取：去 platform.deepseek.com 注册 → 充值（很便宜）→ 创建 API Key。把 Key 填进 AIcut 设置「AI 配置 → 大模型」。

必备条件：联网 + 有效的 API Key。无需下载任何模型。

DeepSeek 默认按量计费（每百万字约几毛到几元），写稿/翻译都会消耗额度。密钥只存在你本机，不会上传给软件作者。

② 语音转文字（自动字幕）

做什么用：把视频里人说的话自动变成字幕，省去手动敲字幕。

用的是什么：阿里云百炼的语音识别服务。可选模型：

  • qwen-audio-3.0-asr-flash-streaming（默认，中文/英文自动判别，效果好）
  • paraformer-realtime-v2（填 paraformer 也能用，百炼经典高精度模型，有免费额度）
  • 也支持本地 Whisper 兜底（需自己准备 Whisper 模型文件）

云端服务 需要百炼 API Key 同时需要本机 Python 运行时

去哪获取：阿里云百炼控制台开通「语音识别」权限，创建 API Key（以 sk- 开头），填进 AIcut 设置「ASR 配置」。

费用：以 paraformer-realtime-v2 为例，约 0.00024 元/秒，每月送 36000 秒（约 10 小时）免费额度，新人另有 90 天额外免费额度。

必备条件：① 百炼 API Key；② 本机必须装好 Python 运行时（见第五节）——因为字幕生成是靠本地 Python 桥接百炼接口完成的，光有 Key 没有 Python 跑不起来。

③ 语音合成（配音 / 朗读）

做什么用：把文字变成真人感的语音，用于给视频配音、做解说。

用的是什么（二选一）：

  • 火山引擎 TTS：音色多、质量高。需要 AppID + Access Token。
  • 百炼 CosyVoice：阿里系，默认模型 cosyvoice-v3.5-plus。只需要百炼 API Key 即可（与 ASR 可共用一个 Key）。

云端服务 需要对应平台密钥

去哪获取：火山引擎（volcano.cn）开通 TTS 拿到 AppID/Token；或百炼控制台开通 CosyVoice 模型权限并取 Key。

必备条件：联网 + 密钥。不需要下载模型、不需要 Python，是纯云端调用。

④ 字幕翻译

做什么用：把一条字幕轨整体翻译成别的语言，生成一条新的外语字幕轨（比如中译英、中译日）。

用的是什么：其实就是调用上面第①项的「通用大模型」来翻译，没有专门的翻译模型。支持 英 / 中 / 日 / 韩 / 法 / 德 / 西 等十余种语言。

云端服务 需要大模型 API Key

必备条件：与「AI 剪辑建议」同一个 Key 即可，无需额外配置。

⑤ 智能抠像（去背景 / 抠人像）

做什么用：把视频里的人或物体从背景里抠出来，方便换背景、做特效。

用的是什么（本地模型）：

  • MODNet（modnet.onnx，约 25.9 MB）：轻量快速，适合实时预览、发丝细节一般。
  • RMBG-2.0 / BiRefNet（rmbg2.onnx，约 1.02 GB）：精细去背景，边缘和发丝更干净，但很吃内存（峰值约 12 GB）。
  • 还有「手动抠像」模式：纯画笔涂抹，不用任何模型。

本地模型 下载后可离线用

去哪下载：软件内「AI 组件」面板一键补全即可自动下载（MODNet 走 HuggingFace 镜像，RMBG-2.0 走 ModelScope 国内镜像）。也可手动从对应开源仓库获取。

必备条件：① 本机 Python 运行时；② 上述 ONNX 模型；③ 有独显（N 卡 / A 卡 / Intel 核显均可）会快很多，没独显用 CPU 也能跑但慢。

这两个模型都是 Apache-2.0 开源协议，可免费用于个人与商业项目。

⑥ 视频超清增强（画质放大）

做什么用：把模糊 / 低分辨率的视频智能放大并修复细节（如 720p → 1440p），常用于老素材、录屏、手机拍摄的素材提质。

用的是什么（本地模型）：AIcut 自研的 RRDBNet 超分模型（sr_v0_test.onnx），放大倍率 2×。

本地模型 下载后可离线用

去哪下载 / 获取：该模型随完成版安装包内置；精简版当前暂不支持一键补全下载该模型（见下方「重要补充」），需用完成版或手动把 sr_v0_test.onnx 放到模型目录。

必备条件：① 本机 Python 运行时；② 该 ONNX 模型；③ 强烈建议独显（N 卡 CUDA 加速）——有独显几分钟出片，纯 CPU 会非常慢。

⑦ 口播自动剪辑（去口水话 / 人声分离）补充项

做什么用：录口播时总免不了「嗯、啊、那个、然后」之类的口头禅和停顿。这个功能自动分析语音，标出该删的废话片段；还能把人声和背景音乐分离（方便单独处理）。

用的是什么（本地）：Whisper（把语音转成文字、定位废话位置）+ Demucs（音轨分离）。二者都打包在 Python 环境里，无需单独下载。

本地模型 已内置在 Python 环境

必备条件：① 本机 Python 运行时；② Whisper/Demucs 已随环境附带。不另外要密钥。

这是很多用户「没想到但真有用」的功能：做知识口播、直播切片时，能省掉大量手动剪废话的时间。

三、下载与路径：完成版 vs 精简版，到底差在哪

AIcut 提供两种安装形态，核心区别就是「模型带不带」：

形态Python 运行时本地模型（抠像/超清）适合谁
完成版✅ 内置（解压即用）✅ 内置（resources/python、resources/models）想省事、一次装好全功能
精简版❌ 首次用 AI 时「一键补全」下载抠像模型可补；超清模型暂不可补硬盘小、只要基础功能

下载后文件落哪儿了？

无论哪种形态，软件按「内置目录优先，否则回退到下载目录」解析：

  • 完成版：模型在软件安装目录的 resources/python 和 resources/models 下。
  • 精简版一键补全：下载到系统的「用户数据目录」下 aicut-assets/，再细分：
    • Python 运行时 → aicut-assets/python/
    • 抠像模型 → aicut-assets/models/modnet.onnx、aicut-assets/models/rmbg2.onnx

（Windows 上「用户数据目录」一般是 C:\Users\你的用户名\AppData\Roaming\应用名\aicut-assets\，软件会自动管理，你通常不需要手动找。）

想确认自己缺什么：打开 AIcut → 顶部「AI 组件」面板，会列出 Python / MODNet / RMBG-2.0 的就绪状态，缺哪个点一下就自动下载。

六、常见问题 FAQ

  • Q：为什么我填了百炼 Key，自动字幕还是报错？
    A：九成是因为没装 Python 运行时（完成版自带；精简版去「AI 组件」点补全）。其次确认在百炼控制台「开通了 paraformer 模型权限」。
  • Q：这些模型下载下来会很大吗？
    A：Python 运行时压缩包约 1.8 GB（解压约 3.1 GB），RMBG-2.0 约 1 GB，MODNet 仅 26 MB，超清模型约 35 MB。完成版一次带齐约 4~5 GB。
  • Q：没有独显能用本地模型吗？
    A：能。抠像用 CPU 也能跑（只是慢，RMBG-2.0 单帧可能几秒）；超清强烈建议独显，否则一段视频可能要几十分钟。云端功能（字幕/配音/AI/翻译）与显卡无关。
  • Q：我的密钥安全吗？
    A：所有云端 Key 只存在你本机配置文件里，软件不内置任何密钥、也不上传。完成版把模型都打进安装包，但绝对不含你的密钥。
  • Q：能完全离线用吗？
    A：本地模型（抠像/超清/口播剪辑）下载后可离线。但字幕、配音、AI、翻译都依赖云端 API，必须联网。

七、重要补充提醒（容易踩坑）

⚠️ 超清增强模型（sr_v0_test.onnx）当前仅完成版内置。精简版的「一键补全」清单里还没有收录超清模型，所以精简版用户暂时用不了超清，或需手动把模型文件放到 aicut-assets/models/ 目录。若你很依赖超清，请直接装完成版。

显存 / 内存提醒：RMBG-2.0 精细抠像推理峰值约 12 GB 内存；超清增强建议 6 GB 以上显存的独显才能流畅。低配电脑建议用 MODNet（轻量）而非 RMBG-2.0。

GPU 兼容性：本地模型用的是 ONNX Runtime，会自动在 CUDA（N 卡）→ DirectML（Win 自带，兼容 A 卡 / Intel / N 卡）→ CPU 之间择优。也就是说不限 N 卡，AMD 和 Intel 显卡也能加速，实在没有独显再退回 CPU。
