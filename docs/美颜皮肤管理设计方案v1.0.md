# AIcut 美颜「皮肤管理」设计方案 v1.0

> 范围：仅做「皮肤管理」，不做美体/五官塑形/美妆。
> 合规红线：**全部采用自研算法与自研模型，禁止直接套用第三方预训练模型 / 商业 SDK（如 MediaPipe、ABPN、ModelScope 皮肤修复模型、剪映同款商业方案）**，避免专利与著作权侵权。
> 日期：2026-07-30
> 硬件基准：RTX 5060 Ti 16GB（Blackwell, sm_120），Win11，DML 可用，CUDA EP 不可用。

## 0. 知识产权与防侵权策略（最高优先级）

| 类别 | 策略 |
|------|------|
| 人脸/皮肤定位 | **自研**：肤色空间分割 + 椭圆拟合，**不引入** MediaPipe / RetinaFace / InsightFace / Dlib |
| 磨皮/美白/清晰/肤色 | **自研**：双边/引导滤波、频率分离、Unsharp、LUT 均为公开数学算法（公有领域思想），自行实现 |
| AI 匀肤/祛瑕 | **自研或延后**：若做 AI，必须基于自有/已授权数据训练自研 U-Net，**不下载** ABPN、cv_unet_skin-retouching 等他人权重 |
| 调色 LUT | **自研**：自行设计 5 套肤色映射曲线，不搬运商业预设 |
| 参考来源 | 调研报告仅用于理解领域概念（能力分层、参数语义），**不复制**其具体实现代码/模型结构 |

> 说明：滤波/色彩变换类算法属于数学方法，思想本身不受版权保护，自行编码实现不侵权；真正有风险的是「直接调用他人模型权重 / SDK / 商业预设」。本方案一律规避。

## 1. 目标与能力分层

在 AIcut 现有 clip 级效果体系（类似 keying）里，新增一套**非破坏、可关键帧、可预览、可导出**的「皮肤管理」能力。

| 功能 | 本期 | 阶段 | 自研方案 |
|------|------|------|----------|
| 磨皮 | ✅ | M1 | 自研双边滤波 / 频率分离 |
| 美白 | ✅ | M1 | 自研亮度/饱和度调整 |
| 肤色 | ✅ | M1 | 自研 5 套 LUT |
| 清晰 | ✅ | M1 | 自研 Unsharp Mask |
| 匀肤 | ⚡ | M3（自研） | 自研轻量 U-Net，需自有数据训练 |
| 祛斑祛痘 | ⚡ | M3（自研） | 自研瑕疵检测 + 自研纹理合成 |
| 祛法令纹 | ❌ | 延后 | 跨帧一致性与结构形变难，暂缓 |
| 祛黑眼圈 | ⚡ | M3（自研） | 自研 ROI 提亮 |
| 丰盈 | ❌ | 不做 | 脸型/五官形变，超出皮肤管理范围 |
| 多人脸 | ❌ | 延后 | M1 只处理主脸区域 |

## 2. 总体架构（无第三方模型依赖）

```
前端 BeautyTab（参数面板）
        ↓ 写 ClipConfig.beauty
   预览：WebGPU shader（ 自研皮肤分割 → skin mask → 实时美颜 ）
        ↓ 点「应用」
   后端 Python：生成 skin_mask.mp4（M1 纯几何/色彩算法，无模型）
        ↓ 资产回写 project.assets
   导出 Rust：graph.rs 读取 mask 资产，拼入 ffmpeg filtergraph
```

- 预览快：皮肤分割用纯色彩/几何算法（CPU 极轻），美颜用 WebGPU shader。
- 导出稳：skin mask 是灰度视频资产，Rust 像 matte 一样用 `movie=` 引入。
- AI 高阶（M3）才引入自研模型，且权重由我们自己在授权数据上训练。

## 4. M1 基础皮肤管理（全自研，零模型）

### 4.1 自研皮肤 Mask 生成（**不使用人脸检测模型**）

利用肤色在 YCbCr / HSV 空间的聚类特性 + 几何约束，**纯公开算法**实现：

1. **肤色阈值**：YCbCr 空间规则（Cb∈[77,127], Cr∈[133,173], Y>20），或 HSV（H∈[0,25]∪[340,360], S∈[0.2,0.8]）。取二者并集提高鲁棒性。
2. **形态学去噪**：open(3×3) + close(5×5)。
3. **主区域提取**：保留画面中央最大的若干连通域（人脸通常在中心），丢弃四肢/背景误检。
4. **椭圆拟合**：对主肤色 blob 做最小外接椭圆，约束长宽比（人脸 ~0.75~0.85）剔除误检。
5. **眼/嘴挖洞（可选）**：椭圆内检测明显暗区（眼窝/嘴）并排除，避免把眼睛磨掉；M1 可简化为仅保留椭圆整体。
6. **羽化**：高斯模糊 8~15px，输出 8bit 灰度 mask（255=全作用）。

> 优点：无模型、无第三方依赖、毫秒级、完全合规。局限：极端光照/手套/大面积同色背景可能误检，可通过用户「蒙版强度」滑块 + 手动擦除（复用抠像涂鸦 UI 思路）兜底。

### 4.2 磨皮（自研）

**预览**：WebGPU 双边滤波 fragment shader（sigmaS 随滑块 1~12，sigmaR 0.05~0.25）。
**导出**：ffmpeg `bilateral` filter（其算法为公有领域方法，自行可调）。

```
[0:v]bilateral=sigmaS=6:sigmaR=0.15[smoothed]
```

滑块映射：
- 0-30：轻度双边（sigmaS 2~5）
- 30-70：双边 + 频率分离混合（自研：高频抑制系数随滑块增大）
- 70-100：强双边 + 较强高频抑制

**自研频率分离**（可选增强）：`I_detail' = clamp(I_detail × α, -ε, ε)`，`α` 由滑块控制，重建 `I_base + I_detail'`。

### 4.3 美白（自研）

**预览/导出**：ffmpeg `eq` 在 YUV 空间调亮度/饱和度，仅作用于 mask 区域。

```
[0:v]eq=brightness=0.08:saturation=0.92[whitened]
```

滑块映射：brightness -0.05~0.25，saturation 0.85~1.0（降饱和防惨黄）。

### 4.4 清晰（自研）

**预览/导出**：Unsharp Mask（`unsharp` filter，公有领域算法）。仅 mask 区域生效。

```
unsharp=luma_msize_x=5:luma_msize_y=5:luma_amount=1.2
```

### 4.5 肤色（自研 LUT）

**完全自研 5 套映射曲线**（不搬运任何商业预设），用 ffmpeg `lutrgb` 或自研 WebGPU LUT：

| 预设 | 自研作用 |
|------|----------|
| none | 原色 |
| cool 冷白 | 减黄、加蓝 |
| natural 自然 | 微提亮 |
| warm 暖白 | 加红、加黄 |
| wheat 小麦 | 整体降亮、加棕 |
| bronze 健康古铜 | 加橙、加暗部对比 |

### 4.6 M1 预览 Shader 管线

```
输入帧 RGB
  ↓ 自研肤色分割（每 3 帧算一次 mask，中间帧复用+位置插值）
  ↓ 按参数：①双边磨皮 ②美白 ③肤色LUT ④unsharp清晰
  ↓ 与原始帧按 mask alpha 混合
输出 RGB
```

> 性能目标：720p 预览 ≥ 25fps（分割极轻，shader 并行）。

## 5. M3 高阶 AI（**明确为自研，不采用第三方模型**）

> 仅在用户确认需要且愿意投入训练数据时启动。以下为架构预留，**默认延后**。

### 5.1 自研路径（合规前提）
- **数据**：收集自有/已授权人像对（原图 + 人工修图），不爬取商业平台。
- **模型**：自研轻量 U-Net（Encoder-Decoder + Skip），参考公开论文思想自行实现，权重自己训练。
- **推理**：onnxruntime-directml（DML EP），输出修复后 RGB。
- **导出**：生成 `beauty_asset.mp4`，Rust 用 mask 与原始帧混合。

### 5.2 祛黑眼圈（自研 ROI）
- 椭圆内下方 1/3 区域判定为眼下区，Lab 空间提亮 + 减青，羽化边界。纯几何/色彩，无模型。

### 5.3 祛斑祛痘（自研）
- 自研瑕疵检测：mask 区域内检测局部高频异常点（比周围皮肤暗/亮且面积小）→ 自研纹理合成（从周围采样）填充。非 GAN、非第三方。

> **禁止项**：ABPN、ModelScope `cv_unet_skin-retouching`、LaMa、DeepFill 等他人权重一律不下载、不调用。

## 6. 导出 filtergraph（Rust）

### 6.1 M1 基础
```
[0:v] 原视频
[1:v] skin_mask.mp4（灰度）

[0:v]split=2[orig][orig_for_mask]
[1:v]format=gray,scale=W:H[mask]

[orig]bilateral=... [smoothed]
[smoothed]eq=brightness=...:saturation=... [toned]
[toned]lutrgb=... [lut]
[lut]unsharp=... [beauty_full]

[beauty_full][orig_for_mask]alphamerge [beauty_rgba]
[beauty_rgba][mask]blend=all_mode=overlay:all_opacity=1 [output]
```
> 关键：mask 必须 `scale` 到同分辨率，否则 alphamerge 协商失败（与 keying 一致）。

### 6.2 M3 AI
```
[0:v] 原视频
[1:v] beauty_asset.mp4（自研模型修复）
[2:v] skin_mask.mp4
[1:v][2:v]alphamerge [beauty_rgba]
[0:v][beauty_rgba]blend=all_mode=overlay [output]
```

## 8. 工程实现步骤

### M1：基础皮肤管理（2~3 周）
1. 类型与配置：`BeautyConfig` 落 types.ts + Rust；clip schema 扩展。
2. 皮肤 Mask 资产：Python `python/beauty/generate_skin_mask.py`（自研肤色分割，无模型）写 gray mp4；新增 IPC `beauty:generateMask`。
3. 前端面板：`BeautyTab.tsx`（仿 KeyingTab），4 滑块 + 肤色预设。
4. 预览：WebGPU 自研肤色分割 + fragment shader（双边/美白/LUT/unsharp）。
5. 导出：Rust `graph.rs` `build_beauty_spec`（M1 filtergraph）。
6. 验证：720p 预览 ≥ 25fps；导出抽帧确认仅皮肤区域变化。

### M3：自研 AI（待用户拍板，默认延后）
1. 若启动：自建数据集 + 自研 U-Net 训练（自有/授权数据）。
2. onnxruntime-directml 推理导出 `beauty_asset.mp4`。
3. 祛黑眼圈/祛斑自研几何+色彩方案。
