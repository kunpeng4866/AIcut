## 第一部分：项目进展摘要

### 1.1 项目定位

AIcut = 类剪映的视频编辑器，Rust (N-API) + TypeScript 架构。
核心数据流：`TS Project JSON → Rust 解析 → FilterGraph 构建 → FFmpeg 命令 → 渲染输出`。

### 1.2 实际完成度（代码盘点）

| 层级 | 设计预期 | 实际状态 | 差距 |
|------|---------|---------|------|
| GUI（Electron+React） | apps/desktop/ | **不存在** | P0 |
| AI 接口层（MCP Server） | apps/mcp-server/ | `src/mcp.rs`（231行骨架） | 部分 |
| 编排层（命令总线） | packages/core/ | **不存在** | P0 |
| UI 组件（面板/时间轴） | packages/ui/ | **不存在** | P0 |
| AI Provider（TTS/ASR/抠像） | packages/ai/ | `src/provider.rs`（237行抽象） | 部分 |
| TS Schema | packages/schema/ | **不存在** | P0 |
| Rust 引擎 | packages/engine/ | `src/`（14文件, 2806行） | **已实现** |
| CLI | cli/ | `src/main.rs`（96行） | 已整合 |

**结论：当前产物 = Rust 引擎核心（约完整架构的 25%），前端/UI/编排层全缺。**

### 1.4 关键问题（来自审计报告）

- **P0**：GUI/编排层/UI/AI Schema 全缺；代理生成逻辑未实现（Phase 4 核心收益未达成）
- **P1**：`filters.rs` ↔ `project.rs` 准循环依赖；`build_render_command` 不返回 Result（unwrap 会 panic）；素材找不到时静默用索引 0
- **P2**：输入去重逻辑重复；单音轨无 -map 隐患；错误类型丢失
- **环境**：N-API 依赖被条件编译移除（待网络恢复激活）

### 1.5 剪映本地资源情况

- `D:\JianyingPro\` 下仅 `JianyingPro Materials\`（空）和 `JianyingPro Presets\`
- `CombinationPresetVirtualStore.json` 是**空壳**（type 0/1 均为空数组）
- **结论：剪映的特效/素材/滤镜均为云端拉取，本地无可提取的资源包**
- 需另寻途径（实地操作截图、网络抓包、官方文档）

## 第二部分：调研计划（待审核）

### 调研依据

`deepseek剪映资料复刻.txt` 的 4 个问答提示了以下方向：
1. **问答一**：直接逆向（资源提取）、核心算法（火山引擎SDK/专利论文/开源复刻）、行为逻辑（功能矩阵）、风险规避
2. **问答二**：多轨道渲染管线（数据层区间树 + 调度层双管线 + 执行层并行解码/合成器/音频独立管线）
3. **问答三**：特效素材热更新（.vfx 包格式 + 云端分发 + 本地安全加载 + 引擎集成）
4. **问答四（提示）**：安全的着色器运行时（静态扫描 + 性能校验 + uniform 注入 + 跨平台）

### 调研项清单

#### 调研项 R1：剪映功能矩阵构建（对应问答一·行为逻辑）
- **目标**：建立 AIcut 需要复刻的完整功能清单（含优先级）
- **方法**：
  - 实地操作剪映，按工作流截图记录：新建项目 → 素材导入 → 分割/裁剪/旋转 → 多轨道 → 转场/滤镜/特效
  - 记录关键交互：磁吸吸附、键盘快捷键、右键菜单层级、自动保存/草稿管理
  - 与 AIcut 现有能力逐项比对，标注"已有/部分/缺失"
- **产出**：`功能矩阵.md`（功能项 × 优先级 × AIcut现状 × 实现建议）
- **执行方**：子代理（需访问剪映实机，**需用户协助提供操作环境或截图**）

#### 调研项 R2：多轨道渲染管线架构设计（对应问答二）
- **目标**：设计超越当前"单次FFmpeg命令构建"的实时渲染管线
- **方法**：
  - 调研区间树/平衡BST 在时间线查询中的应用（Rust crate 选型）
  - 设计双管线：高质量导出管线（零丢帧）+ 低延迟预览管线（降级/跳帧）
  - 并行解码器设计（硬解优先 + LRU 预解码缓存）
  - 合成器层级设计（逐轨道从下至上：变换→不透明度→遮罩混合→Over合成）
  - 音频独立管线（重采样 → 音量/特效 → 多路混音 + 限制器）
  - 与 Phase5 WebGPU 预览方案衔接（预览管线复用代理 720p）
- **产出**：`渲染管线设计.md`
- **执行方**：子代理（基于公开资料 + 项目现有架构）

#### 调研项 R3：特效素材热更新系统设计（对应问答三）
- **目标**：设计 AIcut 的特效包格式与云端热更新机制
- **方法**：
  - 定义 `.aifx` 包格式（zip + manifest.json + shader + assets）
  - manifest.json 规范：ID/版本/分类/gpu_tier/animation/parameters/兼容性
  - 云端分发：资源清单 + 按需下载 + 后台预加载 + 版本管理/热修复
  - 本地安全加载：沙箱隔离 + 签名校验 + LRU 清理 + 资源锁定
  - 引擎集成：查找→挂载→编译预热→运行时渲染
- **产出**：`特效热更新设计.md`
- **执行方**：子代理（基于公开资料 + 项目现有 mcp.rs/provider.rs）

#### 调研项 R4：着色器安全运行时设计（对应问答四提示）
- **目标**：构建安全的着色器加载与运行机制（支撑 R3）
- **方法**：
  - WGSL 着色器静态扫描规则（禁止写入纹理/死循环/系统调用）
  - 编译时性能校验（超时检测）
  - uniform 变量注入规范（时间/分辨率/参数）
  - 跨平台兼容性（WGSL for WebGPU，Phase5 已规划）
  - 与 Phase5 effects.wgsl.ts 衔接
- **产出**：`着色器运行时设计.md`
- **执行方**：子代理（基于 WebGPU/WGSL 公开规范）

#### 调研项 R5：火山引擎SDK与开源复刻调研（对应问答一·核心算法）
- **目标**：了解剪映底层能力来源，找到可参考的开源实现与技术选型
- **方法**：
  - 火山引擎智能媒体套件公开文档（视频编辑/特效/美颜 SDK）
  - GitHub 搜索：剪映复刻 / jianying clone / video editor / 曲线变速 / 色度抠图
  - 检索字节跳动/脸萌科技专利（视频处理/图像分割/音频节拍检测）
  - arXiv 前沿论文（视频理解与生成）
- **产出**：`技术选型参考.md`
- **执行方**：子代理（网络搜索）

#### 调研项 R6：AIcut 现状对齐与开发优先级（综合）
- **目标**：综合 R1-R5，明确 AIcut 下一步开发路线图
- **方法**：
  - 审计报告 P0/P1 问题梳理
  - 已有模块（MCP/Provider/字幕/关键帧/曲线变速）能力盘点
  - Phase5 WebGPU 预览与 R2 渲染管线的衔接方案
  - N-API 恢复计划（网络可用后）
- **产出**：`开发路线图.md`
