三、你可能会遇到的坑，以及怎么解决

提前把高频问题列出来，照着做基本都能解开：

1. 高级抠图要下载模型，在哪点？

软件里打开「AI 组件 / 资产」面板，会看到 RMBG-2.0 模型的下载入口，链接已经内置好，不用你自己去网上找。点一下就下载，下载完自动启用。首次用会慢一点（约 1GB），之后就不用再下了。

解决路径：AI 组件面板 → 找到"高级抠图模型" → 点击下载 → 等进度条走完即可。

2. 模型下载卡住 / 失败怎么办？

多为网络波动。软件支持断点续传，关掉重开再点一次通常会接着下载；大文件下载中途断了不会从头来。

解决路径：检查网络 → 重新打开下载面板 → 重试；仍失败可换个网络时段再试。

3. 语音转文字 / AI 配音要配置什么？

这类云端 AI 功能需要你到对应平台（阿里云百炼 / 火山引擎）注册一个账号，拿到一串"密钥（API Key）"，填进软件的「AI 配置」里。密钥只存在你自己的电脑上。

解决路径：注册平台账号 → 创建 API Key → 软件「AI 配置」粘贴保存 → 即可使用。第一次配置约花 5 分钟。

4. 我没有 N 卡（用的是 AMD / Intel 显卡）能跑吗？

能。本地 AI 推理会自动适配：有 N 卡走 CUDA 加速，没有就走 DirectML，AMD / Intel 显卡照样能加速，实在不行还能用 CPU 跑。也就是说，不是非得买高端显卡。

解决路径：直接安装使用，软件会自动选最合适的运行方式，无需手动设置。

5. 软件体积有点大（完整版好几个 G）？

因为它把 Python 运行环境和基础 AI 模型都打包进去了，这样你下载后不用再折腾环境，双击就能用。体积换来的是"省心"。

解决路径：接受一次性下载大文件；后续若出精简版会再说明。

6. 导出很慢 / 卡顿？

导出速度和视频分辨率、是否开启 AI 功能有关。开独显加速会快很多；超长、高清视频本身就需要时间，属正常现象。

解决路径：确认用独显；先导出一小段测试；关掉暂时不需要的 AI 处理再导出。

你填的每一张平台密钥（API Key），都只保存在你本机的配置文件里，AIcut 不会内置任何密钥，也不会把你的密钥上传到任何服务器。再加上代码开源，任何人都能审计它到底干了什么——这比闭源商业软件更透明。

所有视频剪辑、本地抠图、口播处理，都是在你自己的电脑上完成，素材不会离开你的机器。只有你主动开启的云端 AI 功能（比如"云端配音"），才会把对应的文本/音频发给对应服务商——这是这类功能本身的工作原理，且你可以完全不用它们。
