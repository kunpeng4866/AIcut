AIcut 配置不求人：手把手接入阿里云百炼的语音识别与配音

Paraformer 实时语音识别 + CosyVoice 声音复刻配音

上篇文章我介绍了 AIcut 都能做什么——自动字幕、AI 配音、口播剪辑、智能抠像……这篇专门讲一件事：软件是免费的，但怎么把它真正用起来。核心就是接好两个云端 AI 模型。

一、先搞清楚：要配哪两样东西

AIcut 用到的语音能力，都来自阿里云百炼，而且共用同一个 API Key：

能力 用在哪 百炼模型
语音识别 ASR 语音自动转字幕 paraformer-realtime-v2
语音合成 TTS 文字变成你的声音配音 cosyvoice-v3.5-plus

你只需要准备两样：① 一个百炼 API Key（两个功能通用）；② 想用配音时，再加一个你复刻的声音 ID。软件具体功能看我上一篇文章。

二、第一步：拿到阿里云百炼 API Key（必做，两个功能都靠它）

1. 打开 bailian.console.aliyun.com，用阿里云账号登录（没账号先注册，要做实名认证，不然建不了 Key）。

2. 第一次会弹出"开通百炼服务"，点开通（免费，会自动送一笔试用额度）。

3. 页面右上角点你的头像 / 齿轮 → 选择「API-KEY」。

4. 点「创建 API-KEY」→ 选「默认业务空间」→ 创建。

⚠️ 关键：创建后那串 sk-... 密钥只显示这一次！马上复制保存到备忘录，关掉就再也看不到了。

三、第二步：在 AIcut 里配「语音识别（字幕）」

1. 打开 AIcut，点右上角「AI 配置」（首次启动也会自动弹配置向导，选到"语音识别"那一步即可）。

2. 语音识别(ASR) 的「服务商」选 阿里云百炼。

3. 「API Key」处粘贴刚才复制的 sk-...。

4. 「模型」下拉里选 paraformer-realtime-v2（实时·词级时间戳，字幕对齐最准）。

5. 「接口地址」留空就行（自动用百炼默认地址）。

到这儿字幕功能就通了——给视频加字幕时选「AI 自动字幕」就会调用它。

四、第三步：在百炼网页上"复刻"你的声音（配音的前提）

⚠️ 最重要的一点：AIcut 里没有"造声音"的按钮。必须先在百炼网页上把你的声音复刻好，再把声音 ID 抄回 AIcut。

复刻声音的路径（一步步照着点）：

阿里云百炼 → 模型广场 → 语音模型 → 语音合成 → 声音复刻 → 复刻声音 → 选择复刻及合成模型 → 设置音色名 → 开始复刻

上传一段 10~20 秒你自己的原声（环境安静、少杂音），等几分钟复刻完成。

找到你的声音 ID：

阿里云百炼 → 模型广场 → 语音模型 → 语音合成 → 我的复刻 → 在声音名称旁边那一栏就是「ID」，复制它。

这个 ID 长这样：cosyvoice-v3.5-plus-bailian-xxxxxxxx，它是绑定模型家族的，别选错模型去复刻。

五、第四步：在 AIcut 里配「语音合成（配音）」

1. 还是「AI 配置」里，切到 文字转语音(TTS)。

2. 「服务商」选 阿里云百炼 CosyVoice。

3. 「DashScope API Key」填同一个 sk-...。

【最关键一步】「默认音色 voice（复刻音色 ID）」这里，粘贴第三步复制的 ID。别留空、别用占位符，否则配出来不是你的声音。

4. 「模型」留默认 cosyvoice-v3.5-plus。

配置完，在文字 / 字幕素材上点「AI 配音」，就会用你自己的声音生成配音。

六、三个最容易踩的坑

❌ 配音出来不是我的声音？ → 第一反应查「默认音色 voice」是不是空着或抄错。它留空不会报错，但会悄悄用内置女声。

❌ 找不到声音 ID？ → 它在百炼网页"我的复刻"里，不在 AIcut 里生成；AIcut 只能"填"，不能"造"。

❌ API Key 丢了 / 想换？ → 百炼后台"API-KEY"里可以禁用或重置，旧的就废了，重新建一个新的即可。
