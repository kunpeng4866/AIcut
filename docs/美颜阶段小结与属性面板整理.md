# 美颜阶段小结与属性面板整理

> 基于 2026-07-31 用户反馈：美颜当前效果不满意，先做阶段小结并封存；同时根据三张截图（文本/视频/音频选中后右侧面板）对已有属性做分层归类，减少凌乱堆砌感。

---

## 一、美颜模块阶段小结

### 1.1 目标回顾
美颜 M1 目标：在**不依赖第三方人脸/关键点/美肤模型**的前提下（防侵权硬约束），实现可实战的"皮肤管理"——对皮肤区域单独做磨皮、美白、清晰、肤色调整，且不出现明显的遮罩抖动或背景泄漏。

### 1.2 已交付内容
- **数据模型**：`BeautyConfig`（`enabled / smoothing / whitening / clarity / skinTone / maskAssetId`）。
- **前端面板**：`gui/src/components/panels/BeautyTab.tsx`
  - 磨皮/美白/清晰 0–100 滑块、肤色预设（none/cool/natural/warm/wheat/bronze）。
  - 「生成皮肤遮罩」按钮 + 覆盖率提示。
  - 关键帧支持：`KF_PROPS` 已加入 `beauty.smoothing / whitening / clarity`。
- **预览**：`gui/src/utils/beautyRender.ts` 在 WebGPU/Canvas 预览中按 mask luma 混合美颜后画面。
- **后端生成**：`python/beauty/core.py` + `bridge.py`
  - 自研肤色检测：YCbCr/HSV 阈值 → 连通域 → 空间先验（椭圆二阶矩软加权，不再拟合实心椭圆）→ 形态学闭运算 → 高斯羽化 → **滑动窗口时序中值滤波**（`temporal_window` 默认 7）。
  - 输出灰度 `skin_mask.mp4`（luma = mask * 255）。
- **后端导出**：`src/filters.rs build_beauty_spec` + `src/graph.rs`
  - 用 `alphamerge` + `overlay` 按 mask luma 合成美颜效果（已规避 `maskedmerge` 全局泄漏问题）。
  - 支持美颜参数关键帧：分段烘焙 smoothing/whitening/clarity。
- **提交**：`963cfb0`（2026-07-31）。

### 1.3 验证数据（用户指定真人视频）
| 场景 | 覆盖率 | 右侧同色墙面泄漏 | 逐帧质心抖动 | bbox 宽抖动 | 备注 |
|---|---|---|---|---|---|
| 6s 片段（1280×720/30fps） | ~32% | ≈0% | 2.8px | ±12px | 脸型轮廓，非椭圆 |
| 全片 73.8s | 23.2% | ≈0% | — | — | 2214 帧稳定无漂移 |

### 1.4 为什么不满意 / 封存原因
1. **效果本身仍偏保守**：M1 仅做传统图像处理（双边滤波磨皮、直方图均衡美白、unsharp 清晰），没有高阶匀肤/祛斑/黑眼圈，真人出镜时"磨皮感"和"肤质提升"不明显。
2. **肤色检测仍有边界瑕疵**：虽然消除了"椭圆摆动"和墙面泄漏，但在侧脸、低头、手遮脸、光线突变时，mask 边缘仍可能收缩/扩张不自然。
3. **响应与体验**：生成 mask 需要数秒到数分钟（本机 DML ~0.6s/帧），对长视频不友好。
4. **M3 高阶方案需延后**：自研 U-Net 匀肤/祛斑模型需要自有/授权人像数据集训练，本期不具备条件。

### 1.5 封存结论
- **当前 M1 代码保持可用**，不再继续调参。
- **美颜入口保留在属性面板**，但标记为"皮肤管理"，避免用户误以为是完整美颜美体。
- **后续重启开发时机**：
  - 具备自研/授权人像训练数据后，再启动 M3 自研模型（匀肤、祛斑、黑眼圈）。
  - 或先引入更高效的肤色/人脸空间先验（仍然禁止第三方预训练模型）。

## 二、属性面板整理：按截图分层结构归类

### 2.1 现状与目标结构对比

**当前代码实现**（`gui/src/components/PropertiesPanel.tsx`）：
- 扁平 13 个顶层 tab：`变换 / 滤镜 / 特效 / 音频 / 变速 / 转场 / 文字 / 字幕 / 关键帧 / 插件 / 蒙版 / 抠像 / 美颜`。
- 对几乎所有 clip 类型通用；音频轨仅隐藏 `蒙版 / 抠像 / 美颜`。

**截图目标结构**：按素材类型分一级 tab，同一类型下再分子 tab。

```
文本素材：          文本 / 动画 / 跟踪 / 朗读 / 数字人
视频/图片素材：     画面 / 音频 / 变速 / 动画 / 调整 / AI效果
音频素材：          基础 / 换音色 / 声音效果 / 变速 / 改词翻唱
```

下面把**已开发**的属性按目标结构重新归类，并标注真实落地状态。

## 三、建议的整理动作（不立即开发，先作为方案）

1. **统一入口命名**：把现有扁平 tab 按素材类型收敛。
   - 文本 clip 只显示：文本 / 动画 / 跟踪 / 朗读 / 数字人。
   - 视频/图片 clip 只显示：画面 / 音频 / 变速 / 动画 / 调整 / AI效果。
   - 音频 clip 只显示：基础 / 换音色 / 声音效果 / 变速 / 改词翻唱。

2. **合并重复入口**：把 `滤镜 / 特效 / 插件` 合并到「调整」tab 的二级面板里；转场并入「动画」tab。

3. **删除/隐藏纯占位项**：声相（clip 级）、降噪、变声等若短期不实现，先从 UI 隐藏，避免用户以为能用。

4. **把 AI 能力迁回对应素材类型**：
   - 朗读 / TTS → 文本 tab。
   - AI 字幕 / 口播剪辑 → 音频 tab 或视频 AI效果 tab。
   - 智能抠像 → 视频画面 tab。

5. **美颜命名收敛**：把「美颜」tab 改名为「美颜美体」，当前只展示「皮肤管理」分组；美体/五官塑形明确标注"后续开发"。
