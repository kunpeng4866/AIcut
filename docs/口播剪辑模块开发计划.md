## 0. 目标

在 AIcut 中新增「口播剪辑」功能模块：用户**在时间轴选中一段视频或音频片段** → 点「口播剪辑」→
自动完成**静音/停顿删除 + 语气词废话删除 + （可选）降噪/去齿音/响度归一 + 声学咳嗽/气声判别** →
生成清洗后的**新片段非破坏入轨**（原片段保留，可 A/B 对比）。

## 2. demand-miner 明确缺失的功能（列入开发计划）

以下能力 W1 **代码里完全没有实现**，移植时需在 AIcut 侧补齐或作为已知边界标注：

1. **节奏 / 卡点自动分析** —— 全代码无 beat/节奏检测；设计文档描绘的「智能卡点」无对应实现（仅 `w1_dream.py` 占位）。
2. **语速分析与自动变速** —— 无说话速率计算，无按语速自动加速/平滑。
3. **批量处理多文件** —— `run(input_path)` 仅单文件；无批量/队列入口。
4. **前端 / UI 与文本级可视化编辑** —— 纯 CLI；编辑仅支持 `--exclude 起点-终点` 时间区间，**无字幕式「改文本→回写时间轴」闭环**（ASR 单向）。
5. **视频精细同步切割 / 画面智能处理** —— 视频仅做 ffmpeg 基础 trim+concat 重混音；无镜头切换检测、无画面级优化（AIcut 侧需用自身能力补「音视频同步切割」）。
6. **大样本 / 多口音泛化验证** —— README 验证状态自承 [ ] 未完成，鲁棒性未充分证明。
7. **实时进度反馈** —— CLI 仅 print，无结构化进度；长音频 whisper CPU 推理慢且无进度回调（AIcut 必须补 IPC 进度）。

> 移植策略：v1 不包含缺失项 1/2/3（作为后续 Phase 7+）；但 **4/5/7 必须在 v1 中由 AIcut 侧补齐**（UI 编辑、音视频同步切割、进度反馈），否则模块不可用。

## 3. 架构设计（analyze / assemble 分离）

```
选中时间轴 clip ──► SpeechPanel(左 tab)
        │  inputPath + SpeechEditOptions
        ▼
 window.aicut.speech.analyze()  ──► Rust `speech --mode analyze`
        │                               └► spawn 托管 Python 跑 W1 决策层(bridge.py)
        ▼                                    └► 返回 SpeechEditResult JSON(keep_segments+detail)
 预览（波形 + 保留/删除区段叠加，可手调阈值/增删区段）
        │  确认
        ▼
 window.aicut.speech.assemble() ──► Rust `speech --mode assemble`
        │                               └► ffmpeg trim+concat+crossfade 生成新文件(音视频同步)
        ▼
 addAsset(新路径) + addClipToTrack()  ──► 新片段非破坏入轨（原片段保留）
```

**为什么分离**：W1 的「脑子」（ASR+VAD+声学判别+废词表+区间运算）用 Python 桥接原样复用，能力最全；
媒体生成交给 AIcut 原生 ffmpeg（规避 W1「视频仅重混音」弱点，做到音视频同步切割）。
Python 依赖被隔离在 `analyze` 一步，不影响 `assemble` / 预览 / 落轨。

**运行时注入**：`main.ts` 仿 `AICUT_PLUGIN_DIR` 注入 `AICUT_PYTHON_BIN = 托管 Python 绝对路径`，Rust `speech` 子命令读它 spawn Python。

## 4. 数据契约（三端对齐：TS / Rust / Python）

```ts
// 输入
interface SpeechEditOptions {
  modelSize?: 'tiny'|'base'|'small'|'medium'|'large'; // 默认 base（本机已缓存）
  useDemucs: boolean;        // 降噪（声源分离）
  vadThreshold: number;      // 静音阈值 0~1，默认 0.25
  minGap: number;            // 最小停顿(秒)，默认 0.18
  wordPad: number;           // 词边界 padding(秒)，默认 0.04
  denoise: boolean; deess: boolean; normalize: boolean; fillers: boolean;
  exclude?: [number, number][]; // 手动排除区间（秒）
}

// 输出（= W1 的 keep_segments + detail，字段名对齐）
interface SpeechEditResult {
  duration: number; sampleRate: number;
  words: { word: string; start: number; end: number }[];
  keepSegments: [number, number][];        // ★ 核心编辑方案（相对原媒体的秒区间）
  detail: { type: string; start: number; end: number }[]; // 删除原因分类
  totalRemovedSec: number; ratio: number;  // 压缩比例
}
```

Python `core.analyze(input_path, opts) -> dict` 与 `bridge.py` 的 stdout JSON 必须严格匹配上述结构。

### Phase 2｜Rust 服务层（2 子命令）— `src/main.rs` 加 `speech` 分支

### Phase 3｜IPC 全链路
- `gui/electron/main.ts`：`ipcMain.handle('speech:analyze' / 'speech:assemble', …)` → `callEngine('speech', 'analyze'/'assemble', …)`。
- `gui/electron/preload.ts` + `gui/src/types.ts`：暴露 `speech: { analyze, assemble }` 及上述类型。

### Phase 4｜SpeechPanel（左 tab）
- `App.tsx` `LEFT_TABS` + `uiStore.ts` `LeftPanel` 加 `'speech'`；新建 `gui/src/components/panels/SpeechPanel.tsx`（仿 TextPanel 挂载）。
- 无选中 clip → 提示「请在时间轴选中视频/音频片段」；有选中 → 取 `asset.path` + 类型。
- 选项 UI（模型/降噪/去齿音/响度/阈值滑条）→ 「分析」→ 预览：复用波形 + `keepSegments` 绿(保留)/红(删除) 叠加，区段可拖边/删除/重分析（补 W1 缺失项 4 的 AIcut 侧交互）。
- 「生成清洗片段」→ assemble → `addAsset` + `addClipToTrack`（非破坏，置于原片段之后或轨道末尾）。

### Phase 5｜落轨与体验
- 生成后高亮新 clip；提示「原片段已保留，可对比」。
- 长音频 whisper CPU 慢 → analyze 显示**进度/异步**（Rust 子命令 stdout 流式或两次 IPC，补 W1 缺失项 7）。

### Phase 6｜联调验证
- 真实口播样本端到端：分析 → 预览 → 生成 → 入轨 → 播放/导出，确认音视频同步、无跳帧、降噪/去废话生效。

### Phase 7+（缺失项后续，本次不做）
