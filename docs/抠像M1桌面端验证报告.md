# 抠像 M1 桌面端验证报告

验证时间：2026-07-29 12:50–13:10
验证方式：Cua Driver 直接操作 AIcut 桌面端（pid 19252），真实导入绿幕测试素材并开关抠像功能。

## 测试素材
- 文件：`E:/4、视频/green_circle.mp4`（由 `E:/AIcut/.workbuddy/tmp_keytest/green_circle.mp4` 复制）
- 内容：纯绿背景（#00ff00），中央一个红色方块
- 分辨率：640×360，时长 3 秒

## 验证步骤
1. 启动 AIcut（已运行），右侧属性面板已出现「抠像」tab。
2. 点击「+ 导入」→ 调出文件对话框（Cua 元素索引点击返回 unverifiable，但对话框实际弹出）。
3. 将测试视频复制到对话框当前目录 `E:/4、视频/`，在列表中双击 `green_circle.mp4` 完成导入。
4. 素材库出现 `green_circle.mp4`；预览区自动显示该素材。
5. 在「抠像」面板中点击「已开启」开关关闭抠像，截图记录。
6. 再次点击开关开启抠像，截图记录。

## 验证结果

### 抠像关闭（原始画面）
预览区显示：绿色背景 + 中央红色方块。与原始视频一致。

### 抠像开启（抠像后画面）
预览区显示：绿色背景消失，变为黑色（透明区域），仅保留中央红色方块。

结论：色度抠图功能在桌面端实时预览中正确工作，绿色键色被移除，非键色像素保留。

## 控件状态确认
- 开关：可点击切换「已开启 / 已关闭」，切换后预览实时更新。
- 键色：默认 #00ff00，与绿幕匹配。
- 相似度 / 边缘柔化 / 溢出抑制：滑块显示正常，默认值 0.4 / 0.1 / 0.5。
- 模式按钮：色度、智能、手动 三个选项可见；当前仅「色度」可用（符合 M1 范围）。

## 已知 Cua Driver 限制（本次复现）
- 「+ 导入」按钮点击返回 `unverifiable`，但对话框实际弹出。
- 文件对话框中直接输入带反斜杠的完整路径会被 Windows 文件对话框判定为"文件名无效"；将文件复制到对话框当前目录后双击列表项可成功导入。
- 时间轴片段标签在导入后未实时刷新，但预览区渲染的是正确素材。

## 综合结论
抠像 M1（色度抠图）在 AIcut 桌面端达到使用要求：
- 前端 UI 完整可用；
- 实时预览可正确移除键色；
- 开关可即时切换效果；
- 后端导出路径已在前期通过 `aicut-engine export` 三种场景验证（基础抠像 / 圆形蒙版+抠像 / 文字蒙版+抠像）。
