AIcut 语音识别（ASR）配置帮助指南

模型：阿里云百炼 paraformer-realtime-v2（用于「AI 自动字幕」把视频/音频里的说话内容转成字幕）

这篇指南是写给谁看的：
你（用户）想用 AIcut 的「AI 自动字幕」功能，需要先在阿里云百炼开通语音识别服务、拿到 API Key，再填进 AIcut。下面按「假如你就是第一次操作的用户」的步骤一步步写，照着做即可。

一、先确认你的 AIcut 能用 ASR

AIcut 的语音识别依赖一个本地 Python 运行时和 dashscope SDK（由 python/asr/bridge.py 调用百炼云端接口）。所以：

  • ✅ 完成版软件自带 Python 和依赖，无需任何额外下载，解压即用。
  • ✅ 精简版需先在「AI 组件」面板点一键补全，把 Python 运行时下载下来，之后也能用。
  • ❌ 既没用完成版、又没下载 Python 的，ASR 会无法运行。

判断方法：打开 AIcut → 顶部「AI 组件」→ 看 Python 运行时状态是否显示「已就绪」。

⚠️ 关于密钥安全：你的百炼 API Key 只会保存在你本机的配置文件里（config.json），软件不会内置任何密钥，也不会上传。用完成版还是精简版都不影响这一点。

二、去阿里云百炼开通语音识别（共 4 步）

  1. 注册并实名阿里云账号

    打开 www.aliyun.com，注册账号并完成实名认证（个人/企业均可）。语音类服务要求实名后才可使用。

  2. 开通百炼（DashScope）服务

    进入百炼控制台 bailian.console.aliyun.com，首次进入按提示开通百炼服务。开通后系统会自动发放「新人免费额度」。

    说明：这一步只是把百炼平台打开，后面还要单独开通具体模型权限。

  3. 开通 paraformer-realtime-v2 模型权限

    在百炼控制台的「模型广场 / 业务空间」中找到 paraformer-realtime-v2（语音识别类模型），点击开通。

    ASR 类模型不是开通百炼就能直接调，必须在业务空间里逐一开通具体模型，开通后才会消耗免费额度、才能正常调用。

  4. 创建 API Key 并复制

    进入百炼控制台 → 密钥管理（API Key） → 点击「创建 API Key」（归属选主账号 / 默认业务空间）。创建成功后会显示一串以 sk- 开头的密钥，复制保存好，下一步要填进 AIcut。

    密钥只显示一次，复制后妥善保管，不要泄露给别人。

三、把密钥填进 AIcut

打开 AIcut → 顶部「AI 配置」→ 找到「语音识别（ASR）」区域，按下面填写：

字段填什么说明
providerbailian默认就是百炼，不用改
apiKey你复制的 sk- 密钥必填，留空则无法识别
modelparaformer-realtime-v2可填全称；也可填 paraformer，软件内部会自动映射到 paraformer-realtime-v2
endpoint留空可选，留空即用百炼默认接入点

填完后无需重启，直接去用「AI 自动字幕」即可。

五、验证是否配置成功

  1. 准备一段带人声的视频或音频

    任意你能说话录制的短片即可。

  2. 在时间轴选中该片段 → 点「AI 自动字幕」

    选择刚才配置的百炼（bailian）识别。

  3. 看结果

    ✅ 成功：时间轴自动生成带时间的字幕条，文字与说话内容一致。
    ❌ 失败常见原因：
    • apiKey 没填或填错 → 提示鉴权失败；
    • 模型权限没开通 → 提示模型不可用（回百炼第 3 步确认开通）；
    • Python 未就绪 → 回第一步检查「AI 组件」面板。

六、常见问题

Q：我填 paraformer 还是 paraformer-realtime-v2 都行吗？
A：都行。AIcut 内部有别名映射，paraformer / paraformer-v1 / paraformer-v2 都会自动转成 paraformer-realtime-v2。填全称更直观。

Q：key 会泄露吗？
A：不会。key 只存在你本机配置文件中，软件不内置、不上传。

Q：精简版能用吗？
A：能，但需先在「AI 组件」面板补全 Python 运行时（一次下载）。完成版自带，最省事。

Q：免费额度用完了会怎样？
A：超出部分按 0.00024 元/秒 从阿里云账户扣费，可在百炼控制台随时查余额和用量。

本指南依据阿里云官方文档（密钥管理 / 模型开通 / 新人免费额度）与 AIcut 源码（gui/src/config/ai_config.ts 的 ASRConfig、python/asr/bridge.py 的模型别名映射）整理，内容以实际控制台页面与软件版本为准。
