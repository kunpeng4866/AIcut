## 验证结果

### 后端（真实 ffmpeg 导出）
`aicut-engine export` 对三个工程实跑 ffmpeg，全部成功：
- ✅ 基础色度抠像（`out_basic.mp4`）
- ✅ 圆形蒙版 + 抠像（`out_circle.mp4`）
- ✅ 文字蒙版 + 抠像（`out_text.mp4`）

滤镜链确认 `chromakey` 作用于 YUV 源、位于 mask RGBA 转换之前。

### 前端（算法 Node 测试 6/6）
复刻 `applyKeying` 像素数学验证：
- 纯绿 `#00ff00` → alpha=0（透明）✅
- 纯红 / 蓝 → alpha=255（不透明）✅
- 近绿 `(0,200,0)` → alpha=0 ✅
- 边缘带 `(0,50,0)` → alpha=164（半透，边缘羽化生效）✅
- 带绿溢光保留像素 `(200,230,200)` → alpha=255 且 g 230→215（溢出抑制生效）✅

## 两个 graph.rs bug（主代理复核修复）
1. 初版 keying 插入用 `rfind(",fps=")`，在「文字蒙版+keying」组合会**静默丢弃 chromakey**（该路径末句为 `[cur]fps=30` 无前导逗号）。→ 改为在 `core` 阶段插入。
2. **关键约束**：ffmpeg `chromakey` 仅接受 YUV；mask 路径会把视频转 RGBA，故 keying 必须在 YUV 源阶段施加，否则导出失败（退出码 -1279870712）。→ 已修正，三场景导出全通过。

## 使用方式
重启桌面端（需 cargo build + vite build，已构建）：
1. 选中视频片段 → 右侧属性面板切到「抠像」tab；
2. 开启 → 选模式「色度」→ 用吸管取绿幕色（或输入 `#00ff00`）；
3. 调「相似度 / 边缘柔化 / 溢出抑制」实时预览；导出时绿幕变透明、露出下层片段。
