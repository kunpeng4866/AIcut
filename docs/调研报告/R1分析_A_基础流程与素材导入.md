- 比例、缩放、位置等实时渲染参数作为片段属性写入草稿。

---

### 1.1 小结：剪映主流程
- 首页（工程索引） → 开始创作 → 编辑器空工程 → 导入素材 → 剪辑/调色/特效 → 导出成片
- 关键数据结构推断：
  - 草稿工程：本地目录（`E:/JianyingPro Drafts/草稿名`）+ 工程配置文件；
  - 媒体素材：素材箱只保存引用路径与缩略图，不移动原文件；
  - 时间轴片段：记录片段在素材上的入/出点、轨道顺序、画面/音频属性、关键帧；
  - 导出配置：比例、分辨率、帧率、码率、编码格式等独立配置。

## 模块1.2 素材导入

### 截图1：ScreenShot_2026-07-20_184907_977.png
**导入来源**：剪映内置音频库（音乐素材）—「我的收藏」子页

**支持的格式**：
此页展示的是在线/云端音乐库，不是本地文件导入；收藏的音乐来自平台提供的曲库，具体格式对用户不可见，通常由服务端统一转码后下发。

**导入流程步骤**：
1. 进入编辑器左侧「音频」标签；
2. 顶部子标签切换为「音乐素材」；
3. 当前页面为「音乐收藏」，若未登录则显示空状态并提供「登录」按钮；
4. 登录后可查看/收藏云端音乐，并拖拽到时间轴使用。

**素材管理功能**：
- 仅展示「音乐收藏」一个空列表，无搜索、排序、分组能力（因未登录/无收藏）；
- 提供登录入口以同步云端收藏。

**批量操作**：
收藏列表本身不支持批量导入；使用时通过拖拽单首音乐到时间轴。

**素材信息展示**：
当前空状态，未展示任何素材元数据。

**导入流程步骤**：
1. 触发导入后，弹出「请选择媒体资源」对话框；
2. 在左侧导航选择磁盘/文件夹（此图打开路径为 `此电脑 > 本地磁盘(E:) > JianyingPro Drafts`）；
3. 在文件列表中选择媒体文件；
4. 点击「打开(O)」按钮；
5. 文件被加入左侧素材箱；
6. 拖拽素材到时间轴进行剪辑。

**素材管理功能**：
- 系统文件管理器标准功能：新建文件夹、地址栏、快捷入口（此电脑、WPS云盘、OneDrive、图片、视频、下载、音乐等）；
- 文件类型过滤器：Media Files，限制可选文件范围。

**批量操作**：
系统文件选择器天然支持 Ctrl/Shift 多选，可一次性导入多个媒体文件。

**素材信息展示**：
- 文件列表显示：名称、修改日期、类型、大小；
- 当前路径下以日期命名的文件夹为主；
- 未展示媒体专用的缩略图/时长/分辨率，这些在导入后由素材箱展示。
