## 三、关键功能深度分析

### 3.1 时间轴与多轨道架构

**轨道类型**（自上而下叠加）：
1. **特效/贴纸轨道** — 最上层，橙色纯色条，无缩略图，覆盖下方所有轨道的视觉表现
2. **主视频轨道** — 核心视频内容层，连续帧缩略图
3. **辅助视频轨道（画中画）** — 叠加在主视频之上，同为缩略图展示
4. **音频轨道** — 最底层，蓝色波形可视化，独立于视频的渲染

**叠加逻辑**：经典"上遮下"——上层内容遮挡/覆盖下层内容。特效轨在最上可直接影响整体画面风格（如胶片颗粒/边框叠加）。

**可视化方式**：
- 视频片段：连续帧缩略图
- 音频片段：蓝色波形
- 特效/贴纸：纯色条（无缩略图/波形）

**轨道控制**：左侧提供锁定、隐藏、层级控制按钮。

**对 AIcut 的启示**：Track 模型已有 type/order/clips，需增加 `visible: bool` 和 `locked: bool` 字段；需确保渲染时按 track order 自上而下叠图。

### 3.2 特效与滤镜系统

**分类体系**：

| 模块 | 分类粒度 | 典型分类 | 参数模型 |
|------|----------|----------|----------|
| 滤镜 | 8+ 主题 | 美食/风景/人像/城市/春日/复古/电影 | 名称 + 强度 0-100 |
| 特效 | 12+ 子类 | 热度/视频/画面/复古胶片/鬼畜/美食/光影/边框/心情/人物/节日/氛围 | 名称 + 强度 0-100 |
| 转场 | 11 类 | 基础/模糊/滑动/渐隐/翻页/抖动/溶解/推拉/炫酷/视觉/运镜 | 名称 + 时长 0-5s |

**统一面板模式**：左侧分类列表 → 中部缩略图网格 → 右侧参数面板（名称+核心参数），记忆负担极低。

**热更新可能性**：在线资源通过下载/收藏机制下发，本地缓存后使用。AIcut 的 R3 调研已设计 .aifx 包格式，直接对齐此模式。

**AI 能力"降维"为普通滤镜**：AI 低质修复以滤镜形式嵌入、智能抠像以开关形式出现 —— 降低学习门槛，值得借鉴。

### 3.3 关键帧动画系统

**驱动属性**：任何在右侧面板带有菱形标记的参数均可被关键帧化，包括：
- 位置 X/Y、缩放 X/Y、旋转
- 不透明度、锚点
- 滤镜强度、特效强度
- 音频音量

**添加方式**（三种）：
1. 工具栏菱形按钮 → 当前时间点给所有可调参数打关键帧
2. 参数旁小菱形 → 仅该参数新增关键帧
3. 先拖动/修改参数再自动记录

**曲线模式**：线性 / 缓入 / 缓出 / 缓入缓出 / 自定义

**数据模型推断**：
```json
{
  "keyframes": {
    "scale_x": [
      { "time": 0.0, "value": 1.0, "easing": "ease_in_out" },
      { "time": 2.0, "value": 1.5, "easing": "linear" }
    ]
  }
}
```

**AIcut 现状**：keyframe.rs 已实现线性/贝塞尔关键帧，`Clip.keyframes: HashMap<String, KeyframeTrack>` 正是此结构。只需扩展前端可视化与交互。

### 3.4 变速系统

**两大模式**：

| 模式 | 范围 | 参数 | 实现 |
|------|------|------|------|
| 常规变速 | 0.1x ~ 50x | 倍速 + 时长反向联动 + 声音变调复选框 | FFmpeg setpts/atempo |
| 曲线变速 | 7 种预设 + 自定义 | 自定义 / 更长中 / 更短更慢 / 子弹时间 / 鱼跃 / 快起 / 跳切 | FFmpeg setpts 分段（多个 Clip 或多段 trim+setpts 拼接） |

**数据模型推断**：常规变速度为 atomic 属性（Clip.speed）；曲线变速度为 SpeedCurve 对象（时间-速度映射曲线）。AIcut 的 project.rs 已有曲线变速模型。

### 3.5 抠像系统

**两大模式**：

| 模式 | 触发 | 参数 | 原理 |
|------|------|------|------|
| 智能抠像 | 开关一键启用 | 大小/边缘/羽化 | 深度学习人像分割 |
| 色度抠像 | 滴管选色 + 开关 | 色度选择/强度/阴影 | 传统 chroma key |

**蒙版+抠像组合**：先通过蒙版（圆形/方形/三角/星形等几何形状）限定作用区域，再在此区域内执行抠像算法，实现局部抠像。

**运动跟踪**：支持颜色匹配等跟踪方式，让蒙版跟随主体运动。

### 3.6 音频处理管线

**完整链路**：

```
素材导入 → 音频分离（Ctrl+Shift+S）
         → 基础参数（音量 dB / 声相 / 淡入淡出）
         → 高级处理（降噪 / 人声美化 / 声音分离 / 立体声增强 / 声道配置）
         → 变声（多分类音色库）
         → 声音效果（人声增强 / 空间混响 / 电台 / 电话 / 3D环绕 / ASMR）
         → 混音（多轨叠加 + 节拍标记 + 关键帧音量包络）
         → 导出
```

**关键点**：
- 音频关键帧可构造音量包络（V 形/斜坡/自定义）
- 变声和声音效果是独立的两层，效果可叠加
- 音频特效与画面 AI 功能常混存（如「音频翻译」入口在音频面板）

### 3.7 文本与字幕系统

**完整工作流**：

```
智能文案（AI 生成文案）
  ↓
添加文本层（默认文本 / 文字模板 / 花字模板）

  ↓

  ↓

  ↓
朗读配音（文本 → AI 语音 → 音频轨道）
```

**动画体系**：
- 三阶段：入场（进入动画）/ 出场（离开动画）/ 循环（持续动画）
- 每个阶段有数十种内置模板（弹跳/淡入/飞入/故障/扫光/缩放脉冲/旋转等）
- 独立控制每个阶段的时长
- 与文字模板共享同一动画引擎

**花字与模板**：平台提供大量设计资源；自定义文字可复用模板样式与动画。

## 四、数据模型推断

### 4.1 工程文件结构

```
Draft（草稿）
├── 元信息: id, name, created_at, modified_at, duration
├── canvas: { aspect, width, height, fps }
├── assetPool: Asset[]           // 素材箱（引用路径+元数据）
├── tracks: Track[]              // 时间轴轨道列表
├── transitions: Transition[]    // 转场列表（片段交界处）
├── markers: Marker[]            // 时间轴标记
├── exportConfig: ExportConfig   // 导出参数
└── aiProcessing: AIProcessing[] // AI 处理记录
```

### 4.2 轨道数据模型

```
Track
├── id, name, type (video/audio/effect/text/sticker)
├── order (层叠序号)
├── visible, locked
├── clips: Clip[]
└── (effect tracks have no clips — just a continuous effect layer)
```

### 4.3 片段数据模型（Clip）

```
Clip
├── asset_id (引用 Asset)
├── src_range: { in: f64, out: f64 }       // 素材入出点
├── timeline_in: f64                        // 时间轴起始位置
├── timeline_out: f64                       // 时间轴结束位置
├── transform: Transform                    // 基础变换
│   ├── position: { x, y }
│   ├── scale: { x, y, uniform: bool }
│   ├── rotation: f64
│   ├── opacity: f64
│   ├── anchor: { x, y }
│   └── flip: { h: bool, v: bool }
├── volume: f64                             // 音量 (dB)
├── speed: f64                              // 常规变速倍率
├── speed_curve: SpeedCurve?                // 曲线变速
├── effects: Effect[]
│   ├── id, name, type (filter/special_effect/chroma_key)
│   ├── params: { key: value }
│   └── enabled: bool
├── masks: Mask[]
│   ├── type (circle/rect/triangle/star/heart/custom)
│   ├── position, scale, rotation, feather
│   └── invert: bool
├── keyframes: HashMap<String, KeyframeTrack>
│   └── KeyframeTrack: Vec<{ time, value, easing }>
├── blend_mode: BlendMode?
├── text_overlay: TextOverlay?
│   ├── content, font, size, color
│   ├── style (bold/italic/underline)
│   ├── alignment
│   ├── spacing (letter/line)
│   └── animations: { entrance, exit, loop }
└── stickers: Sticker[]?
```

### 4.4 转场数据模型

```
Transition
├── id, name
├── type (dissolve/slide/blur/page_curl/wipe/...)
├── duration: f64                          // 0.1s ~ 5.0s
├── clip_a_id, clip_b_id                  // 前后片段
├── params: { key: value }
└── position: f64                          // 转场中心时间点（可错位）
```

### 4.5 特效数据模型

```
Effect
├── id, name
├── category (filter/special_effect/ai_effect)
├── source (builtin/downloaded/local)
├── params:
│   ├── strength: f64 (0.0~1.0)
│   └── ... (effect-specific overrides)
├── duration (applied to whole clip range or constrained)
└── enabled: bool
```

### 4.6 AIcut 现有数据模型对比

| 数据结构 | 剪映推断模型 | AIcut 已有 | 状态 |
|----------|------------|-----------|------|
| Project | draft + assetPool + tracks + transitions + exportConfig | version + canvas + assets + tracks | 基础覆盖 |
| Asset | id/type/path/duration/width/height/codec + thumbnail | 同（缺 thumbnail） | 基本对齐 |
| Track | type/order/clips + visible/locked | type/order/clips | 缺 visible/locked |
| Clip | 丰富的参数模型（含 text/sticker/effect/mask） | asset_id/src_range/timeline/transform/volume/speed/effects/masks/keyframes | 架构对路，缺 text/sticker/过渡效果 |
| Transform | position/scale/rotation/opacity/anchor/flip | x/y/scale_x/scale_y/rotation/opacity | 缺 anchor/flip/uniform_scale |
| Keyframe | time/value/easing parametric model | HashMap<String, KeyframeTrack> with 线性/贝塞尔 | 结构对路 |
| Effect | id/name/type/params/enabled | FilterInstance (filters.rs) | 基本对齐 |
| Transition | 独立数据实体（在 Clip 之间） | 无 | 需要新增 |
| TextOverlay | 完整文字样式+动画系统 | 无（仅 subtitle 层） | 需要新增 |
| SpeedCurve | 时间-速度映射曲线 | project.rs 已有 | 已实现 |
