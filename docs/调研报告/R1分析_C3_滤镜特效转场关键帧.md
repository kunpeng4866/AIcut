## 2. 截图 169 — AI 滤镜 / 右键菜单

**面板布局**
- 顶部同样为滤镜缩略图库（风景/植物/城市/……），左下角对时间轴上的片段唤出**右键上下文菜单**。
- 右侧"滤镜"面板已切换为"滤镜参数"：仅展示 `名称 + 强度` 两项。

**滤镜参数**
- 名称：`AI 低质修复`（单选 / 不可叠加于普通滤镜分类）。
- 强度：滑条 `0–100`，当前 100（满强度）。
- 顶部"调节参数"折叠按钮可隐藏/展开数值。

**右键菜单（关键能力清单）**
- 基础操作：复制 `C`、剪切 `X`、粘贴 `C`、删除。
- 片段属性：替换、音量（子菜单 +/−）、分离音视频、倒放 `V`、重置当前片段、隐藏当前片段。
- AI 操作：AI 修复（画质/低质修复）、AI 补帧、删除智能补帧。
- 朗读：新建文本朗读。
- 整理：新增文件夹片段。

**作用范围**
- 滤镜强度作用于选中片段的整段时间，与"基础"位置参数可同时生效。

**交互**
- 菜单项后标注快捷键（`C`/`X`/`V`），便于键盘流。
- 滑条 + 数字双控件，强度可重复拖动覆盖。

- 右侧"特效参数"：仅 `名称 + 强度 0–100` 两项。

**特效类型（按分类）**
- 热度 / 玩法：热门趋势特效。
- 视频特效 / 画面特效：通用运动、形变、光效。

- 边框 / 心情 / 人物 / 节日 / 氛围 / 地方：人像与场景情绪。

**参数选项**
- 名称（特效应名）。
- 强度 `0–100`：决定特效整体表现力；无时长字段（默认作用于片段全程）。

**作用范围**
- 默认作用于整段片段；如需局部，可结合关键帧让强度随时间变化。

**交互**
- 单击缩略图 → 立即应用。
- 右侧可再次调"强度"。
- 替换/删除通过底部片段上小标识完成。

## 5. 截图 172 — 关键帧（基础/画面参数）

**面板布局**
- 顶栏位于"特效"页面，时间轴上一段已选中。
- 底部工具栏出现"关键帧"按钮（菱形图标），点击后变为**高亮/激活态**。
- 右侧"画面 → 基础"面板全部数值旁边多出"菱形 ▾"小标记（关键帧可记录项）。
- 时间轴上片段中央可见**菱形关键帧点**（沿时间轴均匀分布）。

**添加方式**
- 工具栏：单击"关键帧"菱形按钮 → 在当前时间指针位置给所有可调参数打一个关键帧。
- 数值旁小菱形：把指针移到某帧，再点击具体参数旁的菱形 → 仅该参数新增关键帧。
- 画布/属性：先移动 / 旋转 / 缩放，再打关键帧（自动记录当前值）。

**可被关键帧化的参数**
- 基础：位置 X/Y、缩放、旋转、不透明度、锚点。
- 画面风格：色彩饱和度、亮度、对比度等调节项。
- 音轨：音量、淡入淡出（见截图 174）。

**动画曲线**
- 剪映未显式提供"贝塞尔曲线编辑器"，而是按**时间线线性插值**自动生成关键帧动画。
- 高级模式（鼠标右键关键帧点 → 缓动/线性切换）下可选：
  - 线性 Linear
  - 缓入 Ease In
  - 缓出 Ease Out
  - 缓入缓出 Ease In-Out
  - 自定义（高级/抖入抖出）

**作用范围**
- 关键帧作用在"参数 × 时间点"上，仅影响该片段内的相关参数。

## 关键洞察（对我们产品的启示）

1. **参数面板是"参数名 + 滑条 + 数字输入 + 关键帧小菱形"四件套**——我们的素材属性编辑器可复用此布局。
2. **滤镜/特效/转场三者模式统一**：左侧分类、缩略图库、右侧"名称+参数"面板，记忆负担极低。
3. **转场的"在片段交界处插入带标签的小块"**是亮点，UI 比传统下拉列表直观，可借鉴。
4. **关键帧机制被"参数化"**：任何数值旁都带菱形，无需独立工具面板，符合"操作即参数"的现代编辑器理念。
5. **AI 一键修复（AI 低质修复）以滤镜形式出现**——AI 能力在剪映中被"降维"为普通滤镜/特效，降低使用门槛。
