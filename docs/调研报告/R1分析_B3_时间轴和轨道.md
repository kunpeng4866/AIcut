# R1 分析：剪映时间轴与轨道（B3）

## 一、总体观察

五张截图均呈现同一剪映（CapCut PC）编辑界面，时间轴与轨道布局基本一致。可见 4 条轨道，从上到下分别为：特效/贴纸类轨道（橙色条）、主视频轨道（缩略图）、画中画/辅助视频轨道（缩略图）、音频轨道（波形）。预览窗口显示主视频叠加了边框/胶片感特效，说明上层特效轨道对下层视频轨道产生视觉叠加影响。轨道左侧具备锁定、隐藏、层级等常见轨道控制入口，但截图中各按钮状态差异不明显，主要体现默认编辑态。

  - 轨道 3：辅助视频轨道（画中画/叠加），同样显示缩略图，时长与主视频相近。
  - 轨道 4：音频轨道，以蓝色波形表现，呈现音频响度变化。
- **轨道操作**：轨道左侧有锁定/隐藏/层级控制图标，当前状态未发生明显切换，均处于默认可编辑状态。

## 三、关键发现

1. **轨道层级固定**：剪映采用经典自上而下叠加逻辑，上层轨道内容遮挡或覆盖下层轨道内容。特效/贴纸轨道位于最上层，可直接影响预览画面。
2. **片段可视化方式**：视频片段用帧缩略图表示，音频用波形表示，特效/贴纸用纯色条表示，便于用户快速区分媒体类型。
3. **轨道控制入口集中**：轨道左侧提供锁定、隐藏、层级等控制，属于标准非线性编辑软件设计。
4. **五张截图状态一致**：本次截图序列未体现明显的锁定、隐藏、缩放、滚动等动态操作，主要呈现静态编辑界面。

## 四、对产品设计的启示

- 保持“上遮下”的层级语义，便于用户理解多轨道叠加。
- 视频缩略图 + 音频波形 + 特效纯色条的可视化方式直观，可降低用户识别成本。
- 轨道控制按钮应提供清晰的激活/禁用状态反馈，便于判断当前轨道是否被锁定或隐藏。
