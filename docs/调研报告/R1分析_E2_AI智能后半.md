# R1 分析 E2：剪映 AI 智能功能后半（截图 202–203）

> 分析对象：剪映专业版（PC）"文本"模块下的 AI 功能

---

## 截图 202：智能文案

| 项目 | 内容 |
|------|------|
| **功能名称** | 智能文案 |
| **入口位置** | 顶部菜单「文本」 → 左侧面板「智能文案」 |
| **功能描述** | 根据输入的主题或关键词，自动生成可用于视频标题、口播稿、字幕文案的文本内容。 |
| **可见参数/选项** | - 文案类型/长度：单文、短文案、长文案<br>- 主题输入框（可手动输入生成主题）<br>- 自动生成按钮 |
| **关联功能** | 与「新建文本」「识别字幕」「文字模板」等同属文本功能区。 |

---

## 截图 203：智能配音 / 文本朗读

| 项目 | 内容 |
|------|------|
| **功能名称** | 智能配音（文本朗读 / 朗读音色） |
| **入口位置** | 顶部菜单「文本」 → 左侧面板「朗读音色」/「文本朗读」 |
| **功能描述** | 将已输入的文字转换为语音，并支持选择不同音色、语种、风格进行配音。 |
| **可见参数/选项** | - 音色分类：热门、中文、英文、方言、日语、韩语、男生、女生等<br>- 自定义旁白<br>- 音色列表卡片（可试听/选择） |
| **关联功能** | 与「智能文案」形成"文案生成 → 语音合成"的文本-音频工作流。 |

---

## 汇总

| 功能 | 入口 | 核心能力 | 可配参数 |
|------|------|----------|----------|
| 智能文案 | 文本 → 智能文案 | 主题驱动的文案自动生成 | 文案长度、主题关键词 |
| 智能配音 | 文本 → 朗读音色 | 文本转语音、AI 配音 | 音色分类、语种、性别、风格 |

---

## 备注

- 两张截图均位于剪映「文本」大模块，说明 AI 文案与 AI 配音是文本工作流中前后衔接的能力。
- 界面中可见「识别字幕」「识别歌词」等辅助 AI 功能，但当前截图未选中，故未展开详细参数。
- 实际参数以当前版本界面为准，本报告仅基于截图可见信息整理。
