## 功能矩阵小结

| 功能点 | 剪映实现方式 | AIcut 现状 | 复刻优先级 |
|--------|--------------|------------|------------|
| 素材导入/主轨道放置 | 拖拽导入或本地导入后自动入轨；右侧面板「基础」调整 | 待实现 | P0 |
| 片段选中/查看属性 | 时间轴单击选中；右侧属性面板实时显示 | 待实现 | P0 |
| 分割（Split） | 工具栏「分割」按钮或 Ctrl+B；按播放头位置切分 | 待实现 | P0 |
| 删除片段 | 右键菜单「删除」或选中按 Delete | 待实现 | P0 |
| 复制/粘贴片段 | 右键菜单「复制」「粘贴」；可复制到画中画轨道 | 待实现 | P0 |
| 缩放（Scale） | 右侧「缩放」滑块 + 等比缩放开关 | 待实现 | P0 |
| 裁剪（Crop） | 工具栏/右键「裁剪」；弹窗「调整大小」+ 裁切框 | 待实现 | P0 |
| 旋转（Rotate） | 右侧「旋转」数值输入，支持 360° 循环；预览实时同步 | 待实现 | P0 |
| 镜像（Mirror） | 右侧「镜像」按钮或右键菜单入口 | 待实现 | P0 |
| 音量调节 | 音频片段右侧属性或时间轴音量线 | 待实现 | P0 |
| 调整时长（变速/拉伸） | 拖拽片段边缘或右键「变速」 | 待实现 | P0 |
| 拖拽排序 | 按住片段左右移动，自动吸附前后素材 | 待实现 | P0 |
| 时间轴缩放 | 右下角滑块 / Ctrl+滚轮 | 待实现 | P0 |
| 播放头定位 | 点击时间轴或拖动播放头 | 待实现 | P0 |
| 多轨道支持（画中画/音频/文字/贴纸/特效） | 主轨道 + 画中画 + 音频 + 文字 + 贴纸 + 特效轨道；上下层级叠加 | 待实现 | P0 |
| 轨道锁定/隐藏 | 轨道左侧开关/眼睛图标 | 待实现 | P1 |
| 轨道层级调整 | 上下拖拽轨道改变叠加顺序 | 待实现 | P1 |
| 吸附/对齐 | 拖拽片段时自动吸附前后素材边缘 | 待实现 | P0 |
| 右键快捷菜单 | 一站式复制、删除、裁剪、旋转、镜像、变速、识别字幕等 | 待实现 | P1 |
| 时间轴标记 | 播放头 + 时间码显示 | 待实现 | P1 |
| 特效轨道 | 特效以独立橙色条显示，可调整时长和位置 | 待实现 | P2 |

## 关键发现

剪映基础剪辑操作通过「右侧属性面板 + 时间轴工具栏 + 右键快捷菜单」三线覆盖，所有基础操作均支持快捷键与可视化拖拽；时间轴采用主轨道 + 画中画/音频/文字/贴纸/特效多层叠加模型，轨道左侧提供开关、隐藏、层级控制。AIcut 复刻时应优先保障 P0 能力：分割、删除、复制、缩放、裁剪、旋转、镜像、音量、时长、多轨道、时间轴缩放、吸附对齐，再逐步补充 P1/P2 的轨道锁定、隐藏、右键菜单和特效轨道。
