## 1. WGSL 着色器静态扫描

### 1.1 安全规则表

第三方 WGSL 着色器在编译前必须通过 CPU 端静态扫描。以下是禁止与限制的完整规则集：

| 规则 ID | 类别 | 禁止模式 | 原因 | 检测方式 |
|---|---|---|---|---|
| S-001 | 写入纹理 | `textureStore` | 只允许读取纹理，防止写入破坏帧缓冲或纹理池 | 关键字匹配 |
| S-002 | 写入纹理 | `imageStore`（GLSL） | 同上 | 关键字匹配 |
| S-003 | 写入纹理 | `writeonly`（GLSL） | 只写纹理声明 | 关键字匹配 |
| S-004 | 原子操作 | `atomicAdd/atomicSub/atomicMax/atomicMin/atomicAnd/atomicOr/atomicXor/atomicExchange/atomicCompareExchangeWeak` | 竞态条件风险，GPU 端不可预测 | 关键字匹配 |
| S-005 | 原子操作 | `atomicLoad/atomicStore` | 同上 | 关键字匹配 |
| S-006 | 屏障 | `storageBarrier/workgroupBarrier` | 干扰渲染管线调度 | 关键字匹配 |
| S-007 | 屏障 | `memoryBarrier/groupMemoryBarrier`（GLSL） | 同上 | 关键字匹配 |
| S-008 | 无限循环 | `while(true)/while(1)/for(;;)/loop{}`（WGSL） | 死循环卡死 GPU，无中断机制 | AST 分析 + 启发式匹配 |
| S-009 | 深嵌套循环 | 嵌套深度 > 4 层 | 指令膨胀风险，编译超时 | AST 分析 |
| S-010 | 子群操作 | `subgroupBallot/subgroupBroadcast/subgroupShuffle/subgroupF` 系列 | GPU 子群特性不稳定，跨后端兼容差 | 关键字匹配 |
| S-011 | 未授权 builtin | `@builtin(vertex_instance_index)` 等非允许列表 builtin | 限制入口函数能力，防止越权 | AST 分析（允许列表白名单） |
| S-012 | 计算/存储管线 | `@compute` 入口函数 | 仅允许 `@vertex`+`@fragment` 管线 | 关键字匹配 |
| S-013 | 存储缓冲 | `storage` 地址空间声明 | 禁止读写大块存储缓冲 | 关键字匹配 |
| S-014 | 递归调用 | 函数自调用 | WGSL 禁递归但需双重确认 | AST 分析 |
| S-015 | 超长着色器 | 行数 > 2000 或估算指令数 > 5000 | 编译慢/驱动超时 | 行数计数 + 启发式 |
| S-016 | 动态索引 | `array/dynamic_index` 非常量索引 | 部分后端不支持动态索引 | AST 分析（降级为警告） |

### 1.2 允许的 WGSL Built-in 白名单

| Built-in | 用途 | 允许理由 |
|---|---|---|
| `position` | 片段着色器输入，获取屏幕坐标 | 核心，所有特效需要 |
| `vertex_index` | 顶点索引 | 全屏三角形绘制需要 |
| `instance_index` | 实例索引 | 同上 |
| `front_facing` | 正面判断 | 基础渲染需要 |
| `frag_depth` | 深度写入 | 3D 叠加需要 |
| `global_invocation_id` | 计算着色器全局 ID | **仅限 Phase 5+ 计算后效，首版不允许** |

首版仅允许 `@fragment` 入口 + 上述白名单 builtin。`@compute` 入口在首版**禁止**（S-012），Phase 6+ 按需开放并增加独立扫描规则。

### 1.3 扫描实现策略：两阶段混合

**权衡**：纯正则无法区分 `textureStore` 是注释还是真实调用；纯 AST 依赖 WGSL 完整解析器（naga/wgsl-analyzer），引入较重依赖。

**策略**：两阶段——

1. **第一阶段：预处理 + 正则粗扫**（Rust 侧，同步执行，轻量）
   - 去注释（行注释 `//` + 块注释 `/* */`），防止误判注释中的关键字
   - 对去注释后的源码做关键字/模式匹配（覆盖 S-001~S-007, S-010, S-012, S-013）
   - 行数/指令数估算（S-015）
   - 优势：速度快，无外部依赖，可单测

2. **第二阶段：AST 精扫**（可选，Phase 6+，利用 naga crate）
   - 用 `naga::front::wgsl::parse_str()` 获取 AST
   - 检测 S-008（loop 死循环）、S-009（嵌套深度）、S-011（builtin 白名单）、S-014（递归）、S-016（动态索引）
   - 优势：100% 准确，可生成结构化错误报告
   - 代价：naga 为较重依赖（~2MB 编译产物），首版可能不引入

### 1.4 扫描数据结构与伪代码

```rust
// src/vfx/scanner.rs

/// 着色器扫描结果
#[derive(Debug, Clone, Serialize)]
pub struct ShaderScanReport {
    pub shader_id: String,               // 包 id + 着色器文件名
    pub shader_type: ShaderType,
    pub passed: bool,
    pub violations: Vec<ScanViolation>,
    pub warnings: Vec<ScanWarning>,
    pub stats: ShaderStats,
}

#[derive(Debug, Clone, Serialize)]
pub struct ScanViolation {
    pub rule_id: String,                 // "S-001"
    pub severity: ViolationSeverity,     // Error | Critical
    pub message: String,
    pub line: Option<u32>,              // 源码行号（正则可提供，AST 必提供）
    pub snippet: Option<String>,        // 匹配到的原文
}

#[derive(Debug, Clone, Serialize)]
pub struct ScanWarning {
    pub rule_id: String,                 // "W-001"
    pub message: String,
    pub line: Option<u32>,
}

#[derive(Debug, Clone, Serialize)]
pub struct ShaderStats {
    pub line_count: u32,
    pub estimated_ops: u32,              // 启发式估算
    pub loop_count: u32,
    pub max_loop_nesting: u32,
    pub function_count: u32,
    pub uses_textures: bool,
}

#[derive(Debug, Clone, Copy)]
pub enum ShaderType { Wgsl, GlslFrag, GlslVert }
#[derive(Debug, Clone, Copy)]
pub enum ViolationSeverity { Error, Critical }

/// 第一阶段：预处理 + 正则粗扫
pub fn scan_phase1(source: &str, shader_type: ShaderType) -> ShaderScanReport {
    let stripped = strip_comments(source);
    let mut violations = Vec::new();
    let mut warnings = Vec::new();

    // ── 关键字扫描 ──
    for &(pattern, rule_id, reason, severity) in &FORBIDDEN_KEYWORD_RULES {
        // 使用行级扫描以获取行号
        for (line_idx, line) in stripped.lines().enumerate() {
            if line.contains(pattern) {
                violations.push(ScanViolation {
                    rule_id: rule_id.to_string(),
                    severity,
                    message: reason.to_string(),
                    line: Some(line_idx as u32 + 1),
                    snippet: Some(line.trim().to_string()),
                });
            }
        }
    }

    // ── 统计信息 ──
    let stats = compute_stats(&stripped);
    if stats.line_count > 2000 {
        warnings.push(ScanWarning {
            rule_id: "W-001".into(),
            message: format!("着色器行数 {} 超过 2000，编译可能超时", stats.line_count),
            line: None,
        });
    }
    if stats.max_loop_nesting > 3 {
        warnings.push(ScanWarning {
            rule_id: "W-002".into(),
            message: format!("循环嵌套 {} 层，疑似性能风险", stats.max_loop_nesting),
            line: None,
        });
    }
    // 嵌套 > 4 → 升级为 violation
    if stats.max_loop_nesting > 4 {
        violations.push(ScanViolation {
            rule_id: "S-009".into(),
            severity: ViolationSeverity::Error,
            message: format!("循环嵌套深度 {} > 4，禁止加载", stats.max_loop_nesting),
            line: None,
            snippet: None,
        });
    }

    ShaderScanReport {
        shader_id: String::new(),  // 由调用方填充
        shader_type,
        passed: violations.is_empty(),
        violations,
        warnings,
        stats,
    }
}

/// 禁止关键字规则表（第一阶段用）
const FORBIDDEN_KEYWORD_RULES: &[(&str, &str, &str, ViolationSeverity)] = &[
    // (pattern, rule_id, reason, severity)
    ("textureStore",       "S-001", "禁止写入纹理",          ViolationSeverity::Critical),
    ("imageStore",         "S-002", "禁止写入纹理",          ViolationSeverity::Critical),
    ("atomicAdd",          "S-004", "禁止原子操作",          ViolationSeverity::Critical),
    ("atomicSub",          "S-004", "禁止原子操作",          ViolationSeverity::Critical),
    ("atomicLoad",         "S-005", "禁止原子操作",          ViolationSeverity::Critical),
    ("atomicStore",        "S-005", "禁止原子操作",          ViolationSeverity::Critical),
    ("atomicCompareExchangeWeak", "S-004", "禁止原子操作",   ViolationSeverity::Critical),
    ("storageBarrier",     "S-006", "禁止存储屏障",          ViolationSeverity::Error),
    ("workgroupBarrier",   "S-006", "禁止工作组屏障",        ViolationSeverity::Error),
    ("subgroupBallot",     "S-010", "禁止 subgroup 操作",    ViolationSeverity::Error),
    ("@compute",           "S-012", "禁止计算管线入口",      ViolationSeverity::Critical),
    ("storage",            "S-013", "禁止存储缓冲地址空间",  ViolationSeverity::Error),
];

/// 去注释：保留行结构（行号对齐），仅清空注释内容
fn strip_comments(source: &str) -> String {
    let mut result = String::with_capacity(source.len());
    let mut in_block = false;
    for line in source.lines() {
        if in_block {
            if line.contains("*/") {
                in_block = false;
                // 块注释结束行保留注释后内容
                let after = line.split("*/").nth(1).unwrap_or("");
                result.push_str(after);
            }
            result.push('\n');
            continue;
        }
        // 去行注释
        let cleaned = if let Some(pos) = line.find("//") {
            &line[..pos]
        } else {
            line
        };
        // 检测块注释开始
        if cleaned.contains("/*") {
            in_block = true;
            let before = cleaned.split("/*").next().unwrap_or("");
            result.push_str(before);
        } else {
            result.push_str(cleaned);
        }
        result.push('\n');
    }
    result
}

/// 统计信息计算
fn compute_stats(stripped: &str) -> ShaderStats {
    let line_count = stripped.lines().count() as u32;
    let mut loop_count = 0u32;
    let mut max_nesting = 0u32;
    let mut current_nesting = 0u32;
    let mut func_count = 0u32;
    let mut uses_textures = false;

    for line in stripped.lines() {
        let trimmed = line.trim_start();
        if trimmed.starts_with("fn ") { func_count += 1; }
        if trimmed.starts_with("for") || trimmed.starts_with("while") || trimmed.starts_with("loop") {
            loop_count += 1;
            current_nesting += 1;
            max_nesting = max_nesting.max(current_nesting);
        }
        if trimmed.contains('}') && current_nesting > 0 { current_nesting -= 1; }
        if trimmed.contains("texture_2d") || trimmed.contains("sampler") { uses_textures = true; }
    }

    // 启发式估算指令数：每行约 2-3 ops，循环体乘以估算迭代次数
    let estimated_ops = line_count * 3;

    ShaderStats {
        line_count,
        estimated_ops,
        loop_count,
        max_loop_nesting: max_nesting,
        function_count: func_count,
        uses_textures,
    }
}
```

## 2. 编译时性能校验

### 2.1 着色器编译超时检测

WebGPU `createShaderModule` 和 `createRenderPipeline` 是同步 API（返回后即编译完成），但底层驱动编译可能耗时数秒。超时检测策略：

```ts
// packages/engine/src/vfx_runtime.ts

const COMPILE_TIMEOUT_MS = 5000; // 单个着色器编译上限 5 秒

export async function compileWithTimeout(
  device: GPUDevice,
  wgslCode: string,
  label: string,
): Promise<GPUShaderModule | null> {
  // WebGPU shader module 创建本身是同步的，但 compilationInfo 是异步的
  // 超时策略：在 setTimeout 后检查是否已完成

  let compiled = false;
  let module: GPUShaderModule | null = null;

  try {
    module = device.createShaderModule({ code: wgslCode, label });

    // 检查编译信息（含错误）
    const info = await module.getCompilationInfo();
    if (info.messages.some(m => m.type === 'error')) {
      const errors = info.messages
        .filter(m => m.type === 'error')
        .map(m => `${m.lineNum}:${m.linePos} ${m.message}`)
        .join('\n');
      logError(`[vfx] WGSL 编译失败 (${label}): ${errors}`);
      return null;
    }

    compiled = true;
  } catch (e) {
    logError(`[vfx] WGSL 编译异常 (${label}): ${e}`);
    return null;
  }

  return module;
}
```

对于 pipeline 创建（可能更耗时）：

```ts
const PIPELINE_TIMEOUT_MS = 8000;

export async function createPipelineWithTimeout(
  device: GPUDevice,
  module: GPUShaderModule,
  vfxId: string,
): Promise<GPURenderPipeline | null> {
  // createRenderPipeline 是同步的，但可能阻塞主线程
  // 方案：在 Web Worker 中创建 OffscreenCanvas + GPUDevice，异步编译
  // 首版简化：直接在主线程编译，用 performance.now() 记录耗时

  const t0 = performance.now();
  try {
    const pipeline = device.createRenderPipeline({
      layout: 'auto',
      vertex: {
        module,
        entryPoint: 'vs_main',
      },
      fragment: {
        module,
        entryPoint: 'fs_main',
        targets: [{ format: 'bgra8unorm' }],
      },
      primitive: { topology: 'triangle-list' },
    });
    const elapsed = performance.now() - t0;
    if (elapsed > PIPELINE_TIMEOUT_MS) {
      logWarn(`[vfx] Pipeline 创建耗时 ${elapsed}ms > ${PIPELINE_TIMEOUT_MS}ms，标记为慢着色器`);
      // 降级：标记为 gpu_tier=high，预览时可能跳帧
    }
    return pipeline;
  } catch (e) {
    logError(`[vfx] Pipeline 创建失败 (${vfxId}): ${e}`);
    return null;
  }
}
```

### 2.2 离屏渲染预热

预热目的：确保着色器首次运行不会卡顿渲染循环。

```ts
// packages/engine/src/vfx_runtime.ts

export async function warmupShader(
  device: GPUDevice,
  pipeline: GPURenderPipeline,
  vfxId: string,
  uniformLayout: UniformLayout,
): Promise<boolean> {
  // 1. 创建 1×1 临时输出纹理
  const dummyTex = device.createTexture({
    size: [1, 1],
    format: 'bgra8unorm',
    usage: GPUTextureUsage.RENDER_ATTACHMENT,
  });

  // 2. 创建 dummy 输入纹理（黑帧）
  const dummyInput = device.createTexture({
    size: [1, 1],
    format: 'rgba8unorm',
    usage: GPUTextureUsage.TEXTURE_BINDING | GPUTextureUsage.COPY_DST,
  });
  device.queue.writeTexture(
    { texture: dummyInput },
    new Uint8Array([0, 0, 0, 255]),
    { bytesPerRow: 4 },
    [1, 1],
  );

  // 3. 创建 dummy uniform buffer（填零）
  const uniformSize = uniformLayout.totalSize;
  const uniformBuffer = device.createBuffer({
    size: uniformSize,
    usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST,
  });
  device.queue.writeBuffer(uniformBuffer, 0, new Float32Array(uniformSize / 4));

  // 4. 创建 bind group
  const bindGroup = device.createBindGroup({
    layout: pipeline.getBindGroupLayout(0),
    entries: [
      { binding: uniformLayout.inputTexBinding, resource: dummyInput.createView() },
      { binding: uniformLayout.uniformBinding, resource: { buffer: uniformBuffer } },
    ],
  });

  // 5. 执行一次离屏渲染
  const encoder = device.createCommandEncoder();
  const pass = encoder.beginRenderPass({
    colorAttachments: [{
      view: dummyTex.createView(),
      loadOp: 'clear',
      storeOp: 'store',
    }],
  });
  pass.setPipeline(pipeline);
  pass.setBindGroup(0, bindGroup);
  pass.draw(3); // 全屏三角形
  pass.end();
  device.queue.submit([encoder.finish()]);

  // 6. 等待 GPU 完成
  await device.queue.onSubmittedWorkDone();

  // 7. 清理临时资源
  dummyTex.destroy();
  dummyInput.destroy();
  uniformBuffer.destroy();

  const elapsed = performance.now(); // 可用于记录预热耗时
  logInfo(`[vfx] 预热完成: ${vfxId}`);
  return true;
}
```

### 2.4 编译失败/超时的降级策略

```
着色器编译/预热流程
        │
        ▼
┌──────────────────────────────────────┐
│ 1. scan_phase1()                     │
│    失败 → REJECTED (拒绝加载)        │
└──────────────┬───────────────────────┘
               │ passed
               ▼
┌──────────────────────────────────────┐
│ 2. compileShaderModule()             │
│    失败 → COMPILE_FAILED             │
│    ├─ WGSL 语法错误 → 日志 + toast   │
│    ├─ 缺少入口函数 → 日志 + toast    │
└──────────────┬───────────────────────┘
               │ 成功
               ▼
┌──────────────────────────────────────┐
│ 3. createRenderPipeline()            │
│    失败 → PIPELINE_FAILED            │
│    ├─ binding 不匹配 → 日志          │
│    ├─ 超时 → 标记 gpu_tier=high      │
└──────────────┬───────────────────────┘
               │ 成功
               ▼

└──────────────┬───────────────────────┘
               │ 成功
               ▼

```

    │ 失败
    ▼
跳过该特效 (Effect.enabled=false 本地标记)
```

## 3. Uniform 变量注入规范

### 3.1 统一变量集

每个第三方 WGSL 着色器必须遵循以下 uniform 接入规范。引擎为所有着色器注入统一基础变量 + 特效特有参数变量。

#### 基础变量（引擎自动注入，着色器必须声明）

| Uniform 名 | 类型 | 语义 | 来源 |
|---|---|---|---|
| `u_time` | `f32` | 当前帧时间（秒） | `PreviewEngine` 渲染时钟 |
| `u_resolution` | `vec2f` | 输出纹理分辨率 | canvas 尺寸 |
| `u_input_tex` | `texture_2d<f32>` | 输入帧纹理 | `<video>` 解码帧 |
| `u_input_sampler` | `sampler` | 输入纹理采样器 | 引擎创建 |
| `u_transform` | `mat4x4f` | 变换矩阵（scale+rotate+translate） | 片段 Transform 属性 |
| `u_opacity` | `f32` | 不透明度 | 片段 opacity |
| `u_frame_index` | `u32` | 帧序号（从 0 开始） | 渲染循环计数器 |

#### 特效参数变量（由 manifest.parameters 映射）

| 映射规则 | 说明 |
|---|---|
| `manifest.parameters[i].uniform` → WGSL uniform 名 | 如 `intensity` → `u_intensity` |
| 类型映射 | `float` → `f32`, `int` → `i32`, `color` → `vec3f`, `vec2` → `vec2f` |
| 默认值 | `manifest.parameters[i].default` → uniform 初始值 |
| 范围校验 | 运行期 clamp(min, max)，着色器无需自行 clamp |

// src/vfx/uniform_layout.rs

use serde::{Deserialize, Serialize};

/// 完整的 uniform 布局描述（传给 TS 侧创建 bind group）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UniformLayout {
    /// 基础变量区大小（固定 96 bytes）
    pub base_size: u32,
    /// 参数区每项大小（16 bytes aligned）
    pub param_entry_size: u32,
    /// 参数项列表
    pub params: Vec<UniformParamEntry>,
    /// Buffer 总大小
    pub total_size: u32,
    /// 纹理绑定列表
    pub texture_bindings: Vec<TextureBindingEntry>,
    /// 输入纹理 binding 号
    pub input_tex_binding: u32,
    /// 输入采样器 binding 号
    pub input_sampler_binding: u32,
    /// Uniform buffer binding 号
    pub uniform_binding: u32,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UniformParamEntry {
    /// WGSL uniform 变量名
    pub uniform_name: String,
    /// 参数名（manifest.parameters 中对应）
    pub param_name: String,
    /// WGSL 类型: "f32" | "i32" | "vec2f" | "vec3f" | "vec4f"
    pub wgsl_type: String,
    /// Buffer 内偏移
    pub offset: u32,
    /// 占用字节数（含 padding）
    pub size: u32,
    /// 默认值（序列化为 JSON Value）
    pub default: serde_json::Value,
    /// 最小值（范围校验）
    pub min: Option<f64>,
    /// 最大值（范围校验）
    pub max: Option<f64>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TextureBindingEntry {
    /// 纹理 uniform 名
    pub name: String,
    /// Binding 号
    pub binding: u32,
    /// 采样器 binding 号（紧随纹理之后）
    pub sampler_binding: u32,
    /// 包内资源路径
    pub asset_path: String,
    /// Wrap 模式: "repeat" | "clamp" | "mirror"
    pub wrap: String,
    /// Filter 模式: "linear" | "nearest"
    pub filter: String,
}

/// 从 manifest 计算完整 uniform 布局
pub fn compute_uniform_layout(manifest: &crate::vfx::manifest::VfxManifest) -> UniformLayout {
    const BASE_SIZE: u32 = 96;     // 基础变量区固定大小
    const PARAM_ENTRY_SIZE: u32 = 16; // 每参数项 16 bytes aligned

    let mut params = Vec::new();
    let mut offset = BASE_SIZE;

    for p in &manifest.parameters {
        let (wgsl_type, type_size) = match p.param_type {
            ParamType::Float => ("f32", 4),
            ParamType::Int => ("i32", 4),
            ParamType::Bool => ("f32", 4),   // WGSL 无 bool uniform，映射为 f32
            ParamType::Color => ("vec3f", 12),
            ParamType::Vec2 => ("vec2f", 8),
            ParamType::Vec3 => ("vec3f", 12),
            ParamType::Vec4 => ("vec4f", 16),
        };

        params.push(UniformParamEntry {
            uniform_name: p.uniform.clone().unwrap_or_default(),
            param_name: p.name.clone(),
            wgsl_type: wgsl_type.to_string(),
            offset,
            size: PARAM_ENTRY_SIZE,
            default: p.default.clone(),
            min: p.min.clone().and_then(|v| v.as_f64()),
            max: p.max.clone().and_then(|v| v.as_f64()),
        });

        offset += PARAM_ENTRY_SIZE;
    }

    // 纹理绑定：输入纹理(b1) + 输入采样器(b2) + 特效纹理(b3+)
    let mut texture_bindings = Vec::new();
    let mut tex_binding = 3u32; // b3 开始分配特效纹理
    for t in &manifest.textures {
        texture_bindings.push(TextureBindingEntry {
            name: t.name.clone(),
            binding: tex_binding,
            sampler_binding: tex_binding + 1,
            asset_path: t.path.clone(),
            wrap: t.wrap.clone(),
            filter: t.filter.clone(),
        });
        tex_binding += 2; // 纹理 + 采样器各占一个 binding
    }

    UniformLayout {
        base_size: BASE_SIZE,
        param_entry_size: PARAM_ENTRY_SIZE,
        params,
        total_size: offset,
        texture_bindings,
        input_tex_binding: 1,
        input_sampler_binding: 2,
        uniform_binding: 0,
    }
}
```

### 3.4 参数范围校验与默认值

```ts
// packages/engine/src/vfx_runtime.ts

/** 将用户参数写入 uniform buffer，含范围校验 */
export function writeUniformBuffer(
  device: GPUDevice,
  layout: UniformLayout,
  params: Record<string, number | number[]>,
  baseVars: BaseUniformVars,
): GPUBuffer {
  const buffer = device.createBuffer({
    size: layout.totalSize,
    usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST,
  });

  const data = new Float32Array(layout.totalSize / 4);

  // ── 写入基础变量 ──
  data[0] = baseVars.time;               // offset 0: u_time
  data[1] = baseVars.frameIndex;          // offset 4: u_frame_index (as float)
  data[2] = baseVars.opacity;             // offset 8: u_opacity
  // offset 16: u_resolution
  data[4] = baseVars.resolution[0];
  data[5] = baseVars.resolution[1];
  // offset 32: u_transform (mat4x4f, 16 floats)
  for (let i = 0; i < 16; i++) {
    data[8 + i] = baseVars.transform[i];
  }

  // ── 写入参数变量 ──
  for (const entry of layout.params) {
    const idx = entry.offset / 4; // Float32Array index
    let value = extractParamValue(entry, params);

    // 范围校验 clamp
    if (entry.min != null && entry.max != null) {
      value = Math.max(entry.min, Math.min(entry.max, value as number));
    }

    // 写入（简单类型占 1 slot，vec 类型占多个 slot）
    switch (entry.wgsl_type) {
      case 'f32':
      case 'i32':
        data[idx] = value as number;
        break;
      case 'vec2f':
        const v2 = value as number[];
        data[idx] = v2[0]; data[idx + 1] = v2[1];
        break;
      case 'vec3f':
        const v3 = value as number[];
        data[idx] = v3[0]; data[idx + 1] = v3[1]; data[idx + 2] = v3[2];
        break;
      case 'vec4f':
        const v4 = value as number[];
        data[idx] = v4[0]; data[idx + 1] = v4[1]; data[idx + 2] = v4[2]; data[idx + 3] = v4[3];
        break;
    }
  }

  device.queue.writeBuffer(buffer, 0, data);
  return buffer;
}

function extractParamValue(
  entry: UniformParamEntry,
  params: Record<string, number | number[]>,
): number | number[] {
  // 优先从用户参数取，回退到默认值
  const userVal = params[entry.param_name];
  if (userVal != null) return userVal;

  // 默认值解析
  const def = entry.default;
  if (typeof def === 'number') return def;
  if (Array.isArray(def)) return def;
  return 0;
}

interface BaseUniformVars {
  time: number;
  frameIndex: number;
  opacity: number;
  resolution: [number, number];
  transform: number[]; // mat4x4f as 16 floats
}
```

### 3.5 WGSL 着色器模板（第三方必须遵循）

第三方 WGSL 着色器必须声明以下入口函数和 uniform 结构：

```wgsl
// 第三方 WGSL 着色器标准模板
// 文件: shader/effect.wgsl

// ── 基础变量声明（必须）──
struct BaseUniforms {
    u_time: f32,
    u_frame_index: u32,
    u_opacity: f32,
    _pad0: u32,                    // 16-byte alignment padding
    u_resolution: vec2f,
    _pad1: vec2f,                  // alignment padding
    u_transform: mat4x4f,
};

// ── 参数声明（按 manifest.parameters 生成）──
struct EffectParams {
    u_intensity: f32,              // manifest.parameters[0]
    _pad2: vec3f,                  // alignment padding
    u_glow_color: vec3f,           // manifest.parameters[1]
    _pad3: f32,                    // alignment padding
    u_particle_count: f32,         // manifest.parameters[2]
    _pad4: vec3f,                  // alignment padding
};

// ── 合并 Uniform 结构 ──
struct AllUniforms {
    base: BaseUniforms,
    params: EffectParams,
};

@group(0) @binding(0) var<uniform> u_all: AllUniforms;
@group(0) @binding(1) var u_input_tex: texture_2d<f32>;
@group(0) @binding(2) var u_input_sampler: sampler;

// ── 特效纹理（可选，按 manifest.textures 声明）──
// @group(0) @binding(3) var u_noise_tex: texture_2d<f32>;
// @group(0) @binding(4) var u_noise_sampler: sampler;

// ── 顶点着色器（标准全屏三角形）──
@vertex
fn vs_main(@builtin(vertex_index) vi: u32) -> @builtin(position) vec4f {
    // 全屏三角形技巧：3 个顶点覆盖整个屏幕
    var pos = array<vec2f, 3>(
        vec2f(-1.0, -1.0),
        vec2f( 3.0, -1.0),
        vec2f(-1.0,  3.0),
    );
    return vec4f(pos[vi], 0.0, 1.0);
}

// ── 片段着色器（特效核心逻辑）──
@fragment
fn fs_main(@builtin(position) frag_pos: vec4f) -> @location(0) vec4f {
    let uv = frag_pos.xy / u_all.base.u_resolution;
    let input_color = textureSample(u_input_tex, u_input_sampler, uv);

    // ── 在此编写特效逻辑 ──
    var output_color = input_color;

    // 示例：光晕效果
    let glow = u_all.params.u_intensity * 0.5;
    output_color = vec4f(
        input_color.r + u_all.params.u_glow_color.r * glow,
        input_color.g + u_all.params.u_glow_color.g * glow,
        input_color.b + u_all.params.u_glow_color.b * glow,
        input_color.a * u_all.base.u_opacity,
    );

    return output_color;
}
```

引擎侧在加载第三方 WGSL 时，会**自动注入**基础变量声明部分（`BaseUniforms` 结构 + `AllUniforms` 合并 + 纹理 binding 声明 + `vs_main` 顶点着色器），第三方只需提供 `fs_main` 函数体和 `EffectParams` 结构。

## 4. 跨平台兼容性

### 4.1 WGSL 作为主语言

WGSL 是 WebGPU 的原生着色语言，在所有 WebGPU 后端（D3D12/Metal/Vulkan）中统一使用。Chromium 的 WebGPU 实现内部将 WGSL 转译为目标后端语言：

| 运行平台 | GPU 后端 | WGSL → 内部转译 | Electron 支持 |
|---|---|---|---|
| Windows | D3D12 | WGSL → HLSL（naga 内置） | ✅ 主力平台 |
| macOS | Metal | WGSL → MSL（naga 内置） | ✅ |
| Linux | Vulkan | WGSL → SPIR-V（naga 内置） | ✅（Chromium 120+） |

**关键结论**：只要 WGSL 源码在 Chromium WebGPU 编译通过，跨平台自动兼容。开发者无需关心后端差异。

### 4.2 WGSL 跨后端兼容注意事项

虽然 naga 转译自动处理大部分差异，但以下模式可能导致某些后端失败：

| 模式 | 问题描述 | D3D12 | Metal | Vulkan | 建议 |
|---|---|---|---|---|---|
| `f16` 半精度浮点 | 需 `shader-f16` feature，部分 GPU 不支持 | ❌ 集显 | ❌ 旧设备 | ❌ | 禁止，仅用 `f32` |
| 动态数组索引 | `array[f32][N]` 用变量索引 | ⚠️ | ✅ | ✅ | 建议常量索引 |
| 纹理采样 in VS | 部分后端不支持顶点着色器采样 | ❌ | ✅ | ✅ | 禁止 |
| `textureLoad` vs `textureSample` | `textureLoad` 无过滤，`textureSample` 有 | ✅ | ✅ | ✅ | 推荐用 `textureSample` |
| 多 render target | `@location(1)` 等 | ✅ | ✅ | ✅ | 仅用 `@location(0)` |
| `discard` | 片段丢弃 | ✅ | ✅ | ⚠️ 性能差 | 允许，但警告性能 |
| 大 uniform buffer > 64KB | 超过 WebGPU 限制 | ❌ | ❌ | ❌ | 强制限制 < 64KB |

**扫描规则新增**：

| 规则 ID | 模式 | 处理 |
|---|---|---|
| S-017 | `f16` 类型声明 | 禁止（Critical） |
| S-018 | 顶点着色器中 `textureSample` | 禁止（Critical） |
| W-003 | `discard` 使用 | 警告（性能提示） |
| S-019 | Uniform buffer > 64KB | 禁止（Critical） |

### 4.3 导出路径兼容：WGSL → FFmpeg 桥接

WebGPU 预览使用 WGSL，但 FFmpeg 导出不支持 WGSL。需要桥接方案：

**方案 A：`.aifx` 包双后端冗余（推荐，已在特效热更新设计中定义）**

每个特效包同时提供：
- `shader/effect.wgsl` → WebGPU 预览
- `ffmpeg/filter.spec` → FFmpeg 导出（含 `$param` 占位符模板）

优势：预览与导出各自用最优路径，无需翻译。
代价：特效开发者需维护两份实现。

**方案 B：WGSL → GLSL 自动翻译（naga 转译）**

使用 naga crate 在 Rust 侧将 WGSL 转译为 GLSL，再映射到 FFmpeg geq/hwupload 滤镜。

```rust
// src/vfx/transpiler.rs（可选模块，Phase 6+）

use naga::front::wgsl;
use naga::back::glsl;

/// WGSL → GLSL 片段着色器翻译
pub fn wgsl_to_glsl(wgsl_source: &str) -> Result<String, VfxError> {
    // 1. naga 解析 WGSL
    let module = wgsl::parse_str(wgsl_source)
        .map_err(|e| VfxError::TranspileError(format!("WGSL 解析: {}", e)))?;

    // 2. naga 验证
    let info = naga::valid::ModuleInfo::new(&module);
    naga::valid::Validator::new(
        naga::valid::Capabilities::empty(),
        naga::valid::ValidationStage::Full,
    ).validate(&module, &info)
        .map_err(|e| VfxError::TranspileError(format!("WGSL 验证: {}", e)))?;

    // 3. 生成 GLSL (ES 3.0 / 4.50)
    let options = glsl::Options {
        version: glsl::Version::Es(300),
        writer_flags: glsl::WriterFlags::empty(),
        binding_map: Default::default(),
    };
    let mut glsl_output = String::new();
    glsl::write(&module, &info, &options, &mut glsl_output)
        .map_err(|e| VfxError::TranspileError(format!("GLSL 生成: {}", e)))?;

    Ok(glsl_output)
}
```

**GLSL → FFmpeg geq 桥接**（有限，仅适用于简单像素变换）：

```
GLSL 片段着色器:
  uniform float u_intensity;
  uniform vec2 u_resolution;
  void main() {
    vec2 uv = gl_FragCoord.xy / u_resolution;
    vec4 c = texture2D(u_input_tex, uv);
    gl_FragColor = c * (1.0 + u_intensity);
  }

FFmpeg geq 等价:
  geq=lum='lum(X,Y)*(1+$intensity)':cr='r(X,Y)*(1+$intensity)':cb='b(X,Y)*(1+$intensity)'
```

**局限性**：geq 只能做逐像素变换，不支持纹理采样（除输入帧本身）、多 pass、模糊等。复杂特效必须用方案 A（双后端冗余）。

**首版决策**：采用方案 A（双后端冗余），方案 B 作为 Phase 6+ 增强可选。

### 4.4 着色器版本管理

不同 GPU 后端的能力差异通过 WebGPU feature 机制管理：

```ts
// packages/engine/src/vfx_runtime.ts

/** 检测当前 GPU 设备支持的能力 */
export function detectGpuCapabilities(device: GPUDevice): GpuCapabilities {
  return {
    // 基础能力（所有 WebGPU 设备必须支持）
    maxTextureDimension2D: device.limits.maxTextureDimension2D,
    maxUniformBufferBindingSize: device.limits.maxUniformBufferBindingSize,
    maxBufferSize: device.limits.maxBufferSize,

    // 可选能力（影响特效可用性）
    supportsFloat16: device.features.has('shader-f16'),
    supportsTimestampQuery: device.features.has('timestamp-query'),
    supportsDepthTexture: device.features.has('depth-32float-stencil8'),

    // 后端标识（Chromium 不直接暴露，通过适配器信息推断）
    backend: inferBackend(device.adapterInfo),
  };
}

function inferBackend(info: GPUAdapterInfo): 'd3d12' | 'metal' | 'vulkan' | 'unknown' {
  // Windows → d3d12, macOS → metal, Linux → vulkan
  if (info.architecture?.includes('D3D12')) return 'd3d12';
  if (info.architecture?.includes('Metal')) return 'metal';
  if (info.architecture?.includes('Vulkan')) return 'vulkan';
  return 'unknown';
}
```

**manifest.gpu_tier 与设备能力的映射**：

| gpu_tier | 需要的设备能力 | 不满足时 |
|---|---|---|
| `low` | 基础 WebGPU（无额外 feature） | 无法预览（退回 extractFrame） |
| `medium` | 基础 + `timestamp-query`（可选） | 预览可用但无帧计时 |
| `high` | 基础 + `shader-f16` + 大纹理 | 不满足 → 降级预览到 FFmpeg |

### 5.2 运行时隔离

| 隔离维度 | 机制 | 说明 |
|---|---|---|
| 文件隔离 | `.aifx` 包存于 `{app_data}/vfx/{id}/` 沙盒 | 与主程序包物理隔离 |
| GPU 资源隔离 | 每个特效独立 Pipeline + Bind Group | 不共享 pipeline state |
| Uniform 隔离 | 每帧独立 Uniform Buffer | 不复用 buffer，避免竞态 |
| 纹理池隔离 | 特效纹理从包内 `assets/` 加载 | 不使用引擎内置纹理池 |
| 内存限制 | 单特效 uniform buffer < 64KB | 超过拒绝加载 |
| 纹理限制 | 特效纹理 ≤ 2048×2048 | 超过拒绝加载 |
| 执行时间限制 | 单帧单特效 ≤ 8ms（720p） | 超过跳帧 |

### 5.3 异常处理：着色器崩溃不拖垮引擎

WebGPU 的着色器执行发生在 GPU 端。可能的异常：

| 异常类型 | 检测方式 | 处理策略 |
|---|---|---|
| 着色器编译失败 | `compilationInfo().type=error` | 拒绝加载 + 降级链 |
| Pipeline 创建失败 | `createRenderPipeline` 抛异常 | 降级链 |
| GPU 设备丢失 | `device.lost` 事件 | 重建所有 pipeline + 着色器 |
| 着色器执行超时 | 帧级计时超过预算 | 跳帧 + 标记慢特效 |
| 驱动级 TDR（GPU 超时恢复） | Windows TDR 检测 | 全引擎暂停 + 恢复重建 |
| 着色器无限循环 | 预扫描禁止 + 运行期超时 | 防止为主，检测为辅 |

**GPU 设备丢失处理**：

```ts
// packages/engine/src/vfx_runtime.ts

export class ShaderRuntime {
  private pipelineCache: Map<string, GPURenderPipeline> = new Map();
  private compileResults: Map<string, ShaderLoadResult> = new Map();
  private device: GPUDevice;

  constructor(device: GPUDevice) {
    this.device = device;

    // 监听设备丢失事件
    device.lost.then((info: GPUDeviceLostInfo) => {
      if (info.reason === 'destroyed') {
        // 主动销毁，忽略
        return;
      }
      // 意外丢失 → 需要重建
      this.handleDeviceLost(info);
    });
  }

  private async handleDeviceLost(info: GPUDeviceLostInfo) {
    logError(`[vfx] GPU 设备丢失: reason=${info.reason}, message=${info.message}`);

    // 清空所有缓存（pipeline 不再可用）
    this.pipelineCache.clear();
    this.compileResults.clear();

    // 通知 PreviewEngine 重建设备
    // PreviewEngine 重新获取 navigator.gpu → requestAdapter → requestDevice
    // 重建后重新编译所有活跃特效
  }

  /** 安全执行单个特效渲染 pass */
  safeExecute(
    pass: GPURenderPassEncoder,
    vfxId: string,
    params: Record<string, number>,
  ): boolean {
    const pipeline = this.pipelineCache.get(vfxId);
    if (!pipeline) {
      // 降级：跳过此特效
      logWarn(`[vfx] 特效 ${vfxId} pipeline 不可用，跳过`);
      return false;
    }

    try {
      pass.setPipeline(pipeline);
      // ... bind group 设置 ...
      pass.draw(3);
      return true;
    } catch (e) {
      // 异常捕获：标记此特效为 CRASHED，后续帧跳过
      logError(`[vfx] 特效 ${vfxId} 执行异常: ${e}`);
      this.compileResults.set(vfxId, ShaderLoadResult.PipelineFailed({
        error: String(e),
      }));
      this.pipelineCache.delete(vfxId);
      return false;
    }
  }
}
```

export class ShaderManager {
  // 内置 pipeline 缓存（编译期创建，永不失效）
  private builtinPipelines: Map<string, GPURenderPipeline> = new Map();
  // 外部 pipeline 缓存（运行期创建，可失效）
  private vfxPipelines: Map<string, GPURenderPipeline> = new Map();
  // 内置 uniform layout（硬编码）
  private builtinLayouts: Map<string, UniformLayout> = BUILTIN_UNIFORM_LAYOUTS;
  // 外部 uniform layout（从 N-API 获取）
  private vfxLayouts: Map<string, UniformLayout> = new Map();

  /** 判断是否为内置特效 */
  isBuiltin(kind: string): boolean {
    return BUILTIN_EFFECT_KINDS.includes(kind);
  }

  /** 统一获取 pipeline */
  getPipeline(kind: string): GPURenderPipeline | null {
    if (this.isBuiltin(kind)) {
      return this.builtinPipelines.get(kind);
    }
    return this.vfxPipelines.get(kind);
  }

  /** 统一获取 uniform layout */
  getLayout(kind: string): UniformLayout | null {
    if (this.isBuiltin(kind)) {
      return this.builtinLayouts.get(kind);
    }
    return this.vfxLayouts.get(kind);
  }
}

### 6.3 回退机制

当着色器不可用时（编译失败/扫描拒绝/设备丢失），需要回退到 FFmpeg 滤镜路径：

```
着色器可用？
    │
    ├── YES → WebGPU 实时预览（最优）
    │
    └── NO → 判断特效类型
              │
              ├── 内置特效 → FFmpeg 滤镜预览
              │   (extractFrame + 内置 filter_spec)
              │   Phase 5 之前的现有行为
              │
              ├── 外部特效（有 ffmpeg/filter.spec）→ FFmpeg 滤镜预览
              │   (extractFrame + vfx::build_filter_spec)
              │
              ├── 外部特效（无 ffmpeg/filter.spec）→ 跳过此特效
              │   (预览中不应用，导出时也不应用)
              │
              └── navigator.gpu 不可用 → 全引擎退回 extractFrame
                  (Phase 5 之前的现有行为)
```

```ts
// packages/engine/src/App.tsx (Phase 5 扩展)

function PreviewPanel({ project }: { project: Project }) {
  const hasWebGPU = 'gpu' in navigator;

  if (hasWebGPU) {
    return <WebGPUPreview project={project} />;
  }
  // 回退：Phase 5 之前的 extractFrame 预览
  return <FFmpegFramePreview project={project} />;
}
```

Rust 侧回退逻辑（导出路径不受影响）：

```rust
// src/vfx/integration.rs

/// 构建滤镜 spec（被 filters::build_filter_spec 调用）
/// 预览失败不影响导出——导出始终走 FFmpeg 路径
pub fn build_filter_spec(
    kind: &str,
    params: &HashMap<String, f64>,
) -> Option<String> {
    let entry = crate::vfx::registry().lookup_by_kind(kind)?;

    // 外部特效有 ffmpeg/filter.spec → 用模板替换
    if let Some(ref template) = entry.ffmpeg_spec {
        return Some(inflate_template(template, params, &entry.manifest));
    }

    // 外部特效无 ffmpeg/filter.spec 且 WGSL 编译失败 → 导出时跳过
    // 返回 None → filters::build_filter_spec 跳过此特效
    None
}
```

| GPU 设备丢失重建耗时 | 预览中断数秒 | 逐步重建（先恢复内置，再异步恢复外部） |

| 第三方特效开发者学习成本 | WGSL 模板规范限制自由度 | 提供标准模板 + 文档 + 示例特效包 + 校验工具 CLI |
