## 一、磁吸与吸附（Snapping）

### 1.1 截图概述
截图 159、160、161 为剪映专业版主编辑界面，三张几乎一致，仅时间线工具栏中部分按钮状态存在细微差异。三张共同呈现了：
- **顶部菜单栏**：媒体、音频、文本、贴纸、模板、追踪、调节、特效、滤镜、更多
- **左侧素材库**：音频 → 精选音乐分类（电子音乐、节日场景、忧伤治愈、欢快生活、运动节拍、影视综艺等）
- **中间预览窗**：女性水中画面，叠加胶片颗粒滤镜
- **右侧 AI 配乐面板**：基础 / 均衡器 / 音源 / 混响 / 房间预设，悬浮提示「系统支持滑动放大操作了」
- **底部时间线**：5 条轨道（主轨+4 条辅轨），含 1 条音频波纹（蓝色 The-girl）、1 条红色主轨音频、3 条视频片段（紫、青、长彩条）

### 1.2 功能点
磁吸吸附是剪映时间线编辑中的辅助对齐功能。当用户拖动素材、文本、贴纸或音频片段，系统自动检测相邻片段的边缘、播放头、标尺标记点，并在距离阈值内产生吸附效果，帮助精确对齐。

剪映中明确存在**两层独立开关**（来自快捷键面板佐证）：
1. **吸附开关**（全局）：控制是否启用片段间的磁吸吸附
2. **主轨磁吸**：控制是否将辅助轨片段吸附到主轨位置
3. **联动开关**：控制多片段编辑时的联动行为
4. **预览轴开关**：控制预览轴的显示状态

### 1.3 触发方式
- **工具栏按钮**：时间线区域上方工具栏（截图 159-161 可见，约为播放控制按钮组的右侧）有磁吸/吸附相关图标，点击可切换开启/关闭。
- **快捷键触发**（来自快捷键面板）：
  - `P` → 主轨磁吸
  - `N` → 吸附开关
  - `~`（波浪号）→ 联动开关
  - `S` → 预览轴开关
- **菜单路径**：未在截图中明显出现，推测在「设置 → 编辑偏好」或「视图」菜单中可调。

### 1.4 参数选项
- **磁吸总开关（N）**：全局启用/关闭吸附行为。
- **主轨磁吸（P）**：独立于总开关的子模式，决定是否仅对主轨道进行吸附。
- **联动开关（~）**：多选片段时整体移动/编辑的联动行为。
- **吸附灵敏度**：在截图中未直接显示调节滑块，但根据剪映工程实现惯例，应在偏好设置中可调（距离阈值）。
- **对齐对象**：未在截图中显示独立面板，推测默认对齐：片段头、片段尾、播放头、标尺、标记点。

### 1.5 交互细节
- **视觉反馈**：拖动片段靠近吸附点时，剪映通常会显示**高亮竖线**（红/黄色）标识当前对齐位置。截图 159-161 中时间线静止未拖拽，故未捕捉到吸附线高亮态。
- **轨道结构**：截图显示 5 条轨道，其中下方蓝色音频波纹为长波形，上方视频片段呈密集缩略图排列，磁吸在这种密集多轨场景下尤为重要。
- **轨道高度控制**：可通过 `Ctrl+Alt++` / `Ctrl+Alt+-` 快捷键临时调高/降低轨道，便于精细吸附操作（来自快捷键面板 S4）。
- **关闭磁吸后的行为**：可实现素材的"自由"拖动，避免误吸附，便于精细微调。
- **三张截图差异**：三张图整体布局完全相同，差异主要在底部状态栏时间戳（159=19:25:00 / 160=19:25:30 / 161=19:25:55）以及时间线工具栏图标的高亮/非高亮状态——表明用户在演示磁吸开启/关闭或不同子模式时的切换效果。
