# AIcut 特效素材热更新系统设计

> 调研依据：`deepseek剪映资料复刻.txt` 第三个问答（素材标准化打包 / 云端分发与增量更新 / 本地安全加载 / 引擎侧加载与渲染集成）
> 现状依据：`CLAUDE.md` + `src/mcp.rs` + `src/provider.rs` + `src/preset.rs` + `src/filters.rs` + `src/subtitle.rs` + `src/types.rs` + `docs/AIcut设计方案_Phase5_草案.md`
> 目标：让 AIcut 能像剪映一样从云端下载并加载新的视频特效、滤镜、贴纸、转场等资源，在不更新 App 本体的前提下持续扩展特效生态。
> 双渲染路径适配：FFmpeg 导出（CPU 滤镜链）+ WebGPU 预览（WGSL 着色器，Phase 5）。

## 0. 背景与现状诊断

### 0.1 现状

| 维度 | 现状 | 局限 |
|---|---|---|
| 滤镜注册表 | `src/filters.rs:66 REGISTRY: OnceLock<Vec<FilterDef>>`，编译期固化 15 个内置滤镜 | 无法运行期新增；新增必须改源码重新发版 |
| 预置包 | `src/preset.rs:18 FILTER_PRESETS: &[PresetPack]`，5 个静态预置 | 同上，无法运营动态下发 |
| 特效数据模型 | `src/types.rs:14 Effect { kind, params, enabled }`，`kind` 字符串查 `filters::lookup` | `kind` 仅能匹配内置 15 种；外部 `.aifx` 包无法命中 |
| 渲染出口 | `src/filters.rs:270 build_filter_spec` 返回 FFmpeg 滤镜串 | 仅支持 FFmpeg 滤镜语法；无法加载外部着色器 |
| 预览 | Phase 5 WebGPU 合成器使用硬编码 `effects.wgsl.ts` | 无法运行期加载新 WGSL 着色器 |
| MCP 工具 | `src/mcp.rs:33 list_tools` 7 个工具，无特效管理类工具 | AI Agent 无法触发下载/应用特效 |
| 字幕资源处理 | `src/subtitle.rs` 把样式硬编码到 `SubtitleStyle` | 无外部素材加载机制可参考 |

### 0.2 设计目标

1. **标准化打包**：定义 `.aifx` 包格式，自描述、可扩展、跨渲染后端
2. **云端分发**：清单驱动的增量更新，支持按需下载与 Wi-Fi 预加载
3. **安全加载**：签名校验 + 着色器静态扫描 + 沙盒存储
4. **双后端运行**：同一份 `.aifx` 包同时驱动 FFmpeg 导出 与 WebGPU 预览
5. **生命周期**：LRU 缓存 + 资源锁定，500MB 上限自动清理
6. **MCP 集成**：新增 `list_vfx / download_vfx / apply_vfx` 工具，AI Agent 可调用

### 0.3 设计原则

- **Rust 主导**：包管理、清单同步、安全扫描、LRU 全在 Rust 侧；TS 仅负责 UI 与 WebGPU 着色器注入
- **薄接口、厚内核**：N-API 暴露少量高层 API，复杂逻辑全在 `src/vfx/` 模块内
- **渐进式**：先跑通"下载→校验→加载→FFmpeg 应用"主路径，再补 WebGPU 着色器注入与预热
- **不破坏现状**：`filters.rs` 静态注册表保留为"内置快速路径"，`.aifx` 为"动态扩展路径"，两者在 `build_filter_spec` 层统一合并
- **失败可降级**：包损坏 / 签名失败 / 着色器编译失败时，回退到内置滤镜或跳过，不阻塞渲染

## 2. 素材标准化打包：`.aifx` 包格式

### 2.1 包结构

`.aifx` 本质是 ZIP 压缩包，扩展名用于系统关联。包内固定结构：

```
magic_wand.aifx (ZIP)
│
├── manifest.json        # 【核心】特效说明书（必须，签名覆盖此文件）
├── signature.bin        # manifest.json 的 HMAC-SHA256 签名（必须）
├── thumbnail.png        # 预览图，商店面板展示（必须，≤ 256×256, ≤ 100KB）
├── preview.mp4          # 可选，特效演示视频（≤ 3s, ≤ 500KB）
│
├── shader/              # 着色器脚本（至少一个后端必须）
│   ├── effect.wgsl      # WebGPU 预览着色器（WGSL 片段）
│   ├── effect.frag      # GLSL 片段着色器（跨平台备选）
│   └── effect.json      # 着色器元数据（uniform 绑定点、纹理槽位）
│
├── ffmpeg/              # FFmpeg 导出路径（可选，与 shader 至少一个）
│   └── filter.spec      # FFmpeg 滤镜链模板（含 $param 占位符）
│
└── assets/              # 辅助素材
    ├── noise.png        # 噪点纹理
    ├── lut.cube         # LUT 文件
    └── mask.png         # 蒙版图
```

设计要点：

- **多后端冗余**：同一份特效可同时提供 `wgsl` + `frag` + `ffmpeg` 三种后端实现，运行期按渲染路径选择。最少必须提供一个；若仅提供 `ffmpeg`，预览时降级到 FFmpeg 抽帧（Phase 5 之前的行为）
- **着色器优先**：若同时存在 `shader/` 与 `ffmpeg/`，导出优先用 `ffmpeg/filter.spec`（保证画质与性能），预览优先用 `shader/effect.wgsl`（保证实时性）
- **资源引用**：`manifest.json` 与着色器中所有资源路径均使用包内相对路径（如 `assets/noise.png`），由加载器解析为绝对路径

```rust
    Int,

    Vec2,
    Vec3,
    Vec4,

    pub duration: f64,

    pub period: Option<f64>,

    pub name: String,             // uniform 采样器名
    pub path: String,             // 包内相对路径
    #[serde(default = "default_wrap")]
    pub wrap: String,             // "repeat" | "clamp" | "mirror"
    #[serde(default = "default_filter")]
    pub filter: String,           // "linear" | "nearest"

fn default_wrap() -> String { "repeat".into() }
fn default_filter() -> String { "linear".into() }

impl VfxManifest {
    /// 校验 manifest 自身完整性（不含签名）
    pub fn validate(&self) -> Result<(), String> {
        if self.id.is_empty() { return Err("id 不能为空".into()); }
        if !self.id.starts_with("com.aicut.") { return Err("id 必须以 com.aicut. 开头".into()); }
        if self.name.is_empty() { return Err("name 不能为空".into()); }
        if semver::Version::parse(&self.version).is_err() {
            return Err(format!("version '{}' 不是合法 semver", self.version));
        }
        if self.render_backends.ffmpeg.is_none()
            && self.render_backends.wgsl.is_none()
            && self.render_backends.glsl.is_none() {
            return Err("render_backends 至少需要一项".into());
        }
        if self.parameters.iter().any(|p| p.name.is_empty()) {
            return Err("parameter.name 不能为空".into());
        }
        Ok(())
    }

    /// 获取参数的默认值映射（用于初始化 Effect::params）
    pub fn default_params(&self) -> HashMap<String, f64> {
        let mut map = HashMap::new();
        for p in &self.parameters {
            let v = match p.param_type {
                ParamType::Float | ParamType::Int => p.default.as_f64().unwrap_or(0.0),
                ParamType::Bool => if p.default.as_bool().unwrap_or(false) { 1.0 } else { 0.0 },
                _ => 0.0, // color/vec 类型在 WebGPU 侧单独处理
            };
            map.insert(p.name.clone(), v);
        }
        map
    }
}
```

### 2.4 FFmpeg 滤镜模板语法

`ffmpeg/filter.spec` 是带占位符的 FFmpeg 滤镜串模板。占位符语法 `$param_name`，由 `build_filter_spec` 替换为用户当前参数值：

```
# magic_wand/ffmpeg/filter.spec 示例
# 用 geq 实现魔法光晕叠加
geq=lum='lum(X,Y)+if(gt(noise($intensity*X+$intensity*Y),0.5),80,0)':cr='r(X,Y)+20:g(X,Y)+10:b(X,Y)+30'
```

模板支持条件块（高级特性，可选）：

```
#if $intensity > 0.5
geq=lum='...'
#else
eq=brightness=0.1
#endif
```

```rust
/// 增量计算结果
#[derive(Debug, Clone)]
pub struct SyncDelta {
    pub to_install: Vec<CatalogItem>,    // 本地没有
    pub to_update: Vec<(InstalledItem, CatalogItem)>, // 本地有但版本旧
    pub to_remove: Vec<InstalledItem>,   // 本地有但云端已下架（可选策略）
    pub up_to_date: Vec<InstalledItem>,  // 版本一致
}

/// 对比云端清单与本地清单
pub fn compute_delta(
    cloud: &CloudCatalog,
    local: &InstalledRegistry,
    app_version: &str,
) -> SyncDelta {
    let mut delta = SyncDelta {
        to_install: vec![],
        to_update: vec![],
        to_remove: vec![],
        up_to_date: vec![],
    };

    for item in &cloud.items {
        // 兼容性过滤：min_app_version > 当前版本则跳过
        if !version_satisfies(app_version, &item.min_app_version) {
            continue;
        }

        match local.installed.iter().find(|i| i.id == item.id) {
            None => delta.to_install.push(item.clone()),
            Some(installed) => {
                if version_lt(&installed.version, &item.version) {
                    delta.to_update.push((installed.clone(), item.clone()));
                } else {
                    delta.up_to_date.push(installed.clone());
                }
            }
        }
    }

    // 云端已下架的本地包（可选：保留 / 删除）
    for installed in &local.installed {
        if !cloud.items.iter().any(|c| c.id == installed.id) {
            delta.to_remove.push(installed.clone());
        }
    }

    delta
}

fn version_satisfies(app: &str, required: &str) -> bool {
    // 简化实现：用 semver 比较
    let app_v = semver::Version::parse(app).unwrap_or(semver::Version::new(0, 0, 0));
    let req_v = semver::Version::parse(required).unwrap_or(semver::Version::new(0, 0, 0));
    app_v >= req_v
}

fn version_lt(a: &str, b: &str) -> bool {
    let va = semver::Version::parse(a).ok();
    let vb = semver::Version::parse(b).ok();
    match (va, vb) {
        (Some(va), Some(vb)) => va < vb,
        _ => a < b,
    }
}
```

```rust
// src/vfx/package.rs

/// 下载并校验包完整性
pub async fn download_and_verify(item: &CatalogItem, dest: &Path) -> Result<(), VfxError> {
    // 1. HTTP 下载
    let bytes = http_get(&item.package_url).await?;

    // 2. 整包 SHA256 校验
    let hash = sha256(&bytes);
    if hash != item.package_sha256 {
        return Err(VfxError::ChecksumMismatch {
            expected: item.package_sha256.clone(),
            actual: hash,
        });
    }

    // 3. 写入临时文件
    let tmp = dest.with_extension("tmp");
    fs::write(&tmp, &bytes)?;

    // 4. 解压 + manifest 签名校验
    verify_package(&tmp, &item.manifest_sha256)?;

    // 5. 原子重命名
    fs::rename(&tmp, dest)?;

    Ok(())
}
```

### 4.2 签名校验

采用 HMAC-SHA256 对 `manifest.json` 签名，密钥由服务端持有，客户端内嵌公钥用于验证。

```rust
// src/vfx/security.rs

use sha2::{Sha256, Digest};
use hmac::{Hmac, Mac};

type HmacSha256 = Hmac<Sha256>;

/// 内嵌的验证密钥（实际应从编译期注入，非硬编码）
const VFX_SIGNING_KEY: &[u8] = include_bytes!("../keys/vfx_signing.key");

/// 校验 manifest.json 签名
pub fn verify_manifest_signature(
    manifest_bytes: &[u8],
    signature_bytes: &[u8],
) -> Result<(), VfxError> {
    let mut mac = HmacSha256::new_from_slice(VFX_SIGNING_KEY)
        .map_err(|_| VfxError::CryptoError("HMAC key error".into()))?;
    mac.update(manifest_bytes);
    mac.verify_slice(signature_bytes)
        .map_err(|_| VfxError::SignatureInvalid)
}

/// 生成签名（仅供工具使用，运行期不需要）
pub fn sign_manifest(manifest_bytes: &[u8]) -> Vec<u8> {
    let mut mac = HmacSha256::new_from_slice(VFX_SIGNING_KEY).unwrap();
    mac.update(manifest_bytes);
    mac.finalize().into_bytes().to_vec()
}
```

签名覆盖范围：仅 `manifest.json`。着色器与资源文件不单独签名——它们的完整性由 `manifest.checksum`（整包 SHA256）保证。攻击者若篡改着色器但不改 manifest，SHA256 校验会失败；若同时改 manifest，签名校验会失败。

```rust
        }
    }
    max_depth
}
```

### 4.4 LRU 缓存管理

```rust
// src/vfx/cache.rs

use std::time::{SystemTime, UNIX_EPOCH};

/// 更新某包的最后使用时间
pub fn touch_package(id: &str) -> Result<(), VfxError> {
    let mut registry = load_installed_registry()?;
    if let Some(item) = registry.installed.iter_mut().find(|i| i.id == id) {
        item.last_used = now_iso();
    }
    save_installed_registry(&registry)?;
    Ok(())
}

/// 执行 LRU 清理
/// 返回被清理的包 id 列表
pub fn evict_lru() -> Result<Vec<String>, VfxError> {
    let mut registry = load_installed_registry()?;
    let mut evicted = Vec::new();

    // 超过容量上限才清理
    while registry.total_cache_size > registry.cache_limit {
        // 找到最久未使用且未锁定的包
        let candidate_idx = registry.installed.iter()
            .enumerate()
            .filter(|(_, i)| !i.locked)
            .min_by_key(|(_, i)| i.last_used.clone())
            .map(|(idx, _)| idx);

        match candidate_idx {
            Some(idx) => {
                let item = registry.installed.remove(idx);
                // 删除包目录
                let dir = package_dir(&item.id);
                if let Err(e) = std::fs::remove_dir_all(&dir) {
                    eprintln!("[vfx] 删除包目录失败 {:?}: {}", dir, e);
                }
                registry.total_cache_size -= item.size_bytes;
                evicted.push(item.id.clone());
            }
            None => break,  // 所有包都被锁定，无法清理
        }
    }

    save_installed_registry(&registry)?;
    Ok(evicted)
}

/// 锁定/解锁某包（工程打开时锁定，关闭时解锁）
pub fn set_package_locked(id: &str, locked: bool) -> Result<(), VfxError> {
    let mut registry = load_installed_registry()?;
    if let Some(item) = registry.installed.iter_mut().find(|i| i.id == id) {
        item.locked = locked;
    }
    save_installed_registry(&registry)?;
    Ok(())
}

fn now_iso() -> String {
    let secs = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .unwrap_or_default()
        .as_secs();
    format!("{}", secs)  // 简化：实际用 chrono
}
```

LRU 清理触发时机：

1. **下载新包前**：预估下载后总容量，若超限则先清理
2. **App 启动时**：清理上次异常退出可能遗留的临时文件
3. **工程关闭时**：解锁所有包，执行一次轻量清理

```rust
// src/vfx/registry.rs

use std::collections::HashMap;
use std::sync::{Arc, RwLock};
use crate::vfx::manifest::VfxManifest;

/// 运行期 vfx 注册表（已加载到内存的 .aifx 包）
pub struct VfxRegistry {
    /// id → 已加载的 manifest
    entries: RwLock<HashMap<String, Arc<VfxEntry>>>,
}

/// 一个已加载的 vfx 包
pub struct VfxEntry {
    pub manifest: VfxManifest,
    pub package_dir: std::path::PathBuf,
    /// FFmpeg 滤镜模板（已从 filter.spec 读入）
    pub ffmpeg_spec: Option<String>,
    /// WGSL 着色器源码（已读入）
    pub wgsl_source: Option<String>,
    /// GLSL 着色器源码
    pub glsl_source: Option<String>,
    /// 编译状态（用于 WebGPU 预热）
    pub compile_state: RwLock<CompileState>,
}

#[derive(Debug, Clone)]
pub enum CompileState {
    NotCompiled,
    Compiling,
    Compiled,           // 编译成功，可立即使用
    Failed(String),     // 编译失败，回退到 FFmpeg
}

impl VfxRegistry {
    pub fn new() -> Self {
        Self { entries: RwLock::new(HashMap::new()) }
    }

    /// 从磁盘加载一个 .aifx 包到注册表
    pub fn load(&self, id: &str) -> Result<Arc<VfxEntry>, VfxError> {
        // 1. 检查是否已加载
        if let Some(entry) = self.entries.read().unwrap().get(id).cloned() {
            return Ok(entry);
        }

        // 2. 读 manifest
        let pkg_dir = crate::vfx::cache::package_dir(id);
        let manifest_path = pkg_dir.join("manifest.json");
        let manifest_bytes = std::fs::read(&manifest_path)?;
        let manifest: VfxManifest = serde_json::from_slice(&manifest_bytes)?;

        // 3. 签名校验
        let sig_path = pkg_dir.join("signature.bin");
        let sig_bytes = std::fs::read(&sig_path)?;
        crate::vfx::security::verify_manifest_signature(&manifest_bytes, &sig_bytes)?;

        // 4. 读渲染后端资源
        let ffmpeg_spec = manifest.render_backends.ffmpeg.as_ref()
            .map(|p| std::fs::read_to_string(pkg_dir.join(p)))
            .transpose()?;
        let wgsl_source = manifest.render_backends.wgsl.as_ref()
            .map(|p| std::fs::read_to_string(pkg_dir.join(p)))
            .transpose()?;
        let glsl_source = manifest.render_backends.glsl.as_ref()
            .map(|p| std::fs::read_to_string(pkg_dir.join(p)))
            .transpose()?;

        // 5. 着色器静态扫描
        if let Some(ref wgsl) = wgsl_source {
            let report = crate::vfx::security::scan_shader(wgsl, crate::vfx::security::ShaderType::Wgsl);
            if !report.passed {
                return Err(VfxError::ShaderScanFailed(report.violations.join("; ")));
            }
        }
        if let Some(ref glsl) = glsl_source {
            let report = crate::vfx::security::scan_shader(glsl, crate::vfx::security::ShaderType::GlslFrag);
            if !report.passed {
                return Err(VfxError::ShaderScanFailed(report.violations.join("; ")));
            }
        }

        // 6. 注册
        let entry = Arc::new(VfxEntry {
            manifest: manifest.clone(),
            package_dir: pkg_dir.clone(),
            ffmpeg_spec,
            wgsl_source,
            glsl_source,
            compile_state: RwLock::new(CompileState::NotCompiled),
        });

        self.entries.write().unwrap().insert(id.to_string(), entry.clone());

        // 7. 更新 last_used
        let _ = crate::vfx::cache::touch_package(id);

        Ok(entry)
    }

    /// 按 id 查找已加载的 entry
    pub fn lookup(&self, id: &str) -> Option<Arc<VfxEntry>> {
        self.entries.read().unwrap().get(id).cloned()
    }

    /// 按 kind 字符串查找（用于与 filters::build_filter_spec 集成）
    /// kind 可以是 "com.aicut.vfx.magic_wand" 或简写 "magic_wand"
    pub fn lookup_by_kind(&self, kind: &str) -> Option<Arc<VfxEntry>> {
        let entries = self.entries.read().unwrap();
        // 完整 id 匹配
        if let Some(e) = entries.get(kind) {
            return Some(e.clone());
        }
        // 简写匹配：取 id 最后一段
        entries.values().find(|e| {
            e.manifest.id.rsplit('.').next() == Some(kind)
        }).cloned()
    }

    /// 卸载某包（用于 LRU 清理后刷新）
    pub fn unload(&self, id: &str) {
        self.entries.write().unwrap().remove(id);
    }
}

/// 全局单例
static VFX_REGISTRY: std::sync::OnceLock<VfxRegistry> = std::sync::OnceLock::new();

pub fn registry() -> &'static VfxRegistry {
    VFX_REGISTRY.get_or_init(VfxRegistry::new)
}
```

```rust
// src/vfx/integration.rs

/// 为 vfx 特效构建 FFmpeg 滤镜串
/// （被 filters::build_filter_spec 调用）
pub fn build_filter_spec(
    kind: &str,
    params: &HashMap<String, f64>,
) -> Option<String> {
    let entry = registry().lookup_by_kind(kind)?;
    let template = entry.ffmpeg_spec.as_ref()?;

    // 替换模板中的 $param 占位符
    let mut spec = template.clone();
    for p in &entry.manifest.parameters {
        let value = params.get(&p.name)
            .copied()
            .unwrap_or_else(|| p.default.as_f64().unwrap_or(0.0));
        let placeholder = format!("${}", p.name);
        let replacement = format_float(value);
        spec = spec.replace(&placeholder, &replacement);
    }

    Some(spec)
}

fn format_float(v: f64) -> String {
    // 复用 filters::fmt 的格式化逻辑
    crate::filters::fmt(v)
}
```

```ts
// packages/engine/src/vfx_preview.ts（伪代码）

export async function preloadVfx(device: GPUDevice, vfxId: string): Promise<void> {
  // 1. 从 Rust 侧获取 WGSL 源码
  const wgsl = await napi.vfx_get_wgsl_source(vfxId);
  if (!wgsl) return;

  // 2. 编译着色器模块
  const module = device.createShaderModule({ code: wgsl });

  // 3. 创建 pipeline
  const pipeline = device.createRenderPipeline({
    layout: 'auto',
    vertex: { module, entryPoint: 'vs_main' },
    fragment: { module, entryPoint: 'fs_main', targets: [{ format: 'bgra8unorm' }] },
  });

  // 4. 离屏渲染预热（1×1 纹理，跑一次）
  const dummyTex = device.createTexture({
    size: [1, 1], format: 'bgra8unorm', usage: GPUTextureUsage.RENDER_ATTACHMENT,
  });
  const encoder = device.createCommandEncoder();
  const pass = encoder.beginRenderPass({
    colorAttachments: [{ view: dummyTex.createView(), loadOp: 'clear', storeOp: 'store' }],
  });
  pass.setPipeline(pipeline);
  pass.draw(3);
  pass.end();
  device.queue.submit([encoder.finish()]);

  // 5. 缓存 pipeline
  vfxPipelineCache.set(vfxId, pipeline);
  await device.queue.onSubmittedWorkDone();

  // 6. 通知 Rust 侧编译完成
  await napi.vfx_set_compiled(vfxId);
}
```

### 5.6 运行时渲染（参数 → uniform 实时更新）

```ts
// packages/engine/src/vfx_preview.ts（伪代码）

export function applyVfxParams(
  device: GPUDevice,
  vfxId: string,
  params: Record<string, number>,
): GPUBindGroup {
  const pipeline = vfxPipelineCache.get(vfxId)!;
  const layout = vfxUniformLayoutCache.get(vfxId)!;

  // 创建 uniform buffer
  const uniformData = new Float32Array(layout.length * 4);  // 每个参数 16 字节对齐
  layout.forEach((binding, i) => {
    const value = params[binding.param_name] ?? 0;
    uniformData[i * 4] = value;
  });

  const uniformBuffer = device.createBuffer({
    size: uniformData.byteLength,
    usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST,
  });
  device.queue.writeBuffer(uniformBuffer, 0, uniformData);

  return device.createBindGroup({
    layout: pipeline.getBindGroupLayout(0),
    entries: [{ binding: 0, resource: { buffer: uniformBuffer } }],
  });
}

// 渲染循环
function renderFrame(device: GPUDevice, pass: GPURenderPassEncoder, clip: Clip) {
  for (const effect of clip.effects) {
    const vfxId = effect.kind;
    if (!vfxPipelineCache.has(vfxId)) continue;

    const pipeline = vfxPipelineCache.get(vfxId)!;
    const bindGroup = applyVfxParams(device, vfxId, effect.params);
    pass.setPipeline(pipeline);
    pass.setBindGroup(0, bindGroup);
    pass.draw(3);
  }
}
```

```rust
        Err(e) => ToolResponse { success: false, result: None, error: Some(e.to_string()) },
    }
}
"apply_vfx" => {
    let clip_id = request.arguments["clip_id"].as_str().unwrap_or("");
    let vfx_id = request.arguments["vfx_id"].as_str().unwrap_or("");
    let params: HashMap<String, f64> = request.arguments["params"].as_object()
        .map(|m| m.iter().filter_map(|(k, v)| v.as_f64().map(|f| (k.clone(), f))).collect())
        .unwrap_or_default();
    match crate::vfx::apply_to_clip(clip_id, vfx_id, params) {
        Ok(_) => ToolResponse { success: true, result: Some(json!({"applied": true})), error: None },
        Err(e) => ToolResponse { success: false, result: None, error: Some(e.to_string()) },
    }
}
"remove_vfx" => {
    let clip_id = request.arguments["clip_id"].as_str().unwrap_or("");
    let vfx_id = request.arguments["vfx_id"].as_str().unwrap_or("");
    match crate::vfx::remove_from_clip(clip_id, vfx_id) {
        Ok(_) => ToolResponse { success: true, result: Some(json!({"removed": true})), error: None },
        Err(e) => ToolResponse { success: false, result: None, error: Some(e.to_string()) },
    }
}
"get_vfx_status" => {
    let id = request.arguments["id"].as_str().unwrap_or("");
    match crate::vfx::package::get_status(id) {
        status => ToolResponse { success: true, result: Some(json!({"id": id, "status": status})), error: None },
    }
}
```

```rust
    let mut issues = Vec::new();
    for track in &project.tracks {
        for clip in &track.clips {
            for effect in &clip.effects {
                if let Some(ref vfx_id) = effect.vfx_id {
                    match registry().lookup(vfx_id) {
                        Some(entry) => {
                            // 检查版本

                                if used_ver != &entry.manifest.version {

                                        vfx_id: vfx_id.clone(),
                                        expected: used_ver.clone(),
                                        actual: entry.manifest.version.clone(),
                                    });
                                }
                            }
                        }
                        None => {
                            // 未安装，需要下载
                            issues.push(VfxCompatIssue::NotInstalled(vfx_id.clone()));
                        }
                    }
                }
            }
        }
    }
    issues
}
```

## 8. 安全模型总结

### 8.1 威胁模型

| 威胁 | 缓解措施 |
|---|---|
| 中间人攻击篡改下载包 | HTTPS 传输 + 整包 SHA256 校验 |
| 包内 manifest 被篡改（注入恶意参数） | HMAC-SHA256 签名校验 |
| 着色器包含死循环导致 GPU 挂起 | 静态扫描禁止 `while(true)` / `for(;;)` + 循环嵌套深度检测 |
| 着色器写入纹理破坏渲染管线 | 静态扫描禁止 `textureStore` / `imageStore` |
| 着色器访问未授权 builtin | 白名单校验 builtin 变量 |
| 包内文件路径穿越（如 `../../../etc/passwd`） | 解压时校验每个路径在沙盒内 |
| 恶意包耗尽磁盘空间 | LRU 500MB 上限 + 单包大小限制 |
| 重放攻击（旧版本包） | manifest 含 `updated_at` + 版本号单调递增校验 |

### 8.2 路径穿越防护

```rust
// src/vfx/package.rs

/// 解压时校验每个文件路径在目标目录内
fn safe_extract(zip_path: &Path, dest_dir: &Path) -> Result<(), VfxError> {
    let file = std::fs::File::open(zip_path)?;
    let mut archive = zip::ZipArchive::new(file)?;

    for i in 0..archive.len() {
        let mut entry = archive.by_index(i)?;
        let entry_path = entry.name().to_string();

        // 拼接完整路径
        let full_path = dest_dir.join(&entry_path);

        // 校验：解析后的路径必须在 dest_dir 内
        let canonical_dest = dest_dir.canonicalize()
            .map_err(|e| VfxError::IoError(e))?;
        let canonical_full = full_path.parent()
            .ok_or_else(|| VfxError::PackageCorrupt("无效路径".into()))?
            .canonicalize()
            .map_err(|e| VfxError::IoError(e))?;

        if !canonical_full.starts_with(&canonical_dest) {
            return Err(VfxError::PackageCorrupt(format!(
                "路径穿越检测: {} 试图逃逸沙盒", entry_path
            )));
        }

        // 解压文件
        let mut out = std::fs::File::create(&full_path)?;
        std::io::copy(&mut entry, &mut out)?;
    }
    Ok(())
}
```

## 10. 关键决策与权衡

### 10.1 为什么用 HMAC-SHA256 而非非对称签名？

- **HMAC-SHA256**：密钥内嵌在二进制中，攻击者逆向可提取，但需要重新编译才能伪造——对视频编辑器场景足够
- **RSA/Ed25519**：公钥内嵌，私钥服务器保管，更安全但实现复杂
- **决策**：MVP 用 HMAC-SHA256，后续可升级到 Ed25519。签名只防篡改，不防盗版（盗版不是本设计关注点）

### 10.2 为什么不用 GLSL 跨平台，而是同时支持 WGSL + GLSL？

- **WGSL**：WebGPU 原生，Phase 5 预览必需，无需转换
- **GLSL**：FFmpeg 侧若未来引入 GPU 滤镜可用，跨平台备选
- **决策**：包可同时包含两者，运行期按需选择。最少必须提供一个。若仅提供 WGSL，FFmpeg 导出降级到内置滤镜近似

### 10.3 为什么 FFmpeg 导出用模板而非着色器？

- FFmpeg 的 `filter_complex` 是成熟的 CPU 滤镜链，不需要 GPU
- 若用 GLSL 着色器，需要 FFmpeg 的 `frei0r` 或自定义滤镜，兼容性差
- **决策**：FFmpeg 导出路径用 `ffmpeg/filter.spec` 模板（FFmpeg 原生滤镜语法），WebGPU 预览路径用 `shader/effect.wgsl`。两条路径语义对齐由包作者保证（包内可声明 `semantic_version` 供运行期校验）

### 10.4 为什么不直接用 Lottie 动画？

- Lottie 适合矢量动画（贴纸、UI 动效），不适合像素级特效
- 粒子、光晕、变形等特效仍需着色器
- **决策**：`manifest.animation` 字段保留 Lottie 兼容的结构，但首版不实现 Lottie 解析。`category: sticker` 类包未来可扩展 Lottie 路径

### 10.5 LRU 容量上限 500MB 是否合理？

- 剪映移动端约 300-800MB 缓存
- 桌面端磁盘充裕，但过大影响启动扫描速度
- **决策**：默认 500MB，可在设置中调整（100MB - 5GB）。单包大小硬上限 50MB，超过拒绝安装

## 11. 后续演进方向

1. **着色器 IR 中间层**：定义 AIcut 自己的着色器 IR，包内只写一份 IR，运行期转译为 WGSL/GLSL/Metal。降低包作者负担
2. **社区创作工具**：提供 `.aifx` 包打包 CLI + 着色器预览器，让第三方作者贡献特效
3. **AI 生成特效**：结合 Phase 3 的 LLM 能力，让 AI 根据用户描述生成 WGSL 着色器（需更严格的沙箱）
4. **特效订阅与付费**：manifest 增加 `license` 字段，云端清单增加 `price`，支持付费包
5. **P2P 分发**：热门包通过局域网 P2P 分发，降低 CDN 成本
6. **着色器性能 profiling**：运行期采集每个特效的 GPU 耗时，自动降级或提示用户
