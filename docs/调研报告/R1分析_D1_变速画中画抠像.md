# R1分析：变速、画中画与蒙版、抠像功能调研

## 一、变速功能（截图175-177）

### 1.1 常规变速
- **入口**：选中时间轴上的视频片段后，右侧面板切换至「变速」标签，再选择「常规变速」子标签。
- **倍速范围**：滑块调节，支持 **0.1x ~ 50x** 的极宽范围（截图175显示最大可设至50倍）。
- **参数项**：
  - 倍速（滑块 + 数值显示）
  - 时长（随倍速反向联动，如截图175中时长20.4秒）
  - 声音变调（复选框，可勾选是否同步改变音频音调）
- **其他选项**：存在「同时拖动」旁有旋转线的选项，用于处理时间轴联动逻辑。

### 1.2 曲线变速
- **入口**：「变速」标签下切换至「曲线变速」子标签。
- **预设曲线**：提供多种内置速度曲线模板，图标直观展示速度变化趋势：
  1. 自定义（水平直线，可自由绘制）
  2. 更长中（中间慢两头快）
  3. 更短更慢（中间快两头慢）
  4. 子弹时间（急速减速）
  5. 鱼跃（先快后慢再快）
  6. 快起（起始快速）
  7. 跳切（阶梯式速度变化）
- 用户可点击预设快速应用，也可在自定义模式下手动绘制速度曲线。

### 1.3 变速范围与参数值总结
| 项目 | 范围/值 |
|------|--------|
| 常规变速倍率 | 0.1x ~ 50x |
| 曲线变速类型 | 7种预设 + 自定义 |
| 时长联动 | 自动随倍速反向计算 |
| 音频处理 | 可选「声音变调」 |

## 二、画中画与蒙版（截图178）

### 2.1 图层叠加逻辑
- 时间轴支持多轨道叠加，可将多个视频/图片素材拖至不同轨道实现画中画效果。
- 选中上层素材后，预览窗口显示带控制点的变换框，支持直接拖拽调整位置、缩放、旋转。
- 右侧面板层级关系：画面 → 变速 → 动画 → 蒙版 → 抠像 → 调节，各模块独立开关。

### 2.2 蒙版类型
- 右侧面板「蒙版」区域提供多种几何蒙版形状：
  - 圆形蒙版
  - 方形蒙版
  - 三角形蒙版
  - 其他形状（如星形、心形等）
- 蒙版支持位置、大小、羽化边缘等参数调节。

### 2.3 混合模式
- 右侧面板「画面」参数下设有「混合模式」下拉选项，支持多种图层混合方式（如正片叠底、滤色、叠加、柔光等），用于控制上下图层像素的混合计算逻辑。
- 另有「不透明度」滑块，独立控制当前图层透明度。

### 2.4 其他相关参数
- 位置（X、Y坐标）
- 旋转（角度）
- 缩放（宽度、高度，可分别调节或等比锁定）

## 三、抠像功能（截图179-181）

### 3.1 智能抠像
- **入口**：选中素材后，右侧面板「抠像」标签下启用「智能抠像」开关。
- **参数**：
  - 智能抠像：一键自动识别并抠出人物/主体，无需手动选色。
  - 自定义抠像：提供「大小」「边缘」「羽化」等参数滑块，用于精修抠像边缘。
  - 画面参数联动：阴影、亮度、对比度、饱和度、色温、色调等均可辅助优化抠像效果。
  - 运动跟踪：支持「颜色匹配」等跟踪方式，让蒙版跟随主体移动。

### 3.2 色度抠像（绿幕/蓝幕抠像）
- **入口**：「抠像」标签下启用「色度抠像」开关。
- **参数**：
  - 色度：颜色选择器（滴管工具），可吸取需要去除的背景色。
  - 强度：控制抠像的宽容度/强度，数值越高去除越干净，但可能损失主体边缘。
  - 阴影：调节阴影区域的保留与去除。
- 截图181中预览窗口显示蓝色遮罩覆盖人物，直观展示色度抠像的选中区域。

### 3.3 蒙版与抠像的结合
- 智能抠像与色度抠像可独立使用，也可配合蒙版（如圆形、方形蒙版）进一步限制抠像作用区域，实现局部抠像效果。
- 右侧面板中「蒙版」与「抠像」为相邻模块，逻辑上先应用蒙版限定区域，再执行抠像算法。

### 3.4 抠像参数总结
| 功能 | 主要参数 |
|------|----------|
| 智能抠像 | 开关、大小、边缘、羽化 |
| 色度抠像 | 色度选择、强度、阴影 |
| 运动跟踪 | 颜色匹配等 |
| 辅助调节 | 阴影、亮度、对比度、饱和度、色温、色调 |

## 四、综述

剪映专业版在变速、画中画与蒙版、抠像三大模块上提供了完整且直观的参数体系：
- **变速**：常规变速支持0.1x~50x的极宽范围，曲线变速提供7种预设+自定义绘制，满足不同节奏需求。
- **画中画与蒙版**：多轨道叠加配合多种几何蒙版和混合模式，图层合成灵活度高。
- **抠像**：智能抠像一键识别人物，色度抠像精准去背，两者均可配合蒙版和运动跟踪实现复杂合成效果。
