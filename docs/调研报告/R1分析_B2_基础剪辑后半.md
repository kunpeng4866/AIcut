# R1分析_B2_基础剪辑后半

## 截图148：画面旋转/镜像参数调整

- **操作类型**：继续调整视频画面的旋转或镜像属性。
- **触发方式**：在右侧面板「画面 → 基础」中修改「旋转」数值，或点击「镜像」相关按钮。
- **操作对象**：当前选中的单个视频素材片段。
- **参数选项**：
  - 旋转角度（承接截图147的 90°，继续向 450° 调整）
  - 镜像/翻转（水平/垂直四个方向按钮）
  - 缩放、位置等联动参数
- **交互细节**：
  - 右侧面板保持「基础」标签页。
  - 预览窗口实时显示旋转后的画面状态。
  - 为后续 450° 旋转结果做参数输入准备。

## 截图149：画面旋转至 450°

- **操作类型**：将视频画面旋转到 450°（即 360° + 90°）。
- **触发方式**：通过右侧面板「旋转」数值输入框输入 450°，或连续点击快速旋转按钮。
- **操作对象**：当前选中视频素材片段的画面方向。
- **参数选项**：
  - 旋转角度：450.00°（右侧面板精确显示）。
  - 缩放：100%，等比缩放保持锁定。
  - 镜像/翻转按钮组可见。
- **交互细节**：
  - 预览窗口中人物画面顺时针旋转 90° 后横向显示，与 90° 视觉效果一致。
  - 右侧面板出现黄色提示条「素材支持镜像变开了」，带「知道了」按钮可关闭。
  - 旋转支持任意角度输入，450° 说明系统保留了完整旋转圈数。

## 截图151：画面旋转至 720° 并分割片段

- **操作类型**：将视频画面旋转到 720°（两整圈），并对时间轴片段进行分割。
- **触发方式**：
  - 旋转：通过右侧面板「旋转」数值输入框输入 720°。
  - 分割：点击时间轴工具栏「分割」按钮或使用快捷键 Ctrl+B。
- **操作对象**：
  - 旋转操作：当前选中视频素材片段的画面方向。
  - 分割操作：时间轴上播放头所在位置的视频片段。
- **参数选项**：
  - 旋转角度：720.00°（预览画面恢复正立）。
  - 分割后生成两段独立片段，中间留有空隙。
- **交互细节**：
  - 预览窗口中人物画面恢复竖直正立，因为 720° 是 360° 的整数倍。
  - 时间轴片段被切分为两部分，可分别调整或删除。
  - 右侧面板仍显示「画面 → 基础」属性，旋转参数精确可控。

## 截图152：画面叠加/分屏与云端处理授权

- **操作类型**：将另一段素材（蜻蜓）叠加到当前画面上，形成分屏/画中画效果，并触发云端处理授权。
- **触发方式**：将第二段素材拖拽到时间轴的上方轨道，或拖拽到预览窗口进行叠加。
- **操作对象**：两段视频素材，主轨道人物素材与上方轨道蜻蜓素材。
- **参数选项**：
  - 上层素材的位置、大小、缩放等基础参数（右侧面板可见）。
  - 分屏/叠加布局：左右分屏（左侧人物，右侧蜻蜓）。
- **交互细节**：
  - 预览窗口同时显示两段素材，左侧为人物，右侧为蜻蜓，形成左右分屏。
  - 弹出授权对话框：「允许剪映上传你的草稿文件至服务端进行处理」，提供「允许」和「不允许」两个选项。
  - 该提示说明叠加/AI 处理等功能涉及草稿上传云端，需要用户授权。
  - 时间轴出现多个轨道，上层为蜻蜓素材。

## 截图153：添加文字图层与右键菜单

- **操作类型**：在时间轴上添加文字图层，并打开片段右键菜单。
- **触发方式**：
  - 文字：点击左侧「文字」面板，选择默认文字模板并添加到轨道。
  - 右键菜单：在时间轴片段上点击鼠标右键。
- **操作对象**：
  - 文字操作：新增的文字轨道/图层。
  - 右键菜单：时间轴上选中的视频或音频片段。
- **参数选项**：
  - 文字内容：默认文本「默认文本」。
  - 文字样式、动画、位置等（左侧面板显示模板和文案输入）。
  - 右键菜单包含：复制、删除、智能镜头分割、智能剪口播、分离音频、删除等选项。
- **交互细节**：
  - 预览窗口中人物画面上方显示「默认文本」字样，覆盖在画面内容之上。
  - 时间轴新增文字轨道，并以独立片段形式显示。
  - 右键菜单浮现在轨道片段上，提供常用的片段级编辑操作。
  - 轨道下方可见音频波形，说明视频音频已分离或保留。

## 综合分析

这六张截图承接「基础剪辑前半」的变换类操作，继续展示了剪映在单段与多段素材上的进阶基础剪辑能力：旋转任意角度、片段分割、画面叠加/分屏、文字图层添加。旋转操作支持精确数值输入，系统保留完整角度值（如 450°、720°），预览窗口实时反馈。分割操作将单段素材切分为多段，便于独立编辑。叠加与文字功能通过新增轨道实现，叠加/AI 类功能会触发云端上传授权提示。整体交互保持「右侧面板调参 + 预览实时反馈 + 时间轴多轨道管理」的剪辑范式，基础操作入口集中、反馈直观。
