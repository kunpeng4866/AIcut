fix: 修复转场后入片段开头反复播放（预览+导出源位置不连续）

根因：转场窗内入片段按 progress(0→1) 从素材开头推进到 dur*speed 位置，
但转场窗结束后入片段成为活跃片段，clipSourceTime 用真实 timelineIn(=outT) 计算，
off≈0 → 源位置跳回 src_range.start（开头），导致视频被 seek 回开头、反复 2-3 次
才收敛 → 视觉上「入片段开头反复出现」。

修复：引入「虚拟 timelineIn」= 转场窗起点(outT - dur)。转场让入片段提前 dur 秒显示，
其源时间应从转场窗起点起算，窗内(progress 0→1 对应 0→dur*speed)与窗后(从 dur*speed 继续)
连续衔接，不再跳回开头。

预览(PreviewCanvas.tsx)：
- clipSourceTime 加 overrideTimelineIn 可选参数
- activeTransitionLayers 计算时构建 incomingVirtualIn map(入片段id→虚拟timelineIn)
- seek effect：activeTransitionLayers / activeVideoClips(命中虚拟in) / onLoadedMetadataFor
  均用虚拟 timelineIn 计算源时间
导出(export.rs + strategy.rs)：
- clip_source_time_with_in(t, clip, override_in) 新增可覆盖 timelineIn 版本
- 构建 incoming_virtual_in map，video_clips prefetch 与 extra_next(转场窗内) 均用虚拟 timelineIn
  保证导出视频入片段开头不重复

验证: tsc --noEmit 0错; cargo build 0错; cargo test --lib 197/197 通过
